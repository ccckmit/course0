# 第四章 Context Engineering

## 4.1 什麼是 Context Engineering

Context Engineering 是一門專注於設計、建構和管理提供給 AI 模型的上下文資訊的學科。與提示工程不同，Context Engineering 更關注如何選擇、組織和最佳化提供給模型的大量背景資訊，以確保模型能夠在 token 限制內獲得最相關、最有用的資訊。

### 4.1.1 Context Engineering 的定義與範疇

在 AI 軟體工程中，上下文 (context) 指的是提供給模型的所有輔助資訊，包括：

- 專案背景與架構說明
- 相關的原始碼檔案
- 過去的對話歷史
- 外部資料庫查詢結果
- API 文件與規格
- 編碼規範與團隊慣例

Context Engineering 的目標是在有限的 token 預算下，最大化這些資訊對任務的貢獻度。

### 4.1.2 為什麼需要 Context Engineering

大型語言模型有固定的上下文視窗限制。例如：

- GPT-3.5-turbo: 4K tokens (約 3000 個中文字)
- GPT-4: 8K / 32K / 128K tokens
- Claude 3: 200K tokens
- Gemini 1.5 Pro: 1M tokens

即使模型支援越來越長的上下文，但實際使用時仍面臨三個核心問題：

1. **資訊稀釋**：過多的不相關資訊會稀釋模型的注意力
2. **成本問題**：token 數量直接對應 API 成本
3. **延遲問題**：更長的上下文導致更長的處理時間

Context Engineering 的目標就是解決這些問題。

### 4.1.3 Context Engineering vs. Prompt Engineering

| 維度 | 提示工程 | Context Engineering |
|------|---------|-------------------|
| 焦點 | 指令的設計與最佳化 | 資訊的選擇與組織 |
| 規模 | 通常是短文本 (數百 tokens) | 可能是大量文件 (數萬 tokens) |
| 主要挑戰 | 表達清晰度、角色設定 | Token 預算、相關性排序 |
| 關鍵技術 | 提示結構、範例選擇 | 檢索、摘要、壓縮 |
| 變動頻率 | 每次請求可能不同 | 每次請求需要動態組合 |

這兩個領域高度互補。提示工程處理「怎麼說」，Context Engineering 處理「說什麼」。

## 4.2 上下文管理的挑戰

### 4.2.1 Token 預算管理

Token 預算管理是 Context Engineering 最基礎的挑戰。每次 API 呼叫都有 token 上限，開發者需要在這個限制內做出取捨。

```python
class TokenBudgetManager:
    def __init__(self, max_tokens=8000, reserved_output=1000):
        self.max_tokens = max_tokens
        self.reserved_output = reserved_output
        self.context_budget = max_tokens - reserved_output
        self.allocations = {}

    def allocate(self, component, tokens, priority=1):
        if sum(self.allocations.values()) + tokens > self.context_budget:
            return self._reallocate(component, tokens, priority)
        self.allocations[component] = tokens
        return True

    def _reallocate(self, new_component, new_tokens, new_priority):
        total_allocated = sum(self.allocations.values())
        available = self.context_budget - total_allocated

        if available >= new_tokens:
            self.allocations[new_component] = new_tokens
            return True

        # 按優先級重新分配
        sorted_components = sorted(
            self.allocations.items(),
            key=lambda x: self._get_priority(x[0]),
            reverse=True
        )

        freed = 0
        to_remove = []
        for comp, tokens in sorted_components:
            if self._get_priority(comp) < new_priority:
                freed += tokens
                to_remove.append(comp)
                if freed >= new_tokens:
                    break

        if freed >= new_tokens:
            for comp in to_remove:
                del self.allocations[comp]
            self.allocations[new_component] = new_tokens
            return True

        return False

    def _get_priority(self, component):
        # 預定義的優先級映射
        priorities = {
            "system_prompt": 10,
            "user_request": 9,
            "current_file": 8,
            "related_files": 5,
            "dependency_graph": 4,
            "git_history": 3,
            "chat_history": 2,
        }
        return priorities.get(component, 1)

    def get_summary(self):
        return {
            "total_budget": self.context_budget,
            "allocated": sum(self.allocations.values()),
            "remaining": self.context_budget - sum(self.allocations.values()),
            "components": dict(self.allocations)
        }
```

### 4.2.2 資訊過濾與相關性判斷

不是所有資訊都應該被放入上下文。資訊過濾的核心是判斷哪些資訊對當前任務有幫助：

```python
class InformationFilter:
    def __init__(self):
        self.filters = []

    def add_filter(self, name, filter_fn):
        self.filters.append({"name": name, "fn": filter_fn})

    def filter(self, documents, task_description):
        results = []
        for doc in documents:
            passed = True
            filter_results = {}
            for f in self.filters:
                try:
                    score = f["fn"](doc, task_description)
                    filter_results[f["name"]] = score
                    if score < 0.3:
                        passed = False
                except Exception as e:
                    filter_results[f["name"]] = 0.0
                    passed = False

            if passed:
                results.append({
                    "document": doc,
                    "scores": filter_results,
                    "composite_score": sum(filter_results.values()) / len(filter_results)
                })

        results.sort(key=lambda x: x["composite_score"], reverse=True)
        return results


# 實例化不同的過濾器
def length_filter(doc, task):
    max_length = 5000
    relevance = min(1.0, len(doc["content"]) / max_length)
    return relevance

def keyword_filter(doc, task):
    task_keywords = set(task.lower().split())
    doc_keywords = set(doc["content"].lower().split())
    if not task_keywords:
        return 0.5
    intersection = task_keywords & doc_keywords
    return len(intersection) / len(task_keywords)

def recency_filter(doc, task):
    from datetime import datetime, timedelta
    if "last_modified" not in doc:
        return 0.5
    age = datetime.now() - datetime.fromisoformat(doc["last_modified"])
    score = max(0, 1.0 - (age.days / 365))
    return score
```

### 4.2.3 上下文遺忘 (Context Forgetting)

即使是長上下文模型，也會在處理長文本時出現「注意力分散」的問題。模型傾向於更關注文本的開頭和結尾，中間部分的資訊容易被忽略：

```python
class ContextForgettingMitigator:
    def __init__(self, window_size=2000):
        self.window_size = window_size

    def structure_context(self, documents):
        """
        將上下文組織為「重要資訊在前後，次要資訊在中間」的結構。
        利用模型對開頭和結尾的注意力優勢。
        """
        # 對文件進行重要性排序
        ranked = sorted(
            documents,
            key=lambda x: x.get("importance", 0),
            reverse=True
        )

        # 將最重要的放在開頭和結尾
        n = len(ranked)
        if n <= 3:
            return ranked

        reordered = []
        # 最重要的放在開頭
        reordered.extend(ranked[:max(1, n // 4)])
        # 中間放次重要的
        reordered.extend(ranked[n // 4: 3 * n // 4])
        # 次重要的放在結尾
        reordered.extend(ranked[3 * n // 4:])

        return reordered

    def add_attention_markers(self, context):
        """
        在關鍵段落前後加入注意力標記，幫助模型定位重要資訊。
        """
        markers = {
            "high": ("[重要資訊開始]", "[重要資訊結束]"),
            "medium": ("[參考資訊開始]", "[參考資訊結束]"),
            "low": ("[背景資訊開始]", "[背景資訊結束]"),
        }

        marked_context = context
        for level, (start, end) in markers.items():
            pass

        return marked_context

    def segment_and_summarize(self, long_text, max_segments=5):
        """
        將長文本分段，每段獨立摘要，再合併。
        避免模型在長文本中迷失。
        """
        sentences = long_text.split("。")
        segments = []
        current_segment = []
        current_length = 0

        for sentence in sentences:
            current_segment.append(sentence)
            current_length += len(sentence)
            if current_length >= self.window_size:
                segments.append("。".join(current_segment))
                current_segment = []
                current_length = 0

        if current_segment:
            segments.append("。".join(current_segment))

        summaries = []
        for i, segment in enumerate(segments[:max_segments]):
            summary = self._summarize_segment(segment)
            summaries.append(f"[第{i+1}段摘要] {summary}")

        return "\n".join(summaries)

    def _summarize_segment(self, text):
        return text[:100] + "..."
```

## 4.3 上下文建構策略

### 4.3.1 靜態上下文建構

靜態上下文是指在應用啟動時或專案初始化時就確定好的上下文內容，通常不會頻繁變動：

```python
class StaticContextBuilder:
    def __init__(self, project_root):
        self.project_root = project_root
        self.context_sources = {}

    def add_static_source(self, name, content, priority=1):
        self.context_sources[name] = {
            "content": content,
            "priority": priority,
            "type": "static"
        }

    def load_project_config(self):
        import os
        config_files = [
            "README.md",
            "pyproject.toml",
            "setup.cfg",
            ".editorconfig",
            "CONTRIBUTING.md",
            "docs/architecture.md",
            "docs/style-guide.md"
        ]

        for filename in config_files:
            filepath = os.path.join(self.project_root, filename)
            if os.path.exists(filepath):
                with open(filepath, "r", encoding="utf-8") as f:
                    content = f.read()
                self.add_static_source(
                    filename,
                    content,
                    priority=3 if "architecture" in filename else 1
                )

    def build_static_context(self, token_limit=2000):
        sorted_sources = sorted(
            self.context_sources.items(),
            key=lambda x: x[1]["priority"],
            reverse=True
        )

        context_parts = []
        current_tokens = 0

        for name, source in sorted_sources:
            estimated_tokens = len(source["content"]) // 4
            if current_tokens + estimated_tokens > token_limit:
                truncated = source["content"][:token_limit * 4 - current_tokens]
                context_parts.append(f"=== {name} (截斷) ===\n{truncated}")
                break

            context_parts.append(f"=== {name} ===\n{source['content']}")
            current_tokens += estimated_tokens

        return "\n\n".join(context_parts)
```

### 4.3.2 動態上下文建構

動態上下文是根據當前請求即時組合的上下文。這是最常用的策略，因為它能確保每次請求都獲得最相關的資訊：

```python
class DynamicContextBuilder:
    def __init__(self, project_index=None):
        self.project_index = project_index or {}
        self.context_strategies = {}

    def register_strategy(self, name, strategy_fn):
        self.context_strategies[name] = strategy_fn

    def build_context(self, request, strategies=None):
        if strategies is None:
            strategies = list(self.context_strategies.keys())

        context = {}
        for strategy_name in strategies:
            if strategy_name in self.context_strategies:
                context[strategy_name] = self.context_strategies[strategy_name](request)

        return self._compose_context(context)

    def _compose_context(self, context_parts):
        sections = []
        for key, value in context_parts.items():
            if value:
                sections.append(f"## {key}\n{value}")
        return "\n\n".join(sections)


# 註冊常用的動態上下文策略

def current_file_strategy(request):
    """提供當前正在編輯的檔案內容"""
    if "current_file" in request:
        return f"```{request['current_file']['language']}\n{request['current_file']['content']}\n```"
    return ""

def related_files_strategy(request):
    """提供與當前任務相關的檔案內容"""
    if "related_files" in request:
        parts = []
        for f in request["related_files"][:3]:
            parts.append(f"### {f['path']}\n```{f['language']}\n{f['content'][:2000]}\n```")
        return "\n".join(parts)
    return ""

def recent_changes_strategy(request):
    """提供最近的 Git 變更記錄"""
    if "git_log" in request:
        return request["git_log"]
    return ""

def error_context_strategy(request):
    """提供錯誤發生時相關的堆疊追蹤和狀態"""
    if "error" in request:
        parts = [f"錯誤訊息: {request['error'].get('message', '')}"]
        if "traceback" in request["error"]:
            parts.append(f"堆疊追蹤:\n```\n{request['error']['traceback']}\n```")
        if "variables" in request["error"]:
            parts.append(f"變數狀態:\n{request['error']['variables']}")
        return "\n".join(parts)
    return ""
```

### 4.3.3 層級化上下文 (Hierarchical Context)

層級化上下文是將資訊按照抽象層次組織，從高層架構到底層實作：

```python
class HierarchicalContextBuilder:
    def __init__(self):
        self.layers = {
            "global": [],
            "module": [],
            "file": [],
            "function": [],
            "line": []
        }

    def add_to_layer(self, layer, content, metadata=None):
        if layer in self.layers:
            self.layers[layer].append({
                "content": content,
                "metadata": metadata or {}
            })

    def build_hierarchical_context(self, task_type, depth=3):
        """根據任務類型決定需要哪些層級的上下文"""

        task_layer_mapping = {
            "architecture_review": ["global", "module"],
            "code_review": ["module", "file", "function"],
            "debugging": ["function", "line", "file"],
            "feature_implementation": ["global", "module", "file"],
            "code_explanation": ["function", "file"],
        }

        selected_layers = task_layer_mapping.get(task_type, ["file"])

        context_parts = []
        for layer_name in selected_layers[:depth]:
            items = self.layers.get(layer_name, [])
            if not items:
                continue

            layer_header = self._get_layer_header(layer_name)
            context_parts.append(layer_header)

            for item in items:
                context_parts.append(item["content"])

        return "\n\n".join(context_parts)

    def _get_layer_header(self, layer):
        headers = {
            "global": "=== 專案層級上下文 ===",
            "module": "=== 模組層級上下文 ===",
            "file": "=== 檔案層級上下文 ===",
            "function": "=== 函數層級上下文 ===",
            "line": "=== 行級上下文 ===",
        }
        return headers.get(layer, f"=== {layer} ===")


# 使用範例
def build_code_review_context(project, target_file, modified_lines):
    builder = HierarchicalContextBuilder()

    # 全域層：專案架構
    builder.add_to_layer("global", f"""
專案名稱: {project['name']}
語言: {project['language']}
架構: {project['architecture']}
主要依賴: {', '.join(project['dependencies'][:10])}
    """, {"type": "project_metadata"})

    # 模組層：目標檔案所屬模組
    module = project['modules'].get(target_file['module'], {})
    builder.add_to_layer("module", f"""
模組: {target_file['module']}
描述: {module.get('description', '')}
模組內檔案: {len(module.get('files', []))}
外部依賴: {', '.join(module.get('external_deps', []))}
    """)

    # 檔案層：目標檔案
    builder.add_to_layer("file", f"""
檔案: {target_file['path']}
```{target_file['language']}
{target_file['content']}
```
    """)

    # 函數層：修改的函數
    for func in target_file.get('modified_functions', []):
        builder.add_to_layer("function", f"""
函數: {func['name']}
```python
{func['code']}
```
    """)

    return builder.build_hierarchical_context("code_review")
```

## 4.4 Token 最佳化技術

### 4.4.1 摘要壓縮

摘要壓縮是將長文本轉換為簡潔摘要，保留關鍵資訊的技術：

```python
class ContextCompressor:
    def __init__(self, llm_client=None):
        self.llm_client = llm_client

    def summarize_code_file(self, file_path, content, max_tokens=500):
        if self.llm_client:
            prompt = f"""
請對以下程式碼檔案進行專業摘要，保留：
1. 檔案的主要用途
2. 定義的主要類別和函數
3. 重要的設計決策
4. 外部依賴和 API

檔案路徑: {file_path}

```python
{content[:8000]}
```

請以結構化格式輸出摘要，控制在 {max_tokens} tokens 以內。
"""
            return self.llm_client(prompt)
        else:
            return self._basic_summarize(content, max_tokens)

    def _basic_summarize(self, content, max_tokens):
        lines = content.split("\n")
        summary_parts = []

        # 提取 import 語句
        imports = [l for l in lines if l.startswith("import ") or l.startswith("from ")]
        if imports:
            summary_parts.append("依賴: " + ", ".join(imports[:10]))

        # 提取類別和函數定義
        definitions = []
        for line in lines:
            stripped = line.strip()
            if stripped.startswith("class ") or stripped.startswith("def "):
                definitions.append(stripped)

        if definitions:
            summary_parts.append("定義: " + "; ".join(definitions[:20]))

        # 提取 docstring 或註解
        docstrings = []
        in_docstring = False
        for line in lines:
            if '"""' in line or "'''" in line:
                in_docstring = not in_docstring
                continue
            if in_docstring and line.strip():
                docstrings.append(line.strip())

        if docstrings:
            summary_parts.append("文件: " + " ".join(docstrings[:5]))

        return "\n".join(summary_parts)[:max_tokens * 4]

    def lossy_compress(self, text, target_ratio=0.3):
        """有損壓縮：移除註解、空白行，簡化變數名稱等"""
        lines = text.split("\n")
        compressed = []

        for line in lines:
            stripped = line.strip()
            if not stripped:
                continue
            if stripped.startswith("#"):
                continue
            if stripped.startswith("//"):
                continue
            if stripped.startswith("/*") or stripped.startswith("*"):
                continue
            compressed.append(line)

        result = "\n".join(compressed)
        target_length = int(len(text) * target_ratio)
        if len(result) > target_length:
            result = result[:target_length]

        return result
```

### 4.4.2 選擇性包含

選擇性包含是在大量候選資訊中，只選擇最相關的部分加入上下文：

```python
class SelectiveInclusion:
    def __init__(self, max_tokens=4000):
        self.max_tokens = max_tokens

    def select_files(self, all_files, task, max_files=5):
        """從大量檔案中選擇與任務最相關的檔案"""

        scored_files = []
        for file_info in all_files:
            score = self._calculate_relevance(file_info, task)
            scored_files.append((score, file_info))

        scored_files.sort(key=lambda x: x[0], reverse=True)
        return [f[1] for f in scored_files[:max_files]]

    def _calculate_relevance(self, file_info, task):
        score = 0.0
        task_lower = task.lower()

        # 檔案名稱匹配
        if file_info["name"].lower() in task_lower:
            score += 0.4

        # 檔案路徑匹配
        if file_info["path"].lower() in task_lower:
            score += 0.3

        # 檔案內容中的關鍵字匹配
        content_lower = file_info["content"].lower()[:2000]
        task_words = set(task_lower.split())
        content_words = set(content_lower.split())
        overlap = task_words & content_words
        if task_words:
            score += 0.3 * (len(overlap) / len(task_words))

        return score

    def select_lines(self, file_content, task, max_lines=30):
        """從檔案中選擇與任務最相關的行"""
        lines = file_content.split("\n")
        scored_lines = []

        for i, line in enumerate(lines):
            relevance = self._line_relevance(line, task)
            if relevance > 0:
                scored_lines.append((relevance, i, line))

        scored_lines.sort(key=lambda x: x[0], reverse=True)
        selected_indices = sorted([s[1] for s in scored_lines[:max_lines]])

        result = []
        last_idx = -1
        for idx in selected_indices:
            if last_idx >= 0 and idx - last_idx > 3:
                result.append("...")
            result.append(lines[idx])
            last_idx = idx

        return "\n".join(result)

    def _line_relevance(self, line, task):
        task_lower = task.lower()
        line_lower = line.lower()

        score = 0
        for word in task_lower.split():
            if word in line_lower and len(word) > 2:
                score += 0.2

        # 函數定義行優先
        if line.strip().startswith("def ") or line.strip().startswith("class "):
            score += 0.5

        # 錯誤處理優先
        if "error" in line_lower or "exception" in line_lower or "try:" in line_lower:
            score += 0.3

        return score
```

### 4.4.3 滑動窗口 (Sliding Window)

滑動窗口技術用於處理長對話歷史或長時間序列，保留最近且最相關的內容：

```python
class SlidingWindowManager:
    def __init__(self, window_size=3000, overlap=200):
        self.window_size = window_size
        self.overlap = overlap
        self.history = []

    def add_message(self, role, content):
        self.history.append({
            "role": role,
            "content": content,
            "timestamp": self._now()
        })

    def get_window(self, include_recent_n=10):
        """使用滑動窗口取得相關的歷史訊息"""
        if not self.history:
            return []

        # 從最新的訊息開始往回取
        window = []
        current_tokens = 0

        for msg in reversed(self.history[-include_recent_n:]):
            msg_tokens = len(msg["content"]) // 4
            if current_tokens + msg_tokens > self.window_size:
                # 如果超過限制，截斷這個訊息
                remaining_tokens = self.window_size - current_tokens
                if remaining_tokens > 20:
                    truncated = msg["content"][:remaining_tokens * 4]
                    window.insert(0, {
                        "role": msg["role"],
                        "content": truncated + " [截斷]"
                    })
                break
            window.insert(0, msg)
            current_tokens += msg_tokens

        return window

    def get_summarized_window(self, summarizer_fn, max_messages=50):
        """當歷史過長時，將舊訊息摘要後保留"""
        if len(self.history) <= max_messages:
            return self.history

        recent = self.history[-max_messages // 2:]
        old_messages = self.history[:-max_messages // 2]

        old_summary = summarizer_fn(old_messages)
        summarized = [{"role": "system", "content": f"歷史摘要: {old_summary}"}]
        summarized.extend(recent)

        return summarized

    def _now(self):
        from datetime import datetime
        return datetime.now().isoformat()
```

## 4.5 資訊檢索與相關性排序

### 4.5.1 向量搜尋與語義檢索

向量搜尋是實現語義檢索的核心技術，透過將文本轉換為嵌入向量來計算相似度：

```python
class SemanticRetriever:
    def __init__(self, embedding_model="text-embedding-3-small"):
        self.embedding_model = embedding_model
        self.documents = []
        self.embeddings = []
        self.index = {}

    def add_documents(self, documents):
        """加入文件並計算嵌入向量"""
        import openai

        for doc in documents:
            response = openai.embeddings.create(
                model=self.embedding_model,
                input=doc["content"]
            )
            embedding = response.data[0].embedding

            self.documents.append(doc)
            self.embeddings.append(embedding)

        self._build_index()

    def _build_index(self):
        """建立近似最近鄰索引以加速搜尋"""
        try:
            import faiss
            import numpy as np

            if not self.embeddings:
                return

            dim = len(self.embeddings[0])
            index = faiss.IndexFlatIP(dim)
            embeddings_np = np.array(self.embeddings).astype('float32')
            faiss.normalize_L2(embeddings_np)
            index.add(embeddings_np)
            self.index["faiss"] = index

        except ImportError:
            self.index["method"] = "brute_force"

    def search(self, query, top_k=5, min_score=0.5):
        """執行語義搜尋"""
        import openai
        import numpy as np

        query_response = openai.embeddings.create(
            model=self.embedding_model,
            input=query
        )
        query_embedding = query_response.data[0].embedding
        query_np = np.array([query_embedding]).astype('float32')

        if "faiss" in self.index:
            faiss.normalize_L2(query_np)
            scores, indices = self.index["faiss"].search(query_np, top_k)

            results = []
            for score, idx in zip(scores[0], indices[0]):
                if score >= min_score and idx < len(self.documents):
                    results.append({
                        "document": self.documents[idx],
                        "score": float(score),
                        "rank": len(results) + 1
                    })
            return results

        else:
            # 暴力搜尋
            scores = []
            for emb in self.embeddings:
                emb_np = np.array(emb)
                score = np.dot(query_np[0], emb_np) / (
                    np.linalg.norm(query_np[0]) * np.linalg.norm(emb_np)
                )
                scores.append(score)

            ranked_indices = np.argsort(scores)[::-1][:top_k]
            results = []
            for idx in ranked_indices:
                if scores[idx] >= min_score:
                    results.append({
                        "document": self.documents[idx],
                        "score": float(scores[idx]),
                        "rank": len(results) + 1
                    })
            return results
```

### 4.5.2 BM25 關鍵字檢索

BM25 是一種基於詞頻的檢索演算法，與向量搜尋互補。它特別擅長處理精確關鍵字匹配：

```python
import math
from collections import Counter

class BM25Retriever:
    def __init__(self, k1=1.5, b=0.75):
        self.k1 = k1
        self.b = b
        self.documents = []
        self.doc_lengths = []
        self.avg_doc_length = 0
        self.inverted_index = {}
        self.num_docs = 0

    def index_documents(self, documents):
        self.documents = documents
        self.num_docs = len(documents)
        self.doc_lengths = [len(doc["content"].split()) for doc in documents]
        self.avg_doc_length = sum(self.doc_lengths) / self.num_docs if self.num_docs else 0

        for idx, doc in enumerate(documents):
            tokens = doc["content"].split()
            token_counts = Counter(tokens)

            for token, count in token_counts.items():
                if token not in self.inverted_index:
                    self.inverted_index[token] = {}
                self.inverted_index[token][idx] = count

    def search(self, query, top_k=5):
        query_tokens = query.lower().split()
        scores = [0.0] * self.num_docs

        for token in query_tokens:
            if token not in self.inverted_index:
                continue

            df = len(self.inverted_index[token])
            idf = math.log(
                (self.num_docs - df + 0.5) / (df + 0.5) + 1.0
            )

            for doc_idx, freq in self.inverted_index[token].items():
                doc_len = self.doc_lengths[doc_idx]
                tf = freq * (self.k1 + 1) / (
                    freq + self.k1 * (1 - self.b + self.b * doc_len / self.avg_doc_length)
                )
                scores[doc_idx] += idf * tf

        ranked = sorted(
            enumerate(scores),
            key=lambda x: x[1],
            reverse=True
        )[:top_k]

        results = []
        for idx, score in ranked:
            if score > 0:
                results.append({
                    "document": self.documents[idx],
                    "score": score,
                    "rank": len(results) + 1
                })
        return results


class HybridRetriever:
    def __init__(self, semantic_weight=0.6, bm25_weight=0.4):
        self.semantic = SemanticRetriever()
        self.bm25 = BM25Retriever()
        self.semantic_weight = semantic_weight
        self.bm25_weight = bm25_weight

    def index_documents(self, documents):
        self.semantic.add_documents(documents)
        self.bm25.index_documents(documents)

    def search(self, query, top_k=5):
        semantic_results = self.semantic.search(query, top_k=top_k * 2)
        bm25_results = self.bm25.search(query, top_k=top_k * 2)

        # 融合分數
        combined = {}
        for r in semantic_results:
            doc_id = id(r["document"])
            combined[doc_id] = {
                "score": r["score"] * self.semantic_weight,
                "document": r["document"]
            }

        for r in bm25_results:
            doc_id = id(r["document"])
            if doc_id in combined:
                combined[doc_id]["score"] += r["score"] * self.bm25_weight
            else:
                combined[doc_id] = {
                    "score": r["score"] * self.bm25_weight,
                    "document": r["document"]
                }

        ranked = sorted(
            combined.values(),
            key=lambda x: x["score"],
            reverse=True
        )[:top_k]

        return [{
            "document": r["document"],
            "score": r["score"],
            "rank": i + 1
        } for i, r in enumerate(ranked)]
```

### 4.5.3 Re-ranking 技術

Re-ranking 是在初步檢索後，使用更精密的模型對結果進行重新排序：

class ReRanker:
    def __init__(self, llm_client=None):
        self.llm_client = llm_client

    def cross_encoder_rerank(self, query, documents, model_name="cross-encoder/ms-marco-MiniLM-L-6-v2"):

請根據以下查詢，對提供的文件片段進行相關性排序。

"""

class DiversityReRanker:
    """在相關性基礎上增加多樣性，避免結果過於相似"""

    def __init__(self, relevance_weight=0.7, diversity_weight=0.3):
        self.relevance_weight = relevance_weight
        self.diversity_weight = diversity_weight

    def rerank_with_diversity(self, documents, query=None, top_k=5):
        if not documents:
            return []

        selected = [documents[0]]
        candidates = documents[1:]

        while len(selected) < top_k and candidates:
            best_score = -float("inf")
            best_candidate = None

            for candidate in candidates:
                relevance = candidate.get("score", 0)
                diversity = self._min_diversity(candidate, selected)
                combined = (
                    self.relevance_weight * relevance +
                    self.diversity_weight * diversity
                )

                if combined > best_score:
                    best_score = combined
                    best_candidate = candidate

            if best_candidate:
                selected.append(best_candidate)
                candidates.remove(best_candidate)
            else:
                break

        return selected

    def _min_diversity(self, candidate, selected):
        min_diff = float("inf")
        for sel in selected:
            diff = self._jaccard_distance(
                candidate["content"],
                sel["content"]
            )
            min_diff = min(min_diff, diff)
        return min_diff

    def _jaccard_distance(self, text_a, text_b):
        set_a = set(text_a.split())
        set_b = set(text_b.split())
        if not set_a and not set_b:
            return 1.0
        intersection = set_a & set_b
        union = set_a | set_b
        return 1.0 - len(intersection) / len(union)
```

### 4.6.1 相關檔案偵測

在大型專案中，自動偵測與當前任務相關的檔案是 Context Engineering 的核心功能：

```python
class RelevantFileDetector:
    def __init__(self, project_root):
        self.project_root = project_root
        self.file_index = {}
        self.dependency_graph = {}

    def build_file_index(self):
        import os

        for root, dirs, files in os.walk(self.project_root):
            dirs[:] = [d for d in dirs if not d.startswith(".") and d != "node_modules" and d != "__pycache__"]

            for file in files:
                if file.endswith((".py", ".js", ".ts", ".jsx", ".tsx", ".go", ".rs", ".java", ".c", ".cpp", ".h", ".hpp")):
                    filepath = os.path.join(root, file)
                    rel_path = os.path.relpath(filepath, self.project_root)

                    with open(filepath, "r", encoding="utf-8", errors="ignore") as f:
                        content = f.read()

                    self.file_index[rel_path] = {
                        "path": rel_path,
                        "name": file,
                        "extension": os.path.splitext(file)[1],
                        "content": content,
                        "imports": self._extract_imports(content, file),
                        "size": len(content)
                    }

    def _extract_imports(self, content, filename):
        imports = []
        if filename.endswith(".py"):
            for line in content.split("\n"):
                stripped = line.strip()
                if stripped.startswith("import ") or stripped.startswith("from "):
                    imports.append(stripped)
        elif filename.endswith((".js", ".ts", ".jsx", ".tsx")):
            for line in content.split("\n"):
                stripped = line.strip()
                if stripped.startswith("import ") or stripped.startswith("require("):
                    imports.append(stripped)
        return imports

    def detect_related_files(self, target_file, task_description):
        related = set()
        target_info = self.file_index.get(target_file)

        if not target_info:
            return []

        related.add(target_file)

        # 透過 import 關係尋找
        for imp in target_info.get("imports", []):
            for path in self._resolve_import(imp):
                if path in self.file_index:
                    related.add(path)

        # 透過被引用關係尋找
        for path, info in self.file_index.items():
            if target_file in str(info.get("imports", [])):
                related.add(path)

        # 透過關鍵字匹配尋找
        task_keywords = set(task_description.lower().split())
        for path, info in self.file_index.items():
            if path in related:
                continue
            file_kw = set(info["name"].lower().split(".")[0].split("_"))
            if file_kw & task_keywords:
                related.add(path)

        return list(related)

    def _resolve_import(self, import_statement):
        resolved = []
        if "import " in import_statement:
            parts = import_statement.replace("from ", "").replace("import ", "").split(" import ")[0]
        else:
            return resolved

        for path, info in self.file_index.items():
            module_path = path.replace("/", ".").replace("\\", ".").rsplit(".", 1)[0]
            if parts in module_path or module_path.endswith(parts):
                resolved.append(path)

        return resolved[:3]
```

### 4.6.2 依賴圖分析

依賴圖分析幫助理解檔案之間的關聯，從而決定哪些檔案應該被包含在上下文中：

```python
class DependencyGraphAnalyzer:
    def __init__(self):
        self.graph = {}
        self.reverse_graph = {}

    def build_from_imports(self, file_imports):
        """從檔案間的 import 關係建立依賴圖"""
        self.graph = {}
        self.reverse_graph = {}

        for file_path, imports in file_imports.items():
            if file_path not in self.graph:
                self.graph[file_path] = set()

            for imp in imports:
                if imp not in self.graph:
                    self.graph[imp] = set()
                self.graph[file_path].add(imp)

                if imp not in self.reverse_graph:
                    self.reverse_graph[imp] = set()
                self.reverse_graph[imp].add(file_path)

    def get_impact_analysis(self, changed_file, depth=2):
        """分析某個檔案變更會影響哪些其他檔案"""
        affected = set()
        current_level = {changed_file}

        for _ in range(depth):
            next_level = set()
            for file_path in current_level:
                dependents = self.reverse_graph.get(file_path, set())
                next_level.update(dependents - affected)
            affected.update(next_level)
            current_level = next_level

        return affected

    def get_dependency_chain(self, source_file, target_file):
        """找到兩個檔案之間的依賴鏈路"""
        visited = set()
        path = []

        def dfs(current, target, path_so_far):
            if current == target:
                return path_so_far + [current]
            if current in visited:
                return None
            visited.add(current)

            for neighbor in self.graph.get(current, set()):
                result = dfs(neighbor, target, path_so_far + [current])
                if result:
                    return result
            return None

        return dfs(source_file, target_file, [])

    def get_topological_context(self, files, max_files=10):
        """按照依賴關係的拓撲排序來組織上下文"""
        in_degree = {}
        for file_path in files:
            if file_path not in in_degree:
                in_degree[file_path] = 0
            for dep in self.graph.get(file_path, set()):
                if dep in files:
                    in_degree[file_path] = in_degree.get(file_path, 0) + 1

        # 被依賴越多的檔案越重要，優先放入上下文
        sorted_files = sorted(
            files,
            key=lambda f: in_degree.get(f, 0),
            reverse=True
        )

        return sorted_files[:max_files]
```

### 4.6.3 最近修改優先

在開發過程中，最近修改過的檔案通常與當前任務最相關：

class RecentModificationTracker:

    def analyze_git_history(self, days=30):

        import subprocess
        from datetime import datetime, timedelta

        since_date = (datetime.now() - timedelta(days=days)).strftime("%Y-%m-%d")

        result = subprocess.run(
            ["git", "log", "--since", since_date,

                continue
            parts = line.split(" ", 3)

                    "hash": parts[0],
                    "date": parts[1] + " " + parts[2],
                    "message": parts[3]
                }

                if file_path not in self.file_activity:
                    self.file_activity[file_path] = []

        now = datetime.now()

        scores = {}
        for file_path, commits in self.file_activity.items():
            recency = 0
            latest_date = None

            for commit in commits:
                commit_date = datetime.strptime(
                    commit["date"].split(" ")[0],
                    "%Y-%m-%d"
                )
                if latest_date is None or commit_date > latest_date:
                    latest_date = commit_date

            if latest_date:
                days_ago = (now - latest_date).days
                recency = max(0, 1 - days_ago / 90)

            frequency = min(1, len(commits) / 20)
            score = recency_weight * recency + frequency_weight * frequency
            scores[file_path] = score

        sorted_files = sorted(
            scores.items(),
            key=lambda x: x[1],
            reverse=True
        )

            role = msg.get("role", "user")
            content = msg.get("content", "")[:500]
            history_parts.append(f"{role}: {content}")

        return {
            "type": "history",
            "content": "\n".join(history_parts),
            "priority": 3
        }

    def _build_diagnostics_section(self, request):
        errors = request.get("errors", [])
        if not errors:
            return None

        error_parts = []
        for err in errors[:3]:
            error_parts.append(
                f"- {err.get('file', 'unknown')}:{err.get('line', '?')} - {err.get('message', '')}"
            )

        return {
            "type": "diagnostics",
            "content": "\n".join(error_parts),
            "priority": 9
        }

    def _assemble_context(self, sections):
        sections.sort(key=lambda s: s["priority"], reverse=True)
        assembled = []
        current_tokens = 0
        budget = self.token_manager.context_budget

        for section in sections:
            section_tokens = len(section["content"]) // 4
            if current_tokens + section_tokens > budget:
                remaining = budget - current_tokens
                truncated = section["content"][:remaining * 4]
                if len(truncated) > 100:
                    assembled.append(truncated)
                break
            assembled.append(section["content"])
            current_tokens += section_tokens

        return "\n\n".join(assembled)
```

## 4.8 本章小結

Context Engineering 是 AI 軟體工程中確保模型獲得足夠且相關資訊的關鍵學科。本章從核心挑戰入手，深入探討了以下重點：

- Token 預算管理、資訊過濾、上下文遺忘是三大核心挑戰，每項挑戰都有對應的策略和技術
- 靜態、動態、層級化三種上下文建構策略適用於不同的使用場景
- 摘要壓縮、選擇性包含、滑動窗口等技術幫助在有限的 token 預算內最大化資訊價值
- 向量搜尋、BM25 和 Re-ranking 的組合使用能夠有效提升檢索品質
- 在程式碼上下文管理實務中，相關檔案偵測、依賴圖分析和最近修改優先是最常用的技術
- Context Protocol 和自訂 Context Builder 等工具幫助團隊建立標準化的上下文管理流程
