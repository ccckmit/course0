# 第 7 章：Agentic Engineering

## 什麼是 Agentic Engineering

Agentic Engineering 是設計與建構自主 AI 代理系統的工程學科。一個 AI 代理（Agent）不僅是一個語言模型，而是一個具備感知能力、決策能力、行動能力的自主系統，能夠在給定目標下獨立執行複雜任務。

傳統的 AI 軟體工程著重於「詢問-回答」模式：開發者提出請求，AI 產生回應。這種模式雖然有效，但需要人類全程參與，且無法處理需要連續多步驟推理與行動的任務。Agentic Engineering 將 AI 從被動的助手提升為主動的合作夥伴，能夠自主規劃任務流程、選擇適當工具、執行操作、並從結果中學習調整改變。

代理系統的核心能力包括：

- **自主性**：在沒有人類介入的情況下獨立運作
- **目標導向**：根據高層目標自主分解任務並規劃執行步驟
- **工具使用**：能夠呼叫外部工具和 API 來達成目標
- **適應性**：根據環境回饋調整行為策略
- **記憶與學習**：從經驗中累積知識，改善未來表現

Agentic Engineering 不是單純的提示工程或函數呼叫，而是將這些技術融入系統性的架構設計中，使代理能夠在真實世界的不確定性下可靠運作。這需要整合規劃理論、控制系統、人機互動、軟體架構等多個領域的知識。

## 代理架構設計

一個完整的 AI 代理系統通常包含四個核心元件：Planner（規劃器）、Executor（執行器）、Monitor（監控器）、Reflector（反思器）。這四個元件協同運作，形成代理系統的生命週期。

### Planner（規劃器）

Planner 負責將高層目標分解為可執行的子任務序列。好的規劃器需要考慮任務依賴關係、資源限制、以及最優執行順序：

```python
from enum import Enum
from typing import List, Optional, Callable
from dataclasses import dataclass, field
from datetime import datetime


class TaskStatus(Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    FAILED = "failed"
    BLOCKED = "blocked"


@dataclass
class Task:
    """代理系統中的基本任務單元"""
    id: str
    description: str
    priority: int = 0
    dependencies: List[str] = field(default_factory=list)
    status: TaskStatus = TaskStatus.PENDING
    assigned_tool: Optional[str] = None
    result: Optional[str] = None
    created_at: datetime = field(default_factory=datetime.now)
    completed_at: Optional[datetime] = None


class Planner:
    """任務規劃器：將目標分解為可執行任務序列"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.tasks: List[Task] = []
        self.task_counter = 0

    def plan(self, goal: str, available_tools: List[str],
             context: Optional[str] = None) -> List[Task]:
        """根據目標和可用工具生成任務計畫"""
        self.tasks.clear()

        tools_desc = "\n".join(f"- {t}" for t in available_tools)
        prompt = f"""目標: {goal}

可用工具:
{tools_desc}

請將此目標分解為具體的可執行任務。每個任務應該：
1. 有明確的輸入輸出
2. 依賴關係清晰
3. 能夠使用可用工具完成

輸出格式:
任務1: 描述 | 依賴: 無 | 工具: 工具名稱
任務2: 描述 | 依賴: 任務1 | 工具: 工具名稱
...
"""
        if context:
            prompt = f"上下文:\n{context}\n\n{prompt}"

        response = self.model_api.generate(prompt)
        return self._parse_tasks(response)

    def _parse_tasks(self, response: str) -> List[Task]:
        tasks = []
        for line in response.strip().split("\n"):
            line = line.strip()
            if not line or ":" not in line:
                continue
            try:
                task_part, _, rest = line.partition(":")
                rest = rest.strip()
                task_id = f"task_{self.task_counter}"
                self.task_counter += 1

                description = rest
                dependencies = []
                tool = None

                if "|" in rest:
                    parts = rest.split("|")
                    description = parts[0].strip()
                    for part in parts[1:]:
                        part = part.strip()
                        if part.startswith("依賴"):
                            dep_text = part.split(":")[1].strip()
                            if dep_text != "無":
                                dependencies = [
                                    d.strip() for d in dep_text.split(",")
                                ]
                        elif part.startswith("工具"):
                            tool = part.split(":")[1].strip()

                task = Task(
                    id=task_id,
                    description=description,
                    dependencies=dependencies,
                    assigned_tool=tool,
                    status=TaskStatus.PENDING,
                )
                tasks.append(task)
            except Exception:
                continue

        return tasks

    def get_next_tasks(self) -> List[Task]:
        """取得所有可執行的任務（依賴已滿足）"""
        ready = []
        for task in self.tasks:
            if task.status != TaskStatus.PENDING:
                continue
            deps_met = all(
                any(
                    t.status == TaskStatus.COMPLETED
                    for t in self.tasks if t.id == dep_id
                )
                for dep_id in task.dependencies
            )
            if deps_met:
                ready.append(task)
        return sorted(ready, key=lambda t: t.priority, reverse=True)

    def update_task_status(self, task_id: str, status: TaskStatus,
                           result: Optional[str] = None) -> None:
        """更新任務狀態"""
        for task in self.tasks:
            if task.id == task_id:
                task.status = status
                if result:
                    task.result = result
                if status == TaskStatus.COMPLETED:
                    task.completed_at = datetime.now()
                break
```

### Executor（執行器）

Executor 負責實際執行任務，調用適當的工具完成工作：

```python
class Executor:
    """任務執行器：呼叫工具執行具體任務"""

    def __init__(self, tools: dict):
        self.tools = tools

    def execute(self, task: Task) -> dict:
        """執行單一任務"""
        if task.assigned_tool and task.assigned_tool in self.tools:
            tool_fn = self.tools[task.assigned_tool]
            try:
                result = tool_fn(task.description)
                return {"success": True, "result": result}
            except Exception as e:
                return {"success": False, "error": str(e)}

        return {"success": False, "error": f"工具 {task.assigned_tool} 不可用"}

    def execute_with_llm(self, task: Task, model_api) -> dict:
        """使用 LLM 執行不需要特定工具的任務"""
        prompt = f"""請執行以下任務:

{task.description}

請直接輸出任務結果。"""
        result = model_api.generate(prompt)
        return {"success": True, "result": result}
```

### Monitor（監控器）

Monitor 監控代理的執行狀態，偵測異常並做出對應調整：

```python
class Monitor:
    """系統監控器：追蹤代理狀態與效能"""

    def __init__(self):
        self.execution_log: List[dict] = []
        self.error_count = 0
        self.max_errors = 5
        self.start_time = datetime.now()

    def log_execution(self, task_id: str, tool: str,
                       success: bool, duration: float) -> None:
        """記錄任務執行日誌"""
        entry = {
            "task_id": task_id,
            "tool": tool,
            "success": success,
            "duration": duration,
            "timestamp": datetime.now().isoformat(),
        }
        self.execution_log.append(entry)
        if not success:
            self.error_count += 1

    def detect_loop(self, recent_results: List[str],
                    threshold: int = 3) -> bool:
        """偵測是否陷入重複迴圈"""
        if len(recent_results) < threshold * 2:
            return False
        for i in range(len(recent_results) - threshold):
            window = recent_results[i:i + threshold]
            remaining = recent_results[i + threshold:]
            for j in range(0, len(remaining) - threshold + 1):
                if remaining[j:j + threshold] == window:
                    return True
        return False

    def is_healthy(self) -> bool:
        """檢查系統健康狀態"""
        if self.error_count >= self.max_errors:
            return False
        elapsed = (datetime.now() - self.start_time).total_seconds()
        if elapsed > 3600:
            return False
        return True

    def get_stats(self) -> dict:
        total = len(self.execution_log)
        successes = sum(1 for e in self.execution_log if e["success"])
        avg_duration = (
            sum(e["duration"] for e in self.execution_log) / total
            if total > 0 else 0
        )
        return {
            "total_executions": total,
            "success_rate": successes / total if total > 0 else 1.0,
            "avg_duration": avg_duration,
            "error_count": self.error_count,
            "healthy": self.is_healthy(),
        }
```

### Reflector（反思器）

Reflector 分析執行結果，提取經驗教訓，並改善未來表現：

```python
class Reflector:
    """反思器：從執行經驗中學習與改善"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.lessons: List[str] = []
        self.failure_patterns: List[dict] = []

    def reflect(self, task: Task, execution_result: dict) -> Optional[str]:
        """對單一任務執行結果進行反思"""
        if execution_result.get("success"):
            return None

        prompt = f"""
任務: {task.description}
工具: {task.assigned_tool}
錯誤: {execution_result.get('error', '未知錯誤')}

請分析失敗原因，並給出具體改善建議（50 字內）。
"""
        lesson = self.model_api.generate(prompt).strip()
        self.lessons.append(lesson)

        self.failure_patterns.append({
            "task": task.description,
            "tool": task.assigned_tool,
            "error": execution_result.get("error"),
            "lesson": lesson,
        })

        return lesson

    def generate_improvement_plan(self) -> str:
        """基於所有經驗生成改善計畫"""
        if not self.failure_patterns:
            return "無需改善"

        patterns_text = "\n".join(
            f"- 失敗: {p['error']} -> 教訓: {p['lesson']}"
            for p in self.failure_patterns[-10:]
        )

        prompt = f"""
分析以下失敗模式，提出系統性的改善方案：

{patterns_text}

請從以下面向分別給出建議：
1. 工具使用方式
2. 任務分解策略
3. 錯誤處理機制
"""
        return self.model_api.generate(prompt)

    def adapt_prompt(self, base_prompt: str,
                     task_description: str) -> str:
        """根據過往經驗調整提示"""
        if not self.lessons:
            return base_prompt

        recent_lessons = "\n".join(
            f"- {l}" for l in self.lessons[-3:]
        )
        return f"{base_prompt}\n\n注意事項（根據過往經驗）:\n{recent_lessons}"
```

### 完整的代理架構整合

將上述四個元件整合為完整的代理系統：

```python
class Agent:
    """整合式 AI 代理"""

    def __init__(self, model_api, tools: dict, name: str = "Agent"):
        self.name = name
        self.planner = Planner(model_api)
        self.executor = Executor(tools)
        self.monitor = Monitor()
        self.reflector = Reflector(model_api)
        self.model_api = model_api
        self.max_iterations = 20

    def run(self, goal: str) -> dict:
        """執行代理任務"""
        print(f"[{self.name}] 開始執行目標: {goal}")

        available_tools = list(self.executor.tools.keys())
        tasks = self.planner.plan(goal, available_tools)
        print(f"[{self.name}] 規劃完成: {len(tasks)} 個任務")

        iteration = 0
        recent_results = []

        while iteration < self.max_iterations and self.monitor.is_healthy():
            iteration += 1
            next_tasks = self.planner.get_next_tasks()

            if not next_tasks:
                remaining = [t for t in tasks if t.status == TaskStatus.PENDING]
                if not remaining:
                    print(f"[{self.name}] 所有任務已完成")
                    break
                failed = [t for t in tasks if t.status == TaskStatus.FAILED]
                if len(failed) == len(remaining):
                    print(f"[{self.name}] 所有剩餘任務已失敗，中止")
                    break
                continue

            for task in next_tasks:
                print(f"[{self.name}] 執行任務: {task.description}")

                if task.assigned_tool and task.assigned_tool in self.executor.tools:
                    result = self.executor.execute(task)
                else:
                    result = self.executor.execute_with_llm(task, self.model_api)

                duration = 0.1
                self.monitor.log_execution(
                    task.id, task.assigned_tool or "llm",
                    result["success"], duration
                )

                if result["success"]:
                    self.planner.update_task_status(
                        task.id, TaskStatus.COMPLETED, result.get("result")
                    )
                    recent_results.append("success")
                else:
                    lesson = self.reflector.reflect(task, result)
                    self.planner.update_task_status(
                        task.id, TaskStatus.FAILED,
                        result.get("error")
                    )
                    recent_results.append("failure")
                    print(f"[{self.name}] 任務失敗: {result.get('error')}")

                if self.monitor.detect_loop(recent_results):
                    print(f"[{self.name}] 偵測到重複迴圈，重新規劃")
                    replan_result = self._replan(tasks)
                    if replan_result:
                        tasks = replan_result
                    recent_results.clear()
                    break

        improvement_plan = self.reflector.generate_improvement_plan()

        return {
            "goal": goal,
            "tasks_completed": sum(
                1 for t in tasks if t.status == TaskStatus.COMPLETED
            ),
            "tasks_total": len(tasks),
            "stats": self.monitor.get_stats(),
            "improvement_plan": improvement_plan,
        }

    def _replan(self, old_tasks: List[Task]) -> Optional[List[Task]]:
        completed = [
            t for t in old_tasks if t.status == TaskStatus.COMPLETED
        ]
        context = "\n".join(
            f"- [{t.status.value}] {t.description}: {t.result}"
            for t in completed
        )
        available_tools = list(self.executor.tools.keys())
        return self.planner.plan(
            "繼續未完成的目標", available_tools, context
        )
```

## ReAct 模式

ReAct（Reasoning + Acting）是一種將推理與行動整合的代理模式，由 Shunyu Yao 等人於 2022 年提出。其核心思想是讓模型在思考（Thought）與行動（Action）之間交替進行，並觀察（Observation）行動結果來指導下一步推理。

### Thought-Action-Observation 循環

ReAct 循環包含三個階段，形成持續的推理-行動迴路：

```python
class ReActAgent:
    """ReAct 模式代理實作"""

    def __init__(self, model_api, tools: dict):
        self.model_api = model_api
        self.tools = tools
        self.max_steps = 15

    def run(self, task: str) -> str:
        """執行 ReAct 循環"""
        prompt = self._build_initial_prompt(task)
        full_response = ""

        for step in range(self.max_steps):
            response = self.model_api.generate(prompt)
            full_response += response

            thought = self._extract_section(response, "Thought")
            action = self._extract_section(response, "Action")
            action_input = self._extract_section(response, "Action Input")

            if not action or action.strip() == "Final Answer":
                final_answer = self._extract_section(
                    response, "Final Answer"
                )
                if final_answer:
                    return final_answer
                return response

            observation = self._execute_action(action, action_input)
            prompt += f"\nObservation: {observation}"
            prompt += "\nThought: "

        return "已達最大步驟數，任務未完成"

    def _build_initial_prompt(self, task: str) -> str:
        tools_desc = "\n".join(
            f"- {name}: {desc.__doc__ or '無描述'}"
            for name, desc in self.tools.items()
        )
        return f"""你是一個可以思考與行動的代理。請使用以下工具完成任務：

{tools_desc}

請始終遵循以下格式：
Thought: 你當前的思考和推理
Action: 要使用的工具名稱（或 "Final Answer"）
Action Input: 提供給工具的輸入

範例：
Thought: 我需要先讀取檔案內容
Action: read_file
Action Input: /path/to/file.txt
Observation: [工具回傳的結果]
Thought: 現在我了解內容了...

任務: {task}

Thought: """

    def _extract_section(self, text: str, section: str) -> str:
        import re
        patterns = [
            rf"{section}:\s*(.+?)(?=\n(?:Thought|Action|Observation|$))",
            rf"{section}:\s*(.+)",
        ]
        for pattern in patterns:
            match = re.search(pattern, text, re.DOTALL)
            if match:
                return match.group(1).strip()
        return ""

    def _execute_action(self, action: str, action_input: str) -> str:
        if action not in self.tools:
            return f"錯誤: 工具 '{action}' 不存在。可用工具: {list(self.tools.keys())}"
        try:
            result = self.tools[action](action_input)
            return str(result)
        except Exception as e:
            return f"執行錯誤: {e}"
```

### 工具呼叫設計與實現

工具呼叫是 ReAct 模式的關鍵基礎。代理需要能夠精確地描述要呼叫的工具及其參數：

```python
import json
from typing import Any, Optional
from dataclasses import dataclass, field


@dataclass
class ToolParameter:
    name: str
    type: str
    description: str
    required: bool = True
    default: Optional[Any] = None


@dataclass
class ToolSpec:
    name: str
    description: str
    parameters: List[ToolParameter] = field(default_factory=list)
    fn: Optional[Callable] = None


class ToolRegistry:
    """工具註冊與管理"""

    def __init__(self):
        self.tools: dict[str, ToolSpec] = {}

    def register(self, spec: ToolSpec) -> None:
        self.tools[spec.name] = spec

    def register_function(self, name: str, description: str,
                           fn: Callable, **params) -> None:
        parameters = [
            ToolParameter(name=k, type=v.get("type", "string"),
                          description=v.get("description", ""),
                          required=v.get("required", True))
            for k, v in params.items()
        ]
        self.tools[name] = ToolSpec(
            name=name, description=description,
            parameters=parameters, fn=fn
        )

    def call(self, name: str, arguments: dict) -> Any:
        spec = self.tools.get(name)
        if not spec:
            raise ValueError(f"工具 '{name}' 未註冊")
        if spec.fn is None:
            raise ValueError(f"工具 '{name}' 未設定可呼叫的函數")
        return spec.fn(**arguments)

    def to_openai_format(self) -> List[dict]:
        """轉換為 OpenAI 函數呼叫格式"""
        tools = []
        for spec in self.tools.values():
            tool_def = {
                "type": "function",
                "function": {
                    "name": spec.name,
                    "description": spec.description,
                    "parameters": {
                        "type": "object",
                        "properties": {},
                        "required": [],
                    },
                },
            }
            for param in spec.parameters:
                tool_def["function"]["parameters"]["properties"][param.name] = {
                    "type": param.type,
                    "description": param.description,
                }
                if param.required:
                    tool_def["function"]["parameters"]["required"].append(
                        param.name
                    )
            tools.append(tool_def)
        return tools

    def list_tools(self) -> str:
        lines = []
        for spec in self.tools.values():
            params = ", ".join(
                f"{p.name}: {p.type}" for p in spec.parameters
            )
            lines.append(f"- {spec.name}({params}): {spec.description}")
        return "\n".join(lines)


# 使用範例
registry = ToolRegistry()


def read_file(filepath: str) -> str:
    """讀取檔案內容"""
    with open(filepath, "r", encoding="utf-8") as f:
        return f.read()


def write_file(filepath: str, content: str) -> str:
    """寫入檔案"""
    with open(filepath, "w", encoding="utf-8") as f:
        f.write(content)
    return f"已寫入 {len(content)} 字元到 {filepath}"


registry.register_function(
    "read_file", "讀取指定檔案的路徑",
    read_file,
    filepath={"type": "string", "description": "檔案路徑"}
)
registry.register_function(
    "write_file", "將內容寫入指定檔案",
    write_file,
    filepath={"type": "string", "description": "檔案路徑"},
    content={"type": "string", "description": "要寫入的內容"}
)
```

## 工具使用設計

工具是代理與外部世界互動的橋樑。良好的工具設計對代理系統的成功至關重要。

### 工具定義規範

每個工具都應該有清晰的名稱、描述和參數規格，使模型能夠正確理解和使用：

```python
from abc import ABC, abstractmethod


class BaseTool(ABC):
    """工具基礎類別"""

    @property
    @abstractmethod
    def name(self) -> str:
        pass

    @property
    @abstractmethod
    def description(self) -> str:
        pass

    @abstractmethod
    def run(self, **kwargs) -> str:
        pass

    def to_tool_spec(self) -> dict:
        return {
            "name": self.name,
            "description": self.description,
        }


class FileSystemTool(BaseTool):
    """檔案系統操作工具"""

    @property
    def name(self) -> str:
        return "filesystem"

    @property
    def description(self) -> str:
        return """對檔案系統進行讀寫操作。
支援的操作: read (讀取), write (寫入), list (列出目錄), delete (刪除)
範例: {{"operation": "read", "path": "/path/to/file.txt"}}
範例: {{"operation": "list", "path": "/path/to/directory"}}
"""

    def run(self, operation: str, path: str, content: str = None) -> str:
        try:
            if operation == "read":
                with open(path, "r", encoding="utf-8") as f:
                    return f.read()
            elif operation == "write":
                with open(path, "w", encoding="utf-8") as f:
                    f.write(content or "")
                return f"已寫入 {path}"
            elif operation == "list":
                import os
                entries = os.listdir(path)
                return "\n".join(entries)
            elif operation == "delete":
                import os
                os.remove(path)
                return f"已刪除 {path}"
            else:
                return f"不支援的操作: {operation}"
        except Exception as e:
            return f"檔案系統錯誤: {e}"
```

```python
                     assigned_to: str) -> dict:

            return {"error": f"代理 {assigned_to} 不存在"}

        self.conversation_history.append({
            "from": "system",
            "to": assigned_to,
            "task": task,
        })

        result = agent.run(task)

        self.conversation_history.append({
            "from": assigned_to,
            "to": "system",
            "result": result,
        })

        return result

    def collaborative_execution(self, task: str,
                                  workflow: List[dict]) -> dict:

        results = {}
        for step in workflow:
            agent_name = step["agent"]
            description = step["description"]

                step_task = f"{description}\n\n前一步結果:\n{results[input_data]}"
            else:
                step_task = description

            step_task = f"原始任務: {task}\n\n{step_task}"
            result = self.assign_task(step_task, agent_name)
            results[agent_name] = result

        return results

    def review_chain(self, code: str) -> dict:

        workflow = [

             f"請實作以下程式碼:\n```python\n{code}\n```"},

             "請為上述程式碼撰寫完整的單元測試",

             "請審查上述程式碼的安全性",
```

```python
class TaskCoordinator:
    """任務協調器：分配任務給最適合的代理"""

    def __init__(self, team: AgentTeam):
        self.team = team
        self.task_queue = deque()
        self.agent_load = {name: 0 for name in team.members}
        self.max_load_per_agent = 3

    def dispatch(self, task: str, required_skills: List[str]) -> str:
        """根據技能需求和負載分配任務"""
        candidates = []
        for name, agent in self.team.members.items():
            if agent.specialty in required_skills:
                if self.agent_load[name] < self.max_load_per_agent:
                    candidates.append((name, self.agent_load[name]))

        if not candidates:
            return "所有符合條件的代理都在忙碌中"

        candidates.sort(key=lambda x: x[1])
        chosen = candidates[0][0]
        self.agent_load[chosen] += 1

        self.team.assign_task(task, chosen)
        return f"任務已分配給 {chosen}"

    def complete_task(self, agent_name: str):
        self.agent_load[agent_name] = max(
            0, self.agent_load[agent_name] - 1
        )
```

## 記憶與狀態管理

### 短期記憶與長期記憶

代理需要不同層次的記憶來維持對話連貫性和積累知識：

```python
from collections import deque
import json
import numpy as np
from typing import Optional


class ShortTermMemory:
    """短期記憶：維護當前工作階段的上下文"""

    def __init__(self, max_tokens: int = 4000):
        self.messages: deque = deque()
        self.max_tokens = max_tokens
        self.current_tokens = 0

    def add(self, role: str, content: str) -> None:
        """添加訊息並管理 Token 預算"""
        estimated_tokens = len(content) // 2
        self.messages.append({"role": role, "content": content})
        self.current_tokens += estimated_tokens

        while self.current_tokens > self.max_tokens and self.messages:
            removed = self.messages.popleft()
            removed_tokens = len(removed["content"]) // 2
            self.current_tokens -= removed_tokens

    def get_context(self) -> List[dict]:
        return list(self.messages)

    def summarize(self, model_api) -> str:
        """將短期記憶摘要化"""
        if not self.messages:
            return ""
        full_text = "\n".join(
            f"{m['role']}: {m['content']}" for m in self.messages
        )
        prompt = f"""請將以下對話記錄摘要為一段簡短的文字，保留重要資訊：

{full_text}

摘要："""
        return model_api.generate(prompt)


class LongTermMemory:
    """長期記憶：使用向量資料庫儲存與檢索"""

    def __init__(self, embedding_fn: Callable):
        self.embedding_fn = embedding_fn
        self.memories: List[dict] = []
        self.embeddings: List[np.ndarray] = []

    def store(self, key: str, content: str,
               metadata: Optional[dict] = None) -> None:
        """儲存記憶"""
        embedding = self.embedding_fn(content)
        self.memories.append({
            "key": key,
            "content": content,
            "metadata": metadata or {},
            "timestamp": datetime.now().isoformat(),
        })
        self.embeddings.append(embedding)

    def search(self, query: str, top_k: int = 5) -> List[dict]:
        """語意搜尋相關記憶"""
        if not self.memories:
            return []

        query_embedding = self.embedding_fn(query)

        similarities = [
            self._cosine_similarity(query_embedding, emb)
            for emb in self.embeddings
        ]
        top_indices = np.argsort(similarities)[-top_k:][::-1]

        results = []
        for idx in top_indices:
            if similarities[idx] > 0.5:
                results.append({
                    **self.memories[idx],
                    "similarity": float(similarities[idx]),
                })
        return results

    def _cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float:
        if np.linalg.norm(a) == 0 or np.linalg.norm(b) == 0:
            return 0
        return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

    def forget(self, key: str) -> None:
        """刪除特定記憶"""
        for i, mem in enumerate(self.memories):
            if mem["key"] == key:
                self.memories.pop(i)
                self.embeddings.pop(i)
                break

    def get_stats(self) -> dict:
        return {
            "total_memories": len(self.memories),
            "oldest": self.memories[0]["timestamp"] if self.memories else None,
            "newest": self.memories[-1]["timestamp"] if self.memories else None,
        }


class MemoryManager:
    """整合短期與長期記憶的管理器"""

    def __init__(self, embedding_fn: Callable,
                 stm_max_tokens: int = 4000):
        self.stm = ShortTermMemory(stm_max_tokens)
        self.ltm = LongTermMemory(embedding_fn)
        self.session_id = datetime.now().isoformat()

    def add_interaction(self, role: str, content: str) -> None:
        self.stm.add(role, content)

    def save_important(self, key: str, content: str,
                        metadata: Optional[dict] = None) -> None:
        self.ltm.store(key, content, metadata)

    def get_relevant_context(self, query: str) -> str:
        """建構當前對話的相關上下文"""
        stm_context = self.stm.get_context()
        ltm_results = self.ltm.search(query)

        context_parts = ["當前對話："]
        for msg in stm_context[-6:]:
            context_parts.append(f"{msg['role']}: {msg['content'][:200]}")

        if ltm_results:
            context_parts.append("\n相關歷史記憶：")
            for mem in ltm_results[:3]:
                context_parts.append(f"- {mem['content'][:200]}")

        return "\n".join(context_parts)
```

### 工作階段管理

管理代理的工作階段狀態，支援暫停、恢復和並發控制：

```python
import uuid
import pickle


class Session:
    """代理工作階段"""

    def __init__(self, agent_config: dict):
        self.session_id = str(uuid.uuid4())
        self.agent_config = agent_config
        self.memory: Optional[MemoryManager] = None
        self.status = "created"
        self.created_at = datetime.now()
        self.last_active = datetime.now()
        self.context: dict = {}

    def serialize(self) -> bytes:
        return pickle.dumps({
            "session_id": self.session_id,
            "agent_config": self.agent_config,
            "status": self.status,
            "context": self.context,
        })

    @classmethod
    def deserialize(cls, data: bytes) -> "Session":
        obj = pickle.loads(data)
        session = cls(obj["agent_config"])
        session.session_id = obj["session_id"]
        session.status = obj["status"]
        session.context = obj["context"]
        return session


class SessionManager:
    """工作階段管理器"""

    def __init__(self, storage_dir: str = "/tmp/agent_sessions"):
        self.sessions: dict[str, Session] = {}
        self.storage_dir = storage_dir
        import os
        os.makedirs(storage_dir, exist_ok=True)

    def create_session(self, agent_config: dict) -> str:
        session = Session(agent_config)
        self.sessions[session.session_id] = session
        return session.session_id

    def get_session(self, session_id: str) -> Optional[Session]:
        session = self.sessions.get(session_id)
        if session:
            session.last_active = datetime.now()
        return session

    def pause_session(self, session_id: str) -> bool:
        session = self.get_session(session_id)
        if not session:
            return False
        session.status = "paused"
        self._save_to_disk(session)
        return True

    def resume_session(self, session_id: str) -> Optional[Session]:
        session = self.sessions.get(session_id)
        if session and session.status == "paused":
            session.status = "active"
            return session
        session = self._load_from_disk(session_id)
        if session:
            session.status = "active"
            self.sessions[session_id] = session
        return session

    def end_session(self, session_id: str) -> None:
        if session_id in self.sessions:
            session = self.sessions.pop(session_id)
            session.status = "ended"
            self._save_to_disk(session)

    def _save_to_disk(self, session: Session) -> None:
        path = f"{self.storage_dir}/{session.session_id}.pkl"
        with open(path, "wb") as f:
            f.write(session.serialize())

    def _load_from_disk(self, session_id: str) -> Optional[Session]:
        path = f"{self.storage_dir}/{session_id}.pkl"
        try:
            with open(path, "rb") as f:
                return Session.deserialize(f.read())
        except (FileNotFoundError, pickle.UnpicklingError):
            return None
```

## 自主程式設計代理

### SWE-agent、Devin、OpenCode

自主程式設計代理是 Agentic Engineering 在軟體開發領域最重要的應用。這些系統能夠自主完成程式碼編寫、除錯、測試和部署等開發任務。

**SWE-agent** 是由普林斯頓大學開發的開源框架，專注於自主解決 GitHub Issue。其架構包含一個 Agent-Computer Interface（ACI），定義了代理可以使用的命令集合，包括檔案瀏覽、編輯、搜尋、執行測試等。SWE-agent 在 SWE-bench 基準測試中展示了顯著的能力，能夠自主修復大量真實世界的程式碼錯誤。

**Devin** 是由 Cognition Labs 開發的商業自主程式設計代理，整合了開發者環境中的所有工具：終端機、程式碼編輯器、瀏覽器、資料庫客戶端等。Devin 的特色在於其長週期規劃能力和全面的環境控制能力，能夠處理需要數小時甚至數天完成的複雜開發任務。

**OpenCode** 是命令列介面的 AI 軟體工程助理，強調與開發者工作流程的深度整合。與完全自主的代理不同，OpenCode 採用協作模式，在關鍵決策點尋求開發者確認，同時在常規任務上保持高效自動化。

這些系統的共同特點是將 LLM 的語言理解與程式碼生成能力與傳統開發工具進行深度整合，使 AI 不僅能「說」程式碼，更能實際操作開發環境。

### 自主除錯代理實作

以下是一個簡化的自主除錯代理實作，展示如何利用 ReAct 模式和工具使用來定位並修復程式碼問題：

```python
class DebugAgent:
    """自主除錯代理"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.tools = {
            "read_file": self._read_file,
            "search_code": self._search_code,
            "run_test": self._run_test,
            "get_error_trace": self._get_error_trace,
            "edit_file": self._edit_file,
        }
        self.workspace = tempfile.mkdtemp()

    def debug(self, error_description: str,
              project_path: str) -> dict:
        """執行自主除錯流程"""
        prompt = self._build_debug_prompt(error_description, project_path)
        steps = []
        max_cycles = 10

        for cycle in range(max_cycles):
            response = self.model_api.generate(prompt)

            action = self._parse_action(response)
            if not action:
                break

            result = self._execute_action(action)
            steps.append({
                "cycle": cycle + 1,
                "thought": self._parse_thought(response),
                "action": action["name"],
                "action_input": action["input"],
                "observation": result,
            })

            prompt += f"\nObservation: {result}\nThought: "

            if action["name"] == "final_answer":
                return {
                    "success": True,
                    "solution": action["input"],
                    "steps": steps,
                }

        return {
            "success": False,
            "message": "除錯過程未能在最大循環次數內完成",
            "steps": steps,
        }

    def _build_debug_prompt(self, error: str, path: str) -> str:
        return f"""你是一位除錯專家。請分析以下錯誤並修復它。

錯誤描述: {error}
專案路徑: {path}

可用工具:
- read_file(path): 讀取檔案
- search_code(pattern): 在專案中搜尋程式碼
- run_test(test_path): 執行測試
- get_error_trace(): 獲取錯誤堆疊
- edit_file(path, old, new): 編輯檔案（字串取代）

請按以下格式回應:
Thought: 你的分析...
Action: 工具名稱
Action Input: 工具參數

在確定修復方案後:
Action: final_answer
Action Input: 修復說明

Thought: 讓我先了解錯誤的上下文"""

    def _parse_action(self, response: str) -> Optional[dict]:
        import re
        action_match = re.search(r"Action:\s*(.+?)\n", response)
        input_match = re.search(r"Action Input:\s*(.+)", response, re.DOTALL)
        if not action_match:
            return None
        return {
            "name": action_match.group(1).strip(),
            "input": input_match.group(1).strip() if input_match else "",
        }

    def _parse_thought(self, response: str) -> str:
        import re
        match = re.search(r"Thought:\s*(.+?)(?=\nAction)", response, re.DOTALL)
        return match.group(1).strip() if match else ""

    def _execute_action(self, action: dict) -> str:
        tool = self.tools.get(action["name"])
        if not tool:
            return f"錯誤: 未知工具 {action['name']}"
        try:
            return tool(action["input"])
        except Exception as e:
            return f"工具執行錯誤: {e}"

    def _read_file(self, path: str) -> str:
        with open(path, "r", encoding="utf-8") as f:
            return f.read()[:3000]

    def _search_code(self, pattern: str) -> str:
        result = subprocess.run(
            ["grep", "-rn", pattern, self.workspace],
            capture_output=True, text=True, timeout=10
        )
        return result.stdout[:2000] or "無匹配結果"

    def _run_test(self, test_path: str) -> str:
        result = subprocess.run(
            ["pytest", test_path, "-v", "--tb=short"],
            capture_output=True, text=True, timeout=30,
            cwd=self.workspace
        )
        return (result.stdout + "\n" + result.stderr)[:2000]

    def _get_error_trace(self) -> str:
        return "錯誤追蹤功能需要在除錯環境中執行"

    def _edit_file(self, input_str: str) -> str:
        try:
            params = json.loads(input_str)
            path = params["path"]
            old = params["old"]
            new = params["new"]

            with open(path, "r", encoding="utf-8") as f:
                content = f.read()

            if old not in content:
                return f"錯誤: 找不到要取代的文字"

            content = content.replace(old, new, 1)
            with open(path, "w", encoding="utf-8") as f:
                f.write(content)
            return f"已修改 {path}"
        except json.JSONDecodeError:
            return "JSON 解析錯誤，需要 path, old, new 參數"
        except Exception as e:
            return f"編輯錯誤: {e}"
```

```python
class LangChainStyleAgent:
    """以 LangChain 風格實作的代理"""

    def __init__(self, llm, tools: List[BaseTool],
                 system_prompt: str = ""):
        self.llm = llm
        self.tools = {t.name: t for t in tools}
        self.system_prompt = system_prompt
        self.memory = []

    def add_tool(self, tool: BaseTool) -> None:
        self.tools[tool.name] = tool

    def invoke(self, input_text: str) -> str:
        """處理使用者輸入"""
        context = self._build_context(input_text)
        response = self.llm.generate(context)

        action = self._parse_tool_call(response)
        if action:
            result = self.tools[action["name"]].run(**action["args"])
            self.memory.append({
                "input": input_text,
                "action": action,
                "result": result,
            })
            return f"工具 {action['name']} 執行完成: {result[:100]}..."

        return response

    def _build_context(self, input_text: str) -> str:
        tool_descriptions = "\n".join(
            f"{t.name}: {t.description}" for t in self.tools.values()
        )
        memory_context = "\n".join(
            m["input"] for m in self.memory[-3:]
        )
        return f"""{self.system_prompt}

可用工具:
{tool_descriptions}

對話歷史:
{memory_context}

使用者: {input_text}
助手: """

    def _parse_tool_call(self, text: str) -> Optional[dict]:
        import re
        match = re.search(
            r"<tool_call>\s*\{\"name\":\s*\"(.+?)\",\s*\"args\":\s*(\{.+?\})\s*\}",
            text
        )
        if match:
            return {
                "name": match.group(1),
                "args": json.loads(match.group(2)),
            }
        return None


# LangGraph 風格的圖形化工作流
# LangGraph 將代理任務表示為有向圖，節點是處理步驟，邊是狀態轉換


class GraphNode:
    """LangGraph 風格的流程圖節點"""

    def __init__(self, name: str, process_fn: Callable):
        self.name = name
        self.process = process_fn
        self.edges: List[tuple[str, Callable]] = []

    def add_edge(self, next_node: str,
                  condition_fn: Callable = None) -> None:
        self.edges.append((next_node, condition_fn))

    def execute(self, state: dict) -> tuple[str, dict]:
        result = self.process(state)
        for next_node, condition in self.edges:
            if condition is None or condition(result):
                return next_node, result
        return "END", result


class GraphWorkflow:
    """圖形化工作流程引擎"""

    def __init__(self):
        self.nodes: dict[str, GraphNode] = {}
        self.entry_point: Optional[str] = None

    def add_node(self, node: GraphNode) -> None:
        self.nodes[node.name] = node
        if self.entry_point is None:
            self.entry_point = node.name

    def run(self, initial_state: dict) -> dict:
        current = self.entry_point
        state = initial_state.copy()

        while current != "END":
            node = self.nodes.get(current)
            if not node:
                break
            current, state = node.execute(state)

        return state
```

### AutoGPT

AutoGPT 是最早的自主 AI 代理系統之一，以其長週期自主運作能力聞名：

```python
class AutoGPTStyleAgent:
    """AutoGPT 風格的自主代理"""

    def __init__(self, model_api, name: str,
                 goals: List[str], tools: List[BaseTool]):
        self.model_api = model_api
        self.name = name
        self.goals = goals
        self.tools = {t.name: t for t in tools}
        self.memory = []
        self.task_list: List[dict] = []
        self.max_iterations = 25

    def run(self) -> dict:
        """啟動自主執行循環"""
        self._create_initial_tasks()

        for iteration in range(self.max_iterations):
            current_task = self._get_next_task()
            if not current_task:
                print("所有任務已完成")
                break

            print(f"Iteration {iteration + 1}: {current_task['name']}")
            result = self._execute_task(current_task)
            self._add_to_memory(current_task, result)

            new_tasks = self._generate_new_tasks(result)
            self._prioritize_tasks()

            if self._should_stop(result):
                break

        return {
            "status": "completed",
            "tasks_completed": len(self.memory),
            "final_state": self._summarize_results(),
        }

    def _create_initial_tasks(self) -> None:
        prompt = f"""根據以下目標，建立初始任務清單：

目標:
{chr(10).join(f'- {g}' for g in self.goals)}

請列出 3-5 個具體任務來達成這些目標。
每個任務包含名稱和描述。"""
        response = self.model_api.generate(prompt)
        self.task_list = self._parse_tasks(response)

    def _get_next_task(self) -> Optional[dict]:
        if not self.task_list:
            return None
        return self.task_list.pop(0)

    def _execute_task(self, task: dict) -> str:
        prompt = f"""當前任務: {task['name']}
描述: {task['description']}

請執行此任務並回報結果。
可用工具: {', '.join(self.tools.keys())}"""
        return self.model_api.generate(prompt)

    def _generate_new_tasks(self, result: str) -> None:
        prompt = f"""根據以下執行結果，產生新的子任務（如果需要）：

{result}

現有任務清單: {[t['name'] for t in self.task_list]}

請輸出新的任務，或「無新任務」。
"""
        response = self.model_api.generate(prompt)
        if "無新任務" not in response:
            new_tasks = self._parse_tasks(response)
            self.task_list.extend(new_tasks)

    def _prioritize_tasks(self) -> None:
        if not self.task_list:
            return
        prompt = f"""請根據優先級重新排序以下任務：

{chr(10).join(f'{i+1}. {t["name"]}: {t["description"]}' for i, t in enumerate(self.task_list))}

輸出重新排序後的任務編號（用逗號分隔）。"""
        response = self.model_api.generate(prompt)
        import re
        numbers = re.findall(r"\d+", response)
        prioritized = []
        for n in numbers:
            idx = int(n) - 1
            if 0 <= idx < len(self.task_list):
                prioritized.append(self.task_list[idx])
        if prioritized:
            self.task_list = prioritized

    def _should_stop(self, result: str) -> bool:
        prompt = f"""目標: {self.goals}
最新結果: {result[:200]}

是否已達成所有目標？回答 YES 或 NO。"""
        response = self.model_api.generate(prompt)
        return "YES" in response

    def _add_to_memory(self, task: dict, result: str) -> None:
        self.memory.append({
            "task": task,
            "result": result[:500],
        })

    def _summarize_results(self) -> str:
        summary = "\n".join(
            f"- {m['task']['name']}: {m['result'][:100]}"
            for m in self.memory
        )
        return f"執行了 {len(self.memory)} 個任務:\n{summary}"

    def _parse_tasks(self, text: str) -> List[dict]:
        tasks = []
        for line in text.split("\n"):
            line = line.strip()
            if line.startswith("-") or (line[0].isdigit() and "." in line[:3]):
                content = line.lstrip("- ").lstrip("0123456789. ")
                if ":" in content:
                    name, _, desc = content.partition(":")
                    tasks.append({
                        "name": name.strip(),
                        "description": desc.strip(),
                    })
                else:
                    tasks.append({"name": content, "description": content})
        return tasks
```

## 代理系統的挑戰

### 可靠性與錯誤累積

代理系統面臨的最大挑戰是錯誤累積。在一個多步驟的推理鏈中，早期的小錯誤會在後續步驟中被放大，最終導致任務失敗。緩解策略包括：

1. **檢查點與回滾**：在關鍵步驟建立檢查點，失敗時回滾到已知的良好狀態
2. **多路徑驗證**：對同一個任務執行多個方案，投票選出最佳結果
3. **漸進式確認**：每一步執行後都要求「合理性檢查」，確認結果在預期範圍內
4. **人類閘道**：在高風險決策點要求人類確認

```python
class ReliabilityEnhancer:
    """代理可靠性增強器"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.checkpoints: List[dict] = []

    def validate_step(self, step_description: str,
                       step_result: str) -> bool:
        """驗證單一步驟的結果是否合理"""
        prompt = f"""步驟: {step_description}
結果: {step_result[:500]}

請判斷此結果是否合理。考慮：
1. 是否有明顯錯誤
2. 格式是否正確
3. 是否符合預期範圍

回答 VALID 或 INVALID。"""
        response = self.model_api.generate(prompt)
        return "VALID" in response

    def create_checkpoint(self, state: dict) -> str:
        checkpoint_id = f"cp_{len(self.checkpoints)}"
        self.checkpoints.append({
            "id": checkpoint_id,
            "state": state,
            "timestamp": datetime.now().isoformat(),
        })
        return checkpoint_id

    def rollback(self, checkpoint_id: str) -> Optional[dict]:
        for cp in self.checkpoints:
            if cp["id"] == checkpoint_id:
                return cp["state"]
        return None
```

### 成本控制

代理系統的 token 消耗遠高於傳統的單輪生成。一個自主除錯任務可能消耗數萬甚至數十萬 token。有效的成本控制策略包括：

```python
class CostController:
    """代理成本控制器"""

    def __init__(self, token_budget: int = 50000,
                 cost_per_token: float = 0.00001):
        self.token_budget = token_budget
        self.cost_per_token = cost_per_token
        self.total_tokens = 0
        self.step_costs: List[dict] = []

    def check_budget(self, estimated_tokens: int) -> bool:
        """檢查是否有足夠預算執行下一步"""
        remaining = self.token_budget - self.total_tokens
        if estimated_tokens > remaining:
            return False
        return True

    def record_usage(self, step: str, tokens: int) -> dict:
        """記錄 token 使用"""
        self.total_tokens += tokens
        cost = tokens * self.cost_per_token
        entry = {
            "step": step,
            "tokens": tokens,
            "cost": cost,
            "remaining_budget": self.token_budget - self.total_tokens,
        }
        self.step_costs.append(entry)
        return entry

    def get_total_cost(self) -> float:
        return self.total_tokens * self.cost_per_token

    def should_continue(self) -> bool:
        if self.total_tokens >= self.token_budget:
            return False
        recent_window = sum(
            s["tokens"] for s in self.step_costs[-3:]
        )
        if recent_window > self.token_budget * 0.3:
            return False
        return True

    def optimize_prompt(self, prompt: str) -> str:
        """透過摘要化來減少提示長度"""
        if len(prompt) > 2000:
            lines = prompt.split("\n")
            if len(lines) > 50:
                lines = lines[:30] + ["... (略過中間行) ..."] + lines[-15:]
                return "\n".join(lines)
        return prompt
```

### 安全性與權限

代理系統的自主行動能力帶來了新的安全挑戰：

```python
class SecurityManager:
    """代理系統安全管理器"""

    DANGEROUS_PATTERNS = [
        r"rm\s+-rf\s+/",
        r"DROP\s+TABLE",
        r"DELETE\s+FROM.*WHERE\s+1=1",
        r"TRUNCATE\s+TABLE",
        r">\s*/dev/sda",
        r"mkfs\.",
        r"chmod\s+777",
        r"sudo\s+rm",
        r":\(\)\{\s*:\s*\|:\s*&\s*\};",
    ]

    def __init__(self):
        self.permissions: dict = {
            "filesystem": {"read": True, "write": True, "delete": False},
            "network": {"outbound": True, "inbound": False},
            "command": {"allowed": [], "denied": ["rm", "sudo", "chmod"]},
        }

    def check_command(self, command: str) -> bool:
        """檢查命令是否安全"""
        import re
        for pattern in self.DANGEROUS_PATTERNS:
            if re.search(pattern, command):
                return False
        for denied in self.permissions["command"]["denied"]:
            if command.strip().startswith(denied):
                return False
        return True

    def check_file_access(self, path: str, mode: str = "read") -> bool:
        """檢查檔案存取權限"""
        import os
        real_path = os.path.realpath(path)

        protected_dirs = ["/etc", "/sys", "/proc", "/boot"]
        for d in protected_dirs:
            if real_path.startswith(d):
                return False

        if mode == "delete" and not self.permissions["filesystem"]["delete"]:
            return False

        return True

    def sanitize_tool_input(self, tool_name: str,
                             input_data: dict) -> dict:
        """清理並限制工具輸入"""
        if tool_name == "command":
            cmd = input_data.get("command", "")
            if not self.check_command(cmd):
                input_data["command"] = f"echo '命令 {cmd} 已被安全策略封鎖'"
        elif tool_name == "filesystem":
            path = input_data.get("path", "")
            operation = input_data.get("operation", "read")
            if not self.check_file_access(path, operation):
                raise PermissionError(f"不允許存取 {path}")
        return input_data
```

## 小結

Agentic Engineering 代表了 AI 軟體工程的前沿領域，從被動的回應模式轉向主動的自主行動模式。本章介紹的核心架構──Planner、Executor、Monitor、Reflector──提供了建構可靠代理系統的基礎框架。ReAct 模式將推理與行動緊密結合，使代理能夠在執行過程中不斷調整策略。工具使用設計和記憶管理讓代理能夠有效與外部環境互動並積累經驗。

然而，代理系統目前仍面臨可靠性、成本和安全的重大挑戰，這些挑戰需要在具體應用中根據場景特點進行權衡取捨。隨著語言模型能力的不斷提升和框架生態的成熟，Agentic Engineering 將在軟體開發自動化中扮演越來越重要的角色。
