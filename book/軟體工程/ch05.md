# 第五章 Harness Engineering

## 5.1 什麼是 Harness Engineering

Harness Engineering 是一門專注於設計和實作 AI 模型接入基礎設施的學科。它涵蓋了從模型呼叫、API 封裝、快取策略、安全過濾到監控系統的完整技術棧。如果把提示工程比喻為「寫劇本」，Context Engineering 比喻為「準備道具」，那麼 Harness Engineering 就是「搭建舞台和燈光系統」。

### 5.1.1 核心定義

Harness Engineering 指的是在 AI 應用與底層模型之間建立一層可靠的、安全的、可觀測的中介基礎設施。這層基礎設施負責處理所有與模型互動的非功能性需求，讓應用開發者可以專注於業務邏輯。

典型的 Harness 架構包含以下層級：

```
應用層 (Application Layer)
    |
Harness 層 (中介層)
    ├── 模型接入層 (Model Access Layer)
    ├── API 封裝層 (API Wrapper Layer)
    ├── 快取層 (Cache Layer)
    ├── 安全過濾層 (Security Layer)
    ├── 監控層 (Monitoring Layer)
    └── Rate Limiting 層
    |
模型層 (Model Layer)
    ├── GPT-4
    ├── Claude 3
    ├── Gemini
    └── 自訂模型
```

### 5.1.2 Harness Engineering 的重要性

在生產環境中，直接呼叫模型 API 會面臨一系列問題：

- **供應商鎖定**：不同的模型供應商有完全不同的 API 格式和認證方式
- **可靠性問題**：模型 API 可能暫時不可用或回應異常
- **安全風險**：提示注入、敏感資訊洩漏、不當輸出
- **成本控制**：缺乏 Token 使用量的可視化和控制
- **效能瓶頸**：未經最佳化的呼叫可能導致高延遲

Harness Engineering 的目標就是系統性地解決這些問題。

## 5.2 模型接入層設計

### 5.2.1 多模型路由

在生產環境中，同一個應用可能需要對接到多個不同的模型。多模型路由器負責根據請求的特性將流量導向最合適的模型：

```python
import openai
from anthropic import Anthropic
from abc import ABC, abstractmethod
import time
from typing import Dict, List, Optional, Any

class BaseModelProvider(ABC):
    @abstractmethod
    def chat_completion(self, messages, **kwargs) -> Dict[str, Any]:
        pass

    @abstractmethod

        pass


class OpenAIProvider(BaseModelProvider):

        self.model = model

        self.model = model
```

### 5.2.2 模型路由器實作

多模型路由器需支援條件路由、權重路由和 fallback 機制。以下是完整的路由器實作：

```python
class ModelRouter:
    def __init__(self):
        self.providers: Dict[str, BaseModelProvider] = {}
        self.routing_rules: List[Dict] = []

    def register_provider(self, name: str, provider: BaseModelProvider):
        self.providers[name] = provider

    def add_routing_rule(self, rule: Dict):
        self.routing_rules.append(rule)

    def route(self, request: Dict) -> Dict:
        for rule in self.routing_rules:
            if self._match_rule(rule, request):
                provider_name = rule["target"]
                if provider_name in self.providers:
                    provider = self.providers[provider_name]
                    return provider.chat_completion(
                        request["messages"],
                        **request.get("params", {})
                    )

        default = self.providers.get("gpt-4")
        if default:
            return default.chat_completion(
                request["messages"],
                **request.get("params", {})
            )
        return {"error": "No provider available"}

    def _match_rule(self, rule: Dict, request: Dict) -> bool:
        conditions = rule.get("conditions", {})
        for key, value in conditions.items():
            if key == "task_type":
                if request.get("task_type") != value:
                    return False
            elif key == "max_cost":
                if request.get("max_cost", float("inf")) <= value:
                    pass
            elif key == "requires_json":
                if value and request.get("response_format") != "json":
                    return False
            elif key == "estimated_tokens":
                if request.get("estimated_tokens", 0) > value:
                    return False
        return True


def setup_production_router():
    router = ModelRouter()

    router.register_provider("gpt-4", OpenAIProvider(
        api_key="sk-xxx", model="gpt-4"
    ))
    router.register_provider("gpt-3.5", OpenAIProvider(
        api_key="sk-xxx", model="gpt-3.5-turbo"
    ))
    router.register_provider("claude-3", AnthropicProvider(
        api_key="sk-ant-xxx", model="claude-3-sonnet-20240229"
    ))

    router.add_routing_rule({
        "conditions": {"task_type": "code_review", "requires_json": True},
        "target": "gpt-4"
    })
    router.add_routing_rule({
        "conditions": {"task_type": "simple_qa", "estimated_tokens": 1000},
        "target": "gpt-3.5"
    })
    router.add_routing_rule({
        "conditions": {"task_type": "long_document_analysis", "estimated_tokens": 50000},
        "target": "claude-3"
    })

    return router
```

### 5.2.3 版本管理與逐步更新

模型版本管理確保應用在模型更新時仍能穩定運作。逐步更新 (gradual rollout) 是降低風險的關鍵策略：

```python
class ModelVersionManager:
    def __init__(self):
        self.versions = {}
        self.aliases = {}

    def register_version(self, model_id: str, version: str,
                        provider: str, config: Dict = None):
        key = f"{model_id}@{version}"
        self.versions[key] = {
            "model_id": model_id,
            "version": version,
            "provider": provider,
            "config": config or {},
            "status": "active",
            "registered_at": time.time()
        }

    def set_alias(self, alias: str, model_id: str, version: str):
        self.aliases[alias] = {"model_id": model_id, "version": version}

    def resolve(self, model_spec: str) -> Optional[Dict]:
        if model_spec in self.aliases:
            alias_info = self.aliases[model_spec]
            return self.versions.get(
                f"{alias_info['model_id']}@{alias_info['version']}"
            )
        if "@" in model_spec:
            return self.versions.get(model_spec)

        matched = []
        for key, info in self.versions.items():
            if key.startswith(model_spec) and info["status"] == "active":
                matched.append((key, info))
        if matched:
            matched.sort(key=lambda x: x[1]["registered_at"], reverse=True)
            return matched[0][1]
        return None

    def deprecate_version(self, model_id: str, version: str):
        key = f"{model_id}@{version}"
        if key in self.versions:
            self.versions[key]["status"] = "deprecated"


class GradualRolloutManager:
    def __init__(self, model_manager: ModelVersionManager):
        self.model_manager = model_manager
        self.rollouts = {}

    def start_rollout(self, model_id: str, new_version: str,
                     old_version: str, steps: List[float] = None):
        steps = steps or [0.05, 0.1, 0.25, 0.5, 1.0]
        self.rollouts[model_id] = {
            "new_version": new_version,
            "old_version": old_version,
            "steps": steps,
            "current_step": 0,
            "new_version_percentage": steps[0]
        }

    def select_version(self, model_id: str, request_id: str = None) -> Optional[Dict]:
        if model_id not in self.rollouts:
            return self.model_manager.resolve(f"{model_id}@latest")

        rollout = self.rollouts[model_id]
        import hashlib

        if request_id:
            hash_val = int(hashlib.md5(request_id.encode()).hexdigest(), 16) % 100
            use_new = (hash_val / 100) < rollout["new_version_percentage"]
        else:
            import random
            use_new = random.random() < rollout["new_version_percentage"]

        if use_new:
            return self.model_manager.resolve(
                f"{model_id}@{rollout['new_version']}"
            )
        else:
            return self.model_manager.resolve(
                f"{model_id}@{rollout['old_version']}"
            )

    def advance_step(self, model_id: str):
        if model_id in self.rollouts:
            rollout = self.rollouts[model_id]
            if rollout["current_step"] < len(rollout["steps"]) - 1:
                rollout["current_step"] += 1
                rollout["new_version_percentage"] = rollout["steps"][
                    rollout["current_step"]
                ]
```

### 5.2.4 供應商抽象層

供應商抽象層讓應用程式可以無痛切換不同的 AI 服務供應商，並支援多種容錯策略：

```python
class VendorAbstractionLayer:
    def __init__(self):
        self.vendors = {}
        self.default_vendor = None

    def register_vendor(self, name: str, provider: BaseModelProvider,
                       weight: float = 1.0, fallback_order: int = 1):
        self.vendors[name] = {
            "provider": provider,
            "weight": weight,
            "fallback_order": fallback_order,
            "healthy": True
        }

    def set_default(self, vendor_name: str):
        self.default_vendor = vendor_name

    def chat(self, messages, **kwargs) -> Dict:
        vendor_name = kwargs.pop("vendor", self.default_vendor)
        strategy = kwargs.pop("fallback_strategy", "sequential")

        if not vendor_name:
            return {"error": "No vendor specified and no default set"}

        if strategy == "sequential":
            return self._sequential_fallback(messages, **kwargs)
        elif strategy == "parallel":
            return self._parallel_fallback(messages, **kwargs)
        elif strategy == "weighted_random":
            return self._weighted_random(messages, **kwargs)
        else:
            return self._sequential_fallback(messages, **kwargs)

    def _sequential_fallback(self, messages, **kwargs):
        sorted_vendors = sorted(
            self.vendors.items(),
            key=lambda x: x[1]["fallback_order"]
        )
        errors = []
        for name, config in sorted_vendors:
            if not config["healthy"]:
                continue
            try:
                return config["provider"].chat_completion(messages, **kwargs)
            except Exception as e:
                errors.append(f"{name}: {str(e)}")
                continue
        return {"error": "All vendors failed", "details": errors}

    def _parallel_fallback(self, messages, **kwargs):
        import concurrent.futures
        healthy_vendors = {
            name: config for name, config in self.vendors.items()
            if config["healthy"]
        }
        if not healthy_vendors:
            return {"error": "No healthy vendors available"}

        with concurrent.futures.ThreadPoolExecutor(
            max_workers=len(healthy_vendors)
        ) as executor:
            future_to_vendor = {
                executor.submit(
                    config["provider"].chat_completion, messages, **kwargs
                ): name
                for name, config in healthy_vendors.items()
            }
            for future in concurrent.futures.as_completed(future_to_vendor):
                try:
                    return future.result(timeout=30)
                except Exception:
                    continue
        return {"error": "All parallel attempts failed"}

    def _weighted_random(self, messages, **kwargs):
        import random
        healthy = [
            (name, config) for name, config in self.vendors.items()
            if config["healthy"]
        ]
        if not healthy:
            return {"error": "No healthy vendors"}

        total_weight = sum(config["weight"] for _, config in healthy)
        r = random.uniform(0, total_weight)
        cumulative = 0
        for name, config in healthy:
            cumulative += config["weight"]
            if r <= cumulative:
                try:
                    return config["provider"].chat_completion(messages, **kwargs)
                except Exception:
                    pass
        return healthy[0][1]["provider"].chat_completion(messages, **kwargs)
```

### 5.3.2 錯誤處理與重試策略

統一的錯誤分類和智慧重試是生產級 Harness 的核心元件：

```python
from enum import Enum

class ErrorCategory(Enum):
    RATE_LIMIT = "rate_limit"
    AUTH_ERROR = "auth_error"
    TIMEOUT = "timeout"
    SERVER_ERROR = "server_error"
    INVALID_REQUEST = "invalid_request"
    CONTEXT_LENGTH = "context_length"
    UNKNOWN = "unknown"


def categorize_error(exception: Exception) -> ErrorCategory:
    error_str = str(exception).lower()

    if "rate limit" in error_str or "429" in error_str:
        return ErrorCategory.RATE_LIMIT
    elif "authentication" in error_str or "401" in error_str or "403" in error_str:
        return ErrorCategory.AUTH_ERROR
    elif "timeout" in error_str or "timed out" in error_str:
        return ErrorCategory.TIMEOUT
    elif "500" in error_str or "502" in error_str or "503" in error_str:
        return ErrorCategory.SERVER_ERROR
    elif "context length" in error_str or "maximum context" in error_str:
        return ErrorCategory.CONTEXT_LENGTH
    elif "invalid" in error_str or "400" in error_str:
        return ErrorCategory.INVALID_REQUEST
    else:
        return ErrorCategory.UNKNOWN


class RetryStrategy:
    def __init__(self, max_retries: int = 3, base_delay: float = 1.0,
                 max_delay: float = 60.0, exponential_base: float = 2.0):
        self.max_retries = max_retries
        self.base_delay = base_delay
        self.max_delay = max_delay
        self.exponential_base = exponential_base

    def get_delay(self, attempt: int) -> float:
        delay = self.base_delay * (self.exponential_base ** attempt)
        import random
        jitter = random.uniform(0, 0.1 * delay)
        return min(delay + jitter, self.max_delay)

    def should_retry(self, attempt: int, error: Exception) -> bool:
        if attempt >= self.max_retries:
            return False
        category = categorize_error(error)
        non_retryable = {ErrorCategory.AUTH_ERROR, ErrorCategory.INVALID_REQUEST}
        return category not in non_retryable


class RetryHandler:
    def __init__(self, strategy: RetryStrategy = None):
        self.strategy = strategy or RetryStrategy()
        self.retryable_errors = {
            ErrorCategory.RATE_LIMIT, ErrorCategory.TIMEOUT,
            ErrorCategory.SERVER_ERROR, ErrorCategory.UNKNOWN
        }

    def execute_with_retry(self, func, *args, **kwargs):
        last_error = None
        for attempt in range(self.strategy.max_retries + 1):
            try:
                return func(*args, **kwargs)
            except Exception as e:
                last_error = e
                category = categorize_error(e)
                if category not in self.retryable_errors:
                    raise
                if attempt < self.strategy.max_retries:
                    delay = self.strategy.get_delay(attempt)
                    time.sleep(delay)
                else:
                    raise
        raise last_error


class CircuitBreaker:
    def __init__(self, failure_threshold: int = 5,
                 recovery_timeout: float = 30.0,
                 half_open_max_requests: int = 2):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.half_open_max_requests = half_open_max_requests
        self.state = "closed"
        self.failure_count = 0
        self.last_failure_time = 0
        self.half_open_requests = 0

    def call(self, func, *args, **kwargs):
        if self.state == "open":
            if time.time() - self.last_failure_time >= self.recovery_timeout:
                self.state = "half-open"
                self.half_open_requests = 0
            else:
                raise Exception("Circuit breaker is OPEN")

        try:
            result = func(*args, **kwargs)
            if self.state == "half-open":
                self.half_open_requests += 1
                if self.half_open_requests >= self.half_open_max_requests:
                    self.state = "closed"
                    self.failure_count = 0
            self.failure_count = 0
            return result
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = time.time()
            if self.failure_count >= self.failure_threshold:
                self.state = "open"
            raise
```

### 5.3.3 逾時管理

不同類型的任務需要不同的逾時策略。以下是可設定的逾時管理系統：

```python
class TimeoutConfig:
    def __init__(self):
        self.defaults = {
            "chat": 30.0,
            "code_generation": 60.0,
            "analysis": 120.0,
            "long_context": 180.0,
        }
        self.custom = {}

    def get_timeout(self, task_type: str, model: str = None) -> float:
        key = f"{model}:{task_type}" if model else task_type
        if key in self.custom:
            return self.custom[key]
        return self.defaults.get(task_type, 30.0)

    def set_timeout(self, task_type: str, timeout: float, model: str = None):
        if model:
            self.custom[f"{model}:{task_type}"] = timeout
        else:
            self.defaults[task_type] = timeout


class TimeoutManager:
    def __init__(self):
        self.config = TimeoutConfig()

    def execute_with_timeout(self, func, task_type: str,
                            model: str = None, *args, **kwargs):
        import signal
        timeout = self.config.get_timeout(task_type, model)

        def timeout_handler(signum, frame):
            raise TimeoutError(f"Task {task_type} timed out after {timeout}s")

        signal.signal(signal.SIGALRM, timeout_handler)
        signal.alarm(int(timeout))

        try:
            result = func(*args, **kwargs)
            signal.alarm(0)
            return result
        except TimeoutError:
            signal.alarm(0)
            raise
```

## 5.4 快取策略

### 5.4.1 語意快取 (Semantic Cache)

語意快取不是快取完全相同的請求，而是快取語意相似的請求。這項技術可以顯著節省 API 成本：

```python
import numpy as np
from typing import List, Tuple, Optional, Dict
import hashlib
import json

class SemanticCache:
    def __init__(self, similarity_threshold: float = 0.92,
                 max_size: int = 1000, ttl: int = 3600):
        self.similarity_threshold = similarity_threshold
        self.max_size = max_size
        self.ttl = ttl
        self.cache: List[Dict] = []
        self.embeddings: List[np.ndarray] = []

    def get(self, query: str, model: str = None) -> Optional[str]:
        query_embedding = self._get_embedding(query)
        if query_embedding is None:
            return None

        best_match = None
        best_similarity = 0

        for i, cached in enumerate(self.cache):
            if model and cached.get("model") and cached["model"] != model:
                continue
            if self._is_expired(cached):
                continue

            similarity = self._cosine_similarity(
                query_embedding, self.embeddings[i]
            )
            if similarity > best_similarity:
                best_similarity = similarity
                best_match = cached

        if best_match and best_similarity >= self.similarity_threshold:
            return best_match["response"]
        return None

    def set(self, query: str, response: str, metadata: Dict = None):
        embedding = self._get_embedding(query)
        if embedding is None:
            return

        if len(self.cache) >= self.max_size:
            self._evict()

        entry = {
            "query": query,
            "response": response,
            "timestamp": time.time(),
            "ttl": self.ttl,
            "hits": 0,
            "metadata": metadata or {}
        }
        self.cache.append(entry)
        self.embeddings.append(embedding)

    def _get_embedding(self, text: str) -> Optional[np.ndarray]:
        try:
            import openai
            response = openai.embeddings.create(
                model="text-embedding-3-small",
                input=text
            )
            return np.array(response.data[0].embedding)
        except Exception:
            return None

    def _cosine_similarity(self, a: np.ndarray, b: np.ndarray) -> float:
        norm_a = np.linalg.norm(a)
        norm_b = np.linalg.norm(b)
        if norm_a == 0 or norm_b == 0:
            return 0
        return float(np.dot(a, b) / (norm_a * norm_b))

    def _is_expired(self, entry: Dict) -> bool:
        return (time.time() - entry["timestamp"]) > entry["ttl"]

    def _evict(self):
        if not self.cache:
            return
        oldest_idx = 0
        oldest_time = self.cache[0]["timestamp"]
        for i, entry in enumerate(self.cache):
            if entry["timestamp"] < oldest_time:
                oldest_time = entry["timestamp"]
                oldest_idx = i
        self.cache.pop(oldest_idx)
        self.embeddings.pop(oldest_idx)

    def get_stats(self) -> Dict:
        total = len(self.cache)
        hits = sum(1 for e in self.cache if e.get("hits", 0) > 0)
        total_hits = sum(e.get("hits", 0) for e in self.cache)
        return {
            "total_entries": total,
            "unique_hit_entries": hits,
            "total_hits": total_hits,
            "hit_rate": hits / total if total > 0 else 0
        }
```

### 5.4.2 精確快取 (Exact Cache)

精確快取用於完全相同請求的快速回應。它比語意快取更快但覆蓋範圍更窄：

```python
class ExactCache:
    def __init__(self, ttl: int = 300, max_size: int = 5000):
        self.ttl = ttl
        self.max_size = max_size
        self.cache = {}
        self.ttl_map = {}

    def _make_key(self, messages: List[Dict], model: str,
                  temperature: float = None) -> str:
        key_data = {
            "messages": messages,
            "model": model,
            "temperature": temperature
        }
        key_str = json.dumps(key_data, sort_keys=True, ensure_ascii=False)
        return hashlib.sha256(key_str.encode()).hexdigest()

    def get(self, messages: List[Dict], model: str,
            temperature: float = None) -> Optional[str]:
        key = self._make_key(messages, model, temperature)
        if key in self.cache:
            if time.time() - self.ttl_map[key] < self.ttl:
                return self.cache[key]
            else:
                del self.cache[key]
                del self.ttl_map[key]
        return None

    def set(self, messages: List[Dict], model: str, response: str,
            temperature: float = None):
        key = self._make_key(messages, model, temperature)
        if len(self.cache) >= self.max_size:
            self._cleanup()
        self.cache[key] = response
        self.ttl_map[key] = time.time()

    def invalidate(self, messages: List[Dict], model: str,
                   temperature: float = None):
        key = self._make_key(messages, model, temperature)
        self.cache.pop(key, None)
        self.ttl_map.pop(key, None)

    def _cleanup(self):
        now = time.time()
        expired = [k for k, t in self.ttl_map.items() if now - t >= self.ttl]
        for k in expired:
            del self.cache[k]
            del self.ttl_map[k]

    def clear(self):
        self.cache.clear()
        self.ttl_map.clear()


class TwoTierCache:
    def __init__(self, exact_ttl: int = 300, semantic_ttl: int = 3600):
        self.exact = ExactCache(ttl=exact_ttl)
        self.semantic = SemanticCache(ttl=semantic_ttl)

    def get(self, query: str, messages: List[Dict], model: str,
            temperature: float = None) -> Optional[str]:
        result = self.exact.get(messages, model, temperature)
        if result:
            return result
        result = self.semantic.get(query, model)
        if result:
            return result
        return None

    def set(self, query: str, messages: List[Dict], model: str,
            response: str, temperature: float = None):
        self.exact.set(messages, model, response, temperature)
        self.semantic.set(query, response, {"model": model})
```

```python
class PromptInjectionDetector:
    def __init__(self):

            r"ignore\s+(all\s+)?(previous|above|prior)\s+(instructions|prompts|directions)",
            r"forget\s+(everything|all)\s+",
            r"new\s+instructions?:\s*",
            r"print\s+(your\s+)?(system\s+)?prompt",
            r"show\s+(me\s+)?(your\s+)?(system\s+)?instructions",
            r"reveal\s+(your\s+)?prompt",

            r"from\s+now\s+on\s+you\s+are\s+",
            r"execute\s+(the\s+)?(following\s+)?(code|command|script)",
            r"run\s+(this\s+)?(code|command|script)",
        ]

            re.compile(p, re.IGNORECASE) for p in self.injection_patterns
        ]

    def scan(self, text: str) -> List[Dict]:
        findings = []
        for i, pattern in enumerate(self.compiled_patterns):

            for match in matches:

                    "matched_text": match,
                    "severity": "high"

        findings = self.scan(text)
        if not findings:
            return False, 0.0
        score = min(1.0, len(findings) * 0.3)
        return score >= threshold, score


class InputSanitizer:
    def __init__(self):
        self.detector = PromptInjectionDetector()

    def sanitize(self, user_input: str, strategy: str = "block") -> str:
        is_suspicious, score = self.detector.is_suspicious(user_input)
        if not is_suspicious:
            return user_input

        if strategy == "block":
            raise ValueError(f"Detected prompt injection (score: {score:.2f})")
        elif strategy == "warn":
            return f"[SECURITY WARNING: Possible prompt injection detected (confidence: {score:.2f})]\n{user_input}"
        elif strategy == "strip":
            findings = self.detector.scan(user_input)
            cleaned = user_input
            for f in findings:
                match_text = f.get("matched_text", "")
                if isinstance(match_text, str) and match_text:
                    cleaned = cleaned.replace(match_text, "[REDACTED]")
            return cleaned
        elif strategy == "isolate":
            return f"User input:\n---\n{user_input}\n---\nPlease respond within your system role."
        return user_input
```

```python
class PIIDetector:
    def __init__(self):
        self.pii_patterns = {
            "email": r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b",
            "phone": r"\b(\+?\d{1,3}[-.\s]?)?\(?\d{2,4}\)?[-.\s]?\d{3,4}[-.\s]?\d{3,4}\b",
            "credit_card": r"\b(?:\d{4}[-\s]?){3}\d{4}\b",
            "ssn": r"\b\d{3}-\d{2}-\d{4}\b",
            "ip_address": r"\b(?:\d{1,3}\.){3}\d{1,3}\b",
            "api_key": r"\b(sk-[a-zA-Z0-9]{20,}|sk-ant-[a-zA-Z0-9]{20,}|AIza[a-zA-Z0-9\-_]{35})\b",
            "password": r"\b(password|passwd|pwd)\s*[:=]\s*['\"]?\S+['\"]?",

        return findings


class PIIMasker:
    def __init__(self):
        self.detector = PIIDetector()
        self.mask_map = {
            "email": "[EMAIL]",
            "phone": "[PHONE]",
            "credit_card": "[CREDIT_CARD]",
            "ssn": "[SSN]",
            "ip_address": "[IP_ADDRESS]",
            "api_key": "[API_KEY]",
            "password": "[PASSWORD]"
        }

    def mask(self, text: str, mask_types: List[str] = None) -> str:
        masked_text = text
        findings = self.detector.detect_all(text)

        for pii_type, matches in findings.items():
            if mask_types and pii_type not in mask_types:
                continue
            if pii_type not in self.mask_map:
                continue
            placeholder = self.mask_map[pii_type]
            for match in matches:
                if isinstance(match, tuple):
                    match = "".join(match)
                masked_text = masked_text.replace(match, placeholder)
        return masked_text

    def mask_with_mapping(self, text: str) -> Tuple[str, Dict]:
        mapping = {}
        masked_text = text
        findings = self.detector.detect_all(text)

        counter = 0
        for pii_type, matches in findings.items():
            if pii_type not in self.mask_map:
                continue
            for match in matches:
                if isinstance(match, tuple):
                    match = "".join(match)
                placeholder = f"{{PII_{counter}}}"
                mapping[placeholder] = match
                masked_text = masked_text.replace(match, placeholder)
                counter += 1
        return masked_text, mapping

    def unmask(self, masked_text: str, mapping: Dict) -> str:
        result = masked_text
        for placeholder, original in mapping.items():
            result = result.replace(placeholder, original)
        return result
```

```python
class LatencyMonitor:
    def __init__(self):
        self.latency_records = []
        self.percentiles = [50, 90, 95, 99]

    def record(self, model: str, latency_ms: float, endpoint: str = "chat"):
        import datetime
        self.latency_records.append({
            "timestamp": datetime.datetime.now().isoformat(),
            "model": model,
            "latency_ms": latency_ms,
            "endpoint": endpoint
        })

        self._cleanup()

    def _cleanup(self, max_records: int = 10000):
        if len(self.latency_records) > max_records:
            self.latency_records = self.latency_records[-max_records:]

    def get_stats(self, model: str = None, window_minutes: int = 60) -> Dict:
        import datetime
        cutoff = datetime.datetime.now() - datetime.timedelta(minutes=window_minutes)

        records = [
            r for r in self.latency_records
            if (model is None or r["model"] == model)
            and datetime.datetime.fromisoformat(r["timestamp"]) > cutoff
        ]

        if not records:
            return {"error": "No records in window"}

        latencies = sorted([r["latency_ms"] for r in records])
        n = len(latencies)

        stats = {
            "model": model or "all",
            "window_minutes": window_minutes,
            "total_requests": n,
            "min_latency_ms": latencies[0],
            "max_latency_ms": latencies[-1],
            "avg_latency_ms": sum(latencies) / n,
        }

        for p in self.percentiles:
            idx = int(n * p / 100)
            stats[f"p{p}_latency_ms"] = latencies[min(idx, n - 1)]

        return stats

    def detect_anomaly(self, model: str, current_latency: float,
                       threshold_std: float = 3.0) -> bool:
        stats = self.get_stats(model, window_minutes=30)
        if "avg_latency_ms" not in stats:
            return False

        all_latencies = [
            r["latency_ms"] for r in self.latency_records
            if r["model"] == model
        ]

        if len(all_latencies) < 10:
            return False

        import statistics
        mean = statistics.mean(all_latencies)
        std = statistics.stdev(all_latencies)

        return abs(current_latency - mean) > threshold_std * std
```

```python
        return {"total_monthly": round(total, 2), "breakdown": breakdown}
```

## 5.7 Rate Limiting 與配額管理

Rate Limiting 是保護後端服務和控製成本的關鍵機制：

```python
import time
from collections import defaultdict
from threading import Lock

class RateLimiter:
    def __init__(self):
        self.limits = {}
        self.usage = defaultdict(list)
        self.lock = Lock()

    def set_limit(self, key: str, max_requests: int, window_seconds: int):
        self.limits[key] = {
            "max_requests": max_requests,
            "window_seconds": window_seconds
        }

    def check_limit(self, key: str) -> Dict:
        if key not in self.limits:
            return {"allowed": True, "remaining": -1}

        limit = self.limits[key]
        now = time.time()
        window_start = now - limit["window_seconds"]

        with self.lock:
            self.usage[key] = [
                t for t in self.usage[key] if t > window_start
            ]

            current_count = len(self.usage[key])
            remaining = limit["max_requests"] - current_count

            if current_count >= limit["max_requests"]:
                oldest = self.usage[key][0] if self.usage[key] else now
                reset_in = limit["window_seconds"] - (now - oldest)
                return {
                    "allowed": False,
                    "remaining": 0,
                    "reset_in_seconds": int(reset_in)
                }

            self.usage[key].append(now)
            return {
                "allowed": True,
                "remaining": remaining,
                "reset_in_seconds": int(window_start + limit["window_seconds"] - now)
            }


class TokenBucketRateLimiter:
    def __init__(self, tokens_per_second: float, max_tokens: int):
        self.tokens_per_second = tokens_per_second
        self.max_tokens = max_tokens
        self.tokens = max_tokens
        self.last_refill = time.time()
        self.lock = Lock()

    def _refill(self):
        now = time.time()
        elapsed = now - self.last_refill
        self.tokens = min(
            self.max_tokens,
            self.tokens + elapsed * self.tokens_per_second
        )
        self.last_refill = now

    def consume(self, tokens: int = 1) -> bool:
        with self.lock:
            self._refill()
            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            return False

    def get_available_tokens(self) -> float:
        with self.lock:
            self._refill()
            return self.tokens


class QuotaManager:
    def __init__(self):
        self.quotas = {}
        self.usage = defaultdict(lambda: {
            "total_tokens": 0,
            "total_calls": 0,
            "total_cost": 0.0,
            "daily_usage": {}
        })

    def set_quota(self, user_id: str, daily_token_limit: int = None,
                  daily_cost_limit: float = None, monthly_token_limit: int = None):
        self.quotas[user_id] = {
            "daily_token_limit": daily_token_limit,
            "daily_cost_limit": daily_cost_limit,
            "monthly_token_limit": monthly_token_limit
        }

    def check_quota(self, user_id: str, estimated_tokens: int,
                    estimated_cost: float) -> Dict:
        if user_id not in self.quotas:
            return {"allowed": True, "reason": "no_quota_set"}

        import datetime
        today = datetime.date.today().isoformat()
        quota = self.quotas[user_id]
        usage = self.usage[user_id]

        today_usage = usage["daily_usage"].get(today, {
            "tokens": 0, "cost": 0.0, "calls": 0
        })

        if quota["daily_token_limit"]:
            projected = today_usage["tokens"] + estimated_tokens
            if projected > quota["daily_token_limit"]:
                return {
                    "allowed": False,
                    "reason": f"Daily token limit exceeded: {projected} > {quota['daily_token_limit']}"
                }

        if quota["daily_cost_limit"]:
            projected_cost = today_usage["cost"] + estimated_cost
            if projected_cost > quota["daily_cost_limit"]:
                return {
                    "allowed": False,
                    "reason": f"Daily cost limit exceeded: {projected_cost:.2f} > {quota['daily_cost_limit']:.2f}"
                }

        return {"allowed": True, "reason": "within_quota"}

    def record_usage(self, user_id: str, tokens: int, cost: float):
        import datetime
        today = datetime.date.today().isoformat()

        self.usage[user_id]["total_tokens"] += tokens
        self.usage[user_id]["total_calls"] += 1
        self.usage[user_id]["total_cost"] += cost

        if today not in self.usage[user_id]["daily_usage"]:
            self.usage[user_id]["daily_usage"][today] = {
                "tokens": 0, "cost": 0.0, "calls": 0
            }
        self.usage[user_id]["daily_usage"][today]["tokens"] += tokens
        self.usage[user_id]["daily_usage"][today]["cost"] += cost
        self.usage[user_id]["daily_usage"][today]["calls"] += 1

    def get_user_report(self, user_id: str) -> Dict:
        return self.usage.get(user_id, {})
```

## 5.8 本章小結

Harness Engineering 是將 AI 模型整合到生產環境中的關鍵基礎設施學科。本章深入探討了以下核心主題：

- 模型接入層提供了多模型路由、版本管理和供應商抽象，讓應用可以靈活調度不同的 AI 模型
- API 封裝與中介層統一了請求回應格式，並提供錯誤分類、重試策略、斷路器和逾時管理等可靠性機制
- 快取策略包含語意快取和精確快取兩層，在保證回應品質的同時顯著降低成本
- 安全過濾層從提示注入防護、PII 遮罩、輸出驗證到敏感操作核准，建立了多層次的安全防護
- 監控與可觀測性涵蓋 Token 追蹤、延遲監控、錯誤分析和成本分析，確保系統的可見性
- Rate Limiting 和配額管理在服務端和使用者端兩個層面控制資源使用

這五章的內容（提示工程、Context Engineering、Harness Engineering）構成了一個完整的 AI 軟體工程知識體系，涵蓋了從與模型溝通到建構生產級基礎設施的各個層面。
