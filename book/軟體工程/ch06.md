# 第 6 章：Loop Engineering

## 什麼是 Loop Engineering

Loop Engineering 是 AI 軟體工程中關於設計與實作迭代回饋迴路的專業領域。傳統的 AI 程式碼生成採用單輪產出模式：給定提示、產生結果、任務結束。這種方式雖然簡單，但生成的程式碼往往需要大量人工修正才能達到可用的品質。Loop Engineering 的核心思想是將程式碼生成轉變為一個多輪迭代的過程，每一輪都包含生成、評估、修正三個階段，透過反覆精煉逐步逼近目標。

這個概念源自控制理論中的回饋迴路（feedback loop），但將其應用於 AI 驅動的軟體開發流程。在傳統控制系統中，感測器量測輸出、控制器計算誤差、制動器調整行為；在 Loop Engineering 中，AI 模型扮演生成器、評估工具扮演感測器、而修正提示則扮演制動器。這種類比幫助我們理解為什麼單輪生成往往不夠：沒有回饋的系統無法自我校正。

Loop Engineering 解決的核心問題包括：AI 生成程式碼的正確性無法一次性保證、程式碼品質需要多維度驗證、以及複雜功能需要逐步建構而非一次完成。透過系統性的迴路設計，我們可以將 AI 的創造力與自動化驗證的嚴謹性結合起來，產生更高品質的軟體產出。

## 迭代回饋迴路設計

### 生成-評估-修正循環

最基本的迭代迴路由三個步驟組成，形成一個閉環：

1. **生成（Generate）**：AI 模型根據當前上下文和提示產生程式碼輸出
2. **評估（Evaluate）**：對生成的程式碼進行多維度檢查，收集錯誤與問題
3. **修正（Refine）**：將評估結果回饋給模型，要求其根據問題進行修正

以下是一個基礎的迭代迴路實作：

```python
import subprocess
import tempfile
import os
from typing import List, Optional

class LoopEngine:
    """基礎的生成-評估-修正迴路引擎"""

    def __init__(self, model_api, max_iterations: int = 5):
        self.model_api = model_api
        self.max_iterations = max_iterations
        self.history = []

    def generate(self, prompt: str, context: str = "") -> str:
        """呼叫 AI 模型生成程式碼"""
        full_prompt = f"{context}\n\n{prompt}" if context else prompt
        response = self.model_api.generate(full_prompt)
        code = self._extract_code(response)
        self.history.append({"stage": "generate", "code": code})
        return code

    def evaluate(self, code: str) -> List[str]:
        """對生成的程式碼進行評估，回傳問題列表"""
        issues = []
        issues.extend(self._check_syntax(code))
        issues.extend(self._check_static_analysis(code))
        return issues

    def refine(self, code: str, issues: List[str]) -> str:
        """根據評估結果要求模型修正"""
        refine_prompt = self._build_refine_prompt(code, issues)
        response = self.model_api.generate(refine_prompt)
        refined = self._extract_code(response)
        self.history.append({"stage": "refine", "code": refined, "issues": issues})
        return refined

    def run(self, prompt: str, context: str = "") -> str:
        """執行完整的迭代迴路"""
        code = self.generate(prompt, context)
        for i in range(self.max_iterations):
            issues = self.evaluate(code)
            if not issues:
                print(f"在第 {i+1} 輪後收斂，無問題")
                return code
            print(f"第 {i+1} 輪發現 {len(issues)} 個問題")
            code = self.refine(code, issues)
        print(f"已達最大迭代次數 {self.max_iterations}")
        return code

    def _extract_code(self, response: str) -> str:
        """從模型回應中提取程式碼區塊"""
        if "```" in response:
            parts = response.split("```")
            for i, part in enumerate(parts):
                if i % 2 == 1 and ("python" in part or i == len(parts)-1):
                    content = part.strip()
                    if content.startswith("python"):
                        content = content[6:].strip()
                    return content
        return response

    def _check_syntax(self, code: str) -> List[str]:
        """檢查 Python 語法錯誤"""
        issues = []
        try:
            compile(code, "<string>", "exec")
        except SyntaxError as e:
            issues.append(f"語法錯誤: {e.msg} 在第 {e.lineno} 行")
        return issues

    def _check_static_analysis(self, code: str) -> List[str]:
        """執行基本的靜態分析"""
        issues = []
        lines = code.split("\n")
        for i, line in enumerate(lines, 1):
            stripped = line.strip()
            if len(stripped) > 100:
                issues.append(f"第 {i} 行過長 ({len(stripped)} 個字元)")
            if stripped.endswith((" ", "\t")):
                issues.append(f"第 {i} 行結尾有多餘空白")
        return issues

    def _build_refine_prompt(self, code: str, issues: List[str]) -> str:
        """建構修正提示"""
        issues_text = "\n".join(f"- {issue}" for issue in issues)
        return f"""請修正以下程式碼中的問題：

```python
{code}
```

發現的問題：
{issues_text}

請輸出修正後的完整程式碼。"""
```

這個實作展示了循環的核心結構，但在生產環境中，評估階段需要整合更多專業工具。

### 自我修正機制

自我修正機制是迴路設計的進化版本，其關鍵差異在於模型能夠自主判斷何時需要修正、如何修正，以及何時應該停止。這需要模型具備對自身輸出的批判性思考能力。

```python
class SelfCorrectingLoop:
    """具備自我修正能力的進階迴路"""

    def __init__(self, model_api, quality_gates: List[callable]):
        self.model_api = model_api
        self.quality_gates = quality_gates
        self.iteration_count = 0

    def self_correct(self, task: str, code: str) -> str:
        """模型自我審查並修正程式碼"""
        critique_prompt = f"""
        任務: {task}

        請審查以下程式碼，找出所有可能的問題（語法、邏輯、效能、安全）：
        ```python
        {code}
        ```

        請列出問題，並說明修正方式。如果沒有問題，請回答「無問題」。
        """
        critique = self.model_api.generate(critique_prompt)

        if "無問題" in critique:
            return code

        refine_prompt = f"""
        原始任務: {task}

        原始程式碼:
        ```python
        {code}
        ```

        審查意見:
        {critique}

        請根據審查意見修正程式碼，輸出修正後的完整版本。
        """
        refined = self.model_api.generate(refine_prompt)
        self.iteration_count += 1
        return self._extract_code(refined)

    def run_with_self_correction(self, task: str, initial_code: str,
                                  max_rounds: int = 3) -> str:
        """執行自我修正迴路"""
        code = initial_code
        for round_num in range(max_rounds):
            improved = self.self_correct(task, code)
            if improved == code:
                print(f"自我修正已收斂，共 {self.iteration_count} 次迭代")
                return code
            code = improved
            all_pass = all(gate(code) for gate in self.quality_gates)
            if all_pass:
                print("所有品質閘道通過，停止迭代")
                return code
        return code
```

### 多輪精煉策略

多輪精煉並非簡單的重複修正，而是需要策略性地設計每一輪的關注焦點。常見的精煉策略包括：

- **由廣到深（Broad-to-Deep）**：第一輪關注整體架構正確性，後續輪次逐步深入細節
- **由硬到軟（Hard-to-Soft）**：先修正編譯錯誤和語法問題，再處理程式碼風格和最佳實踐
- **分階段閘道（Staged Gates）**：每一輪通過不同的品質閘道組合，逐步提高標準

```python
class MultiStageRefiner:
    """多階段精煉器，每一輪關注不同層面"""

    STAGES = [
        {"name": "語法與編譯", "gates": ["syntax", "type_check"]},
        {"name": "邏輯正確性", "gates": ["unit_test", "functional_test"]},
        {"name": "品質與風格", "gates": ["lint", "code_style", "complexity"]},
        {"name": "最佳實踐", "gates": ["security", "performance", "documentation"]},
    ]

    def __init__(self, model_api, gate_implementations: dict):
        self.model_api = model_api
        self.gates = gate_implementations

    def refine_staged(self, task: str, code: str) -> str:
        """按階段依序精煉"""
        current_code = code
        for stage in self.STAGES:
            print(f"--- 階段: {stage['name']} ---")
            active_gates = {name: self.gates[name] for name in stage["gates"]}
            for round_num in range(3):
                issues = self._check_gates(current_code, active_gates)
                if not issues:
                    break
                current_code = self._apply_fixes(current_code, issues, stage["name"])
        return current_code

    def _check_gates(self, code: str, gates: dict) -> List[str]:
        issues = []
        for name, gate_fn in gates.items():
            result = gate_fn(code)
            if result:
                issues.append(f"[{name}] {result}")
        return issues

    def _apply_fixes(self, code: str, issues: List[str], stage_name: str) -> str:
        prompt = f"""程式碼存在以下 {stage_name} 問題：

{"\\n".join(issues)}

請修正程式碼，輸出完整版本：

```python
{code}
```"""
        response = self.model_api.generate(prompt)
        return self._extract_code(response)
```

## 品質閘道 (Quality Gate)

品質閘道是迴路設計中的關鍵檢查點，每個閘道代表一個必須通過的品質標準。閘道的設計原則是：明確（檢查標準清晰）、自動（無需人工介入）、快速（不顯著增加迭代時間）。

### 語法驗證閘道

語法驗證是最基本的閘道，確保生成的程式碼是合法可編譯的：

```python
class SyntaxGate:
    """語法驗證閘道"""

    def __init__(self, language: str = "python"):
        self.language = language

    def check(self, code: str) -> Optional[str]:
        try:
            if self.language == "python":
                compile(code, "<verify>", "exec")
            elif self.language == "python_expression":
                compile(code, "<verify>", "eval")
            return None
        except SyntaxError as e:
            return f"語法錯誤: {e.msg} (第 {e.lineno} 行, 偏移 {e.offset})"
        except ValueError as e:
            return f"編碼錯誤: {e}"

    def check_file(self, filepath: str) -> Optional[str]:
        with open(filepath, "r", encoding="utf-8") as f:
            return self.check(f.read())
```

### 型別檢查閘道

使用 mypy 或 pyright 進行型別檢查，確保型別安全：

```python
class TypeCheckGate:
    """型別檢查閘道，使用 mypy"""

    def __init__(self, mypy_config: Optional[str] = None):
        self.mypy_config = mypy_config

    def check(self, code: str) -> List[str]:
        issues = []
        with tempfile.NamedTemporaryFile(
            mode="w", suffix=".py", delete=False, encoding="utf-8"
        ) as f:
            f.write(code)
            tmp_path = f.name

        try:
            cmd = ["mypy", "--show-error-codes", tmp_path]
            if self.mypy_config:
                cmd.extend(["--config-file", self.mypy_config])

            result = subprocess.run(
                cmd, capture_output=True, text=True, timeout=30
            )

            for line in result.stderr.split("\n"):
                if "error:" in line.lower():
                    issues.append(line.strip())
            for line in result.stdout.split("\n"):
                if "error:" in line.lower():
                    issues.append(line.strip())
        except subprocess.TimeoutExpired:
            issues.append("型別檢查超時")
        finally:
            os.unlink(tmp_path)

        return issues if issues else None
```

### 測試通過閘道

測試是最強大的品質閘道之一，直接驗證行為正確性：

```python
class TestGate:
    """測試通過閘道"""

    def __init__(self, test_framework: str = "pytest",
                 timeout: int = 60):
        self.test_framework = test_framework
        self.timeout = timeout

    def check(self, code: str, test_code: str) -> dict:
        """執行程式碼並運行測試，回傳測試結果"""
        with tempfile.TemporaryDirectory() as tmpdir:
            code_path = os.path.join(tmpdir, "solution.py")
            test_path = os.path.join(tmpdir, "test_solution.py")

            with open(code_path, "w", encoding="utf-8") as f:
                f.write(code)
            with open(test_path, "w", encoding="utf-8") as f:
                f.write(test_code)

            result = subprocess.run(
                ["pytest", test_path, "-v", "--tb=short"],
                capture_output=True, text=True, timeout=self.timeout,
                cwd=tmpdir
            )

            passed = result.returncode == 0
            return {
                "passed": passed,
                "stdout": result.stdout,
                "stderr": result.stderr,
                "summary": self._parse_pytest_output(result.stdout),
            }

    def _parse_pytest_output(self, output: str) -> dict:
        lines = output.strip().split("\n")
        summary = {"total": 0, "passed": 0, "failed": 0, "errors": []}
        for line in lines:
            if "failed" in line and "passed" in line:
                parts = line.split()
                for i, part in enumerate(parts):
                    if part == "passed":
                        summary["passed"] = int(parts[i-1])
                    elif part == "failed":
                        summary["failed"] = int(parts[i-1])
            summary["total"] = summary["passed"] + summary["failed"]
        return summary
```

### Lint 與風格閘道

程式碼風格的一致性對於專案維護至關重要：

```python
class LintGate:
    """Lint 與程式碼風格檢查閘道"""

    def __init__(self, max_warnings: int = 0,
                 ignore_rules: Optional[List[str]] = None):
        self.max_warnings = max_warnings
        self.ignore_rules = ignore_rules or []

    def check_with_flake8(self, code: str) -> Optional[List[str]]:
        with tempfile.NamedTemporaryFile(
            mode="w", suffix=".py", delete=False, encoding="utf-8"
        ) as f:
            f.write(code)
            tmp_path = f.name

        try:
            result = subprocess.run(
                ["flake8", tmp_path, "--max-line-length=88",
                 "--extend-ignore=" + ",".join(self.ignore_rules)],
                capture_output=True, text=True, timeout=15
            )
            violations = [l.strip() for l in result.stdout.split("\n") if l.strip()]
            if len(violations) > self.max_warnings:
                return violations[:20]
            return None
        finally:
            os.unlink(tmp_path)

    def check_with_pylint(self, code: str,
                           min_score: float = 7.0) -> Optional[List[str]]:
        with tempfile.NamedTemporaryFile(
            mode="w", suffix=".py", delete=False, encoding="utf-8"
        ) as f:
            f.write(code)
            tmp_path = f.name

        try:
            result = subprocess.run(
                ["pylint", tmp_path, "--score=y", "--output-format=text"],
                capture_output=True, text=True, timeout=30
            )
            issues = []
            for line in result.stdout.split("\n"):
                if "Your code has been rated at" in line:
                    score = float(line.split("at ")[1].split("/")[0])
                    if score < min_score:
                        issues.append(f"程式碼評分 {score} 低於閾值 {min_score}")
                elif ":" in line and ("C0" in line or "W0" in line or
                                       "E0" in line):
                    issues.append(line.strip())
            return issues if issues else None
        finally:
            os.unlink(tmp_path)
```

## 人機迴圈 (Human-in-the-Loop)

### 何時需要人類介入

完全自動化的迴路雖然高效，但在某些情況下必須引入人類判斷：

1. **模糊的意圖**：當任務描述不明確，AI 無法確定正確的實作方向時
2. **高風險決策**：涉及生產環境變更、資料庫遷移、安全政策修改
3. **創意與設計選擇**：架構方案選擇、UI 設計、API 設計風格
4. **邊界案例處理**：AI 無法確定的特殊情況處理邏輯
5. **安全關鍵路徑**：加密、認證、授權相關程式碼需要人工審查
6. **持續失敗**：多輪迭代後問題仍未解決，需要人類引導方向

### 審查請求設計

設計良好的人機互動介面是 HITL 成功的關鍵：

```python
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Optional

class ReviewPriority(Enum):
    LOW = 1
    MEDIUM = 2
    HIGH = 3
    CRITICAL = 4

class ReviewStatus(Enum):
    PENDING = "pending"
    APPROVED = "approved"
    CHANGES_REQUESTED = "changes_requested"
    ESCALATED = "escalated"

@dataclass
class ReviewRequest:
    """結構化的人類審查請求"""
    request_id: str
    priority: ReviewPriority
    task_description: str
    generated_code: str
    test_results: Optional[dict] = None
    lint_issues: Optional[List[str]] = None
    ai_explanation: str = ""
    alternative_solutions: List[str] = field(default_factory=list)
    questions_for_human: List[str] = field(default_factory=list)
    status: ReviewStatus = ReviewStatus.PENDING
    human_feedback: Optional[str] = None

class HumanInTheLoop:
    """人機迴圈管理器"""

    def __init__(self, notification_callback: Optional[callable] = None):
        self.pending_reviews: List[ReviewRequest] = []
        self.completed_reviews: List[ReviewRequest] = []
        self.callback = notification_callback

    def request_review(self, request: ReviewRequest) -> str:
        """提交審查請求"""
        self.pending_reviews.append(request)
        if self.callback:
            self.callback(f"審查請求 {request.request_id} "
                         f"優先級: {request.priority.name}")
        return request.request_id

    def submit_feedback(self, request_id: str, feedback: str,
                        approved: bool) -> None:
        """提交人類審查意見"""
        for req in self.pending_reviews:
            if req.request_id == request_id:
                req.human_feedback = feedback
                req.status = (
                    ReviewStatus.APPROVED if approved
                    else ReviewStatus.CHANGES_REQUESTED
                )
                self.pending_reviews.remove(req)
                self.completed_reviews.append(req)
                return
        raise ValueError(f"找不到審查請求: {request_id}")

    def should_escalate(self, ai_difficulty_score: float,
                         iteration_count: int) -> bool:
        """判斷是否需要升級到人類"""
        if iteration_count >= 5 and ai_difficulty_score > 0.8:
            return True
        if ai_difficulty_score > 0.95:
            return True
        return False
```

### 回饋整合機制

人類回饋需要有效地整合到後續的 AI 生成過程中：

```python
class FeedbackIntegrator:
    """將人類回饋整合到後續的 AI 生成中"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.feedback_history: List[dict] = []

    def integrate_feedback(self, original_code: str,
                            feedback: str) -> str:
        """根據人類回饋修正程式碼"""
        self.feedback_history.append({
            "type": "code_revision",
            "original": original_code,
            "feedback": feedback,
        })

        prompt = f"""原始程式碼:
```python
{original_code}
```

人類審查意見:
{feedback}

請根據審查意見修正程式碼。"""
        response = self.model_api.generate(prompt)
        revised_code = self._extract_code(response)

        diff = self._compute_diff(original_code, revised_code)
        self.feedback_history[-1]["revised"] = revised_code
        self.feedback_history[-1]["diff"] = diff

        return revised_code

    def get_feedback_context(self) -> str:
        """生成回饋歷史上下文，用於後續請求"""
        if not self.feedback_history:
            return ""
        context_parts = ["## 先前的人類回饋記錄"]
        for i, entry in enumerate(self.feedback_history[-5:], 1):
            context_parts.append(
                f"{i}. {entry.get('feedback', '')[:200]}"
            )
        return "\n".join(context_parts)

    def _compute_diff(self, old: str, new: str) -> str:
        import difflib
        diff = difflib.unified_diff(
            old.splitlines(keepends=True),
            new.splitlines(keepends=True),
            fromfile="original", tofile="revised"
        )
        return "".join(diff)
```

## 自動化評估

### 單元測試作為指標

單元測試不僅驗證正確性，還可以作為程式碼品質的量測指標：

```python
class TestBasedEvaluator:
    """基於測試的評估器"""

    def __init__(self, model_api):
        self.model_api = model_api

    def generate_and_evaluate(self, task: str,
                               test_cases: List[dict]) -> dict:
        """生成程式碼並用測試評估"""
        code = self.model_api.generate(task)
        results = []
        for tc in test_cases:
            result = self._execute_test(code, tc)
            results.append(result)

        passed = sum(1 for r in results if r["passed"])
        return {
            "code": code,
            "test_results": results,
            "pass_rate": passed / len(test_cases) if test_cases else 0,
            "summary": f"{passed}/{len(test_cases)} 測試通過",
        }

    def _execute_test(self, code: str, test_case: dict) -> dict:
        """執行單一測試案例"""
        try:
            local_scope = {}
            exec(code, local_scope)
            func = local_scope.get(test_case.get("func_name"))
            if func is None:
                return {"passed": False, "error": "函數未定義"}

            args = test_case.get("args", [])
            expected = test_case.get("expected")
            actual = func(*args)
            passed = actual == expected

            return {
                "passed": passed,
                "args": args,
                "expected": expected,
                "actual": actual,
            }
        except Exception as e:
            return {"passed": False, "error": str(e)}
```

### 程式碼相似度比對

程式碼相似度用於檢測抄襲、評估重構品質，以及判斷生成結果是否只是微調既有程式碼：

```python
import ast
import hashlib

class CodeSimilarity:
    """程式碼相似度分析工具"""

    @staticmethod
    def token_based_similarity(code_a: str, code_b: str) -> float:
        """基於 Token 的相似度計算"""
        tokens_a = set(code_a.split())
        tokens_b = set(code_b.split())
        if not tokens_a and not tokens_b:
            return 1.0
        intersection = tokens_a & tokens_b
        union = tokens_a | tokens_b
        return len(intersection) / len(union)

    @staticmethod
    def ast_based_similarity(code_a: str, code_b: str) -> float:
        """基於 AST 的結構相似度"""
        try:
            tree_a = ast.parse(code_a)
            tree_b = ast.parse(code_b)
        except SyntaxError:
            return CodeSimilarity.token_based_similarity(code_a, code_b)

        nodes_a = [type(n).__name__ for n in ast.walk(tree_a)]
        nodes_b = [type(n).__name__ for n in ast.walk(tree_b)]

        from collections import Counter
        counter_a = Counter(nodes_a)
        counter_b = Counter(nodes_b)

        all_types = set(counter_a.keys()) | set(counter_b.keys())
        dot_product = sum(counter_a[t] * counter_b[t] for t in all_types)
        magnitude_a = sum(v**2 for v in counter_a.values()) ** 0.5
        magnitude_b = sum(v**2 for v in counter_b.values()) ** 0.5

        if magnitude_a == 0 or magnitude_b == 0:
            return 0.0
        return dot_product / (magnitude_a * magnitude_b)

    @staticmethod
    def structural_hash(code: str) -> str:
        """生成程式碼的結構哈希值（忽略變數名稱）"""
        try:
            tree = ast.parse(code)
            for node in ast.walk(tree):
                if isinstance(node, ast.Name):
                    node.id = "_"
                elif isinstance(node, ast.FunctionDef):
                    node.name = "_"
                elif isinstance(node, ast.arg):
                    node.arg = "_"
            return hashlib.md5(ast.dump(tree).encode()).hexdigest()
        except SyntaxError:
            return hashlib.md5(code.encode()).hexdigest()
```

## 收斂策略

收斂策略決定迭代迴路何時停止。好的收斂策略能在品質與效率之間取得平衡。

### 最大迭代次數

最簡單的收斂條件，設定硬性上限防止無限循環：

```python
class ConvergenceManager:
    """收斂管理器"""

    def __init__(self, max_iterations: int = 10,
                 improvement_threshold: float = 0.01,
                 window_size: int = 3):
        self.max_iterations = max_iterations
        self.improvement_threshold = improvement_threshold
        self.window_size = window_size
        self.scores: List[float] = []
        self.iteration = 0

    def should_stop(self, current_score: float) -> bool:
        """判斷是否應停止迭代"""
        self.iteration += 1
        self.scores.append(current_score)

        if self.iteration >= self.max_iterations:
            return True

        if len(self.scores) >= self.window_size:
            recent = self.scores[-self.window_size:]
            improvements = [
                recent[i+1] - recent[i]
                for i in range(len(recent) - 1)
            ]
            avg_improvement = sum(improvements) / len(improvements)
            if avg_improvement < self.improvement_threshold:
                return True

        return False

    @property
    def best_score(self) -> float:
        return max(self.scores) if self.scores else 0.0

    @property
    def best_iteration(self) -> int:
        if not self.scores:
            return 0
        return self.scores.index(self.best_score) + 1
```

### 改善幅度閾值

當連續多輪的改善幅度低於某個閾值時，繼續迭代的邊際效益遞減：

```python
class AdaptiveConvergence:
    """自適應收斂策略"""

    def __init__(self, initial_threshold: float = 0.1,
                 patience: int = 2):
        self.threshold = initial_threshold
        self.patience = patience
        self.no_improvement_count = 0
        self.best_quality = 0.0

    def evaluate(self, quality_score: float,
                  issues_count: int) -> bool:
        """評估是否應該收斂，回傳 True 表示應停止"""
        improvement = quality_score - self.best_quality

        if improvement > self.threshold:
            self.best_quality = quality_score
            self.no_improvement_count = 0

            if improvement > self.threshold * 3:
                self.threshold *= 1.5
            return False
        else:
            self.no_improvement_count += 1
            if self.no_improvement_count >= self.patience:
                return True
            if issues_count == 0 and improvement <= 0:
                return True
            return False
```

### 多候選方案評比

不只在單一方案上迭代，而是同時探索多個方案，最後選出最佳者：

```python
import concurrent.futures
from dataclasses import dataclass

@dataclass
class Candidate:
    """候選方案"""
    id: int
    code: str
    score: float = 0.0
    issues: List[str] = None

    def __post_init__(self):
        if self.issues is None:
            self.issues = []

class MultiCandidateLoop:
    """多候選方案評比迴路"""

    def __init__(self, model_api, num_candidates: int = 3):
        self.model_api = model_api
        self.num_candidates = num_candidates

    def generate_candidates(self, task: str) -> List[Candidate]:
        """生成多個候選方案"""
        candidates = []
        for i in range(self.num_candidates):
            prompt = f"""
            任務: {task}

            請給出第 {i+1} 個解決方案，確保與其他方案有不同的實作方式。
            """
            code = self.model_api.generate(prompt)
            candidates.append(Candidate(id=i+1, code=code))
        return candidates

    def evaluate_candidates(self,
                             candidates: List[Candidate]) -> List[Candidate]:
        """評估所有候選方案"""
        def evaluate_one(candidate: Candidate) -> Candidate:
            eval_prompt = f"""
            請評估以下程式碼的品質（正確性、效率、可讀性、安全性）。
            給出 0-100 的評分和問題列表。

            ```python
            {candidate.code}
            ```
            """
            result = self.model_api.generate(eval_prompt)
            score = self._extract_score(result)
            issues = self._extract_issues(result)
            candidate.score = score
            candidate.issues = issues
            return candidate

        with concurrent.futures.ThreadPoolExecutor() as executor:
            candidates = list(executor.map(evaluate_one, candidates))

        return sorted(candidates, key=lambda c: c.score, reverse=True)

    def select_best(self, candidates: List[Candidate]) -> Candidate:
        return candidates[0]

    def refine_best(self, task: str, best: Candidate,
                     max_rounds: int = 2) -> Candidate:
        """對最佳方案進行額外精煉"""
        current = best
        for round_num in range(max_rounds):
            if not current.issues:
                break
            refine_prompt = f"""
            任務: {task}

            候選方案評分: {current.score}
            問題: {"\\n".join(current.issues)}

            請改善方案:

            ```python
            {current.code}
            ```
            """
            new_code = self.model_api.generate(refine_prompt)
            new_score = current.score + 5
            current = Candidate(
                id=current.id, code=new_code,
                score=new_score, issues=[]
            )
        return current

    def run(self, task: str) -> Candidate:
        candidates = self.generate_candidates(task)
        evaluated = self.evaluate_candidates(candidates)
        best = self.select_best(evaluated)
        final = self.refine_best(task, best)
        return final

    def _extract_score(self, text: str) -> float:
        import re
        scores = re.findall(r"(\d+)[./](\d+)", text)
        if scores:
            num, den = int(scores[0][0]), int(scores[0][1])
            return (num / den) * 100 if den > 0 else float(num)
        nums = re.findall(r"\b(\d+)\b", text)
        return float(nums[0]) if nums else 50.0

    def _extract_issues(self, text: str) -> List[str]:
        issues = []
        for line in text.split("\n"):
            line = line.strip()
            if line.startswith("-") or line.startswith("*"):
                issues.append(line.lstrip("-* "))
        return issues[:10]
```

## 案例：AI Code Review Loop 的完整實作

以下是一個完整的 AI Code Review 迴路實作，整合了本章介紹的多個概念：

```python
"""
AI Code Review Loop - 完整實作

整合生成、評估、修正迴路，自動審查 Pull Request 中的程式碼變更。
"""

import os
import re
import json
import subprocess
import tempfile
from typing import List, Optional, Tuple
from dataclasses import dataclass, field
from datetime import datetime


@dataclass
class ReviewComment:
    """審查意見"""
    file_path: str
    line_number: int
    severity: str  # error, warning, suggestion
    category: str  # syntax, style, logic, security, performance
    message: str
    suggestion: Optional[str] = None


@dataclass
class ReviewResult:
    """審查結果"""
    pr_id: str
    comments: List[ReviewComment] = field(default_factory=list)
    score: float = 100.0
    passed: bool = True
    summary: str = ""
    reviewed_at: str = ""


class CodeReviewer:
    """AI Code Review 核心引擎"""

    def __init__(self, model_api):
        self.model_api = model_api
        self.gates = {
            "syntax": SyntaxGate(),
            "type_check": TypeCheckGate(),
            "lint": LintGate(max_warnings=5),
        }

    def review(self, code: str, file_path: str = "source.py",
               context: Optional[dict] = None) -> ReviewResult:
        """執行完整的 Code Review 迴路"""
        result = ReviewResult(
            pr_id=context.get("pr_id", "unknown") if context else "unknown",
            reviewed_at=datetime.now().isoformat(),
        )

        # 第一階段：自動化閘道檢查
        gate_comments = self._run_quality_gates(code, file_path)
        result.comments.extend(gate_comments)

        # 第二階段：AI 邏輯審查
        ai_comments = self._ai_code_review(code, file_path, context)
        result.comments.extend(ai_comments)

        # 第三階段：安全審查
        security_comments = self._security_review(code, file_path)
        result.comments.extend(security_comments)

        # 計算評分
        result.score = self._calculate_score(result.comments)
        result.passed = self._should_pass(result.score, result.comments)
        result.summary = self._generate_summary(result)

        return result

    def _run_quality_gates(self, code: str,
                            file_path: str) -> List[ReviewComment]:
        """執行品質閘道檢查"""
        comments = []

        syntax_issue = self.gates["syntax"].check(code)
        if syntax_issue:
            comments.append(ReviewComment(
                file_path=file_path,
                line_number=0,
                severity="error",
                category="syntax",
                message=syntax_issue,
            ))

        lint_issues = self.gates["lint"].check_with_flake8(code)
        if lint_issues:
            for issue in lint_issues[:10]:
                match = re.match(r".+:(\d+):(\d+):\s*(\w+)\s*(.+)", issue)
                if match:
                    line = int(match.group(1))
                    severity = match.group(3)
                    msg = match.group(4)
                    comments.append(ReviewComment(
                        file_path=file_path,
                        line_number=line,
                        severity="warning" if "W" in severity else "error",
                        category="style",
                        message=msg,
                    ))

        return comments

    def _ai_code_review(self, code: str, file_path: str,
                         context: Optional[dict]) -> List[ReviewComment]:
        """使用 AI 進行邏輯審查"""
        context_str = json.dumps(context, ensure_ascii=False, indent=2) if context else ""
        prompt = f"""你是一位資深程式碼審查員。請審查以下程式碼：

檔案路徑: {file_path}

```python
{code}
```

專案上下文:
{context_str}

請找出以下類型的問題，並按格式輸出：
- 邏輯錯誤（可能導致錯誤行為）
- 程式碼異味（可讀性、維護性問題）
- 效能問題
- 邊界情況處理缺失

每行問題格式: LINE:{line}|SEVERITY:{error/warning/suggestion}|CATEGORY:{logic/style/performance}|MESSAGE:{說明}|SUGGESTION:{建議}

如果沒有問題，輸出 "NO_ISSUES"。
"""
        response = self.model_api.generate(prompt)

        if "NO_ISSUES" in response:
            return []

        comments = []
        for line in response.strip().split("\n"):
            line = line.strip()
            if not line.startswith("LINE:"):
                continue
            try:
                parts = line.split("|")
                comment_data = {}
                for part in parts:
                    key, _, value = part.partition(":")
                    comment_data[key.strip()] = value.strip()

                comments.append(ReviewComment(
                    file_path=file_path,
                    line_number=int(comment_data.get("LINE", "0")),
                    severity=comment_data.get("SEVERITY", "warning"),
                    category=comment_data.get("CATEGORY", "logic"),
                    message=comment_data.get("MESSAGE", ""),
                    suggestion=comment_data.get("SUGGESTION"),
                ))
            except (ValueError, KeyError):
                continue

        return comments

    def _security_review(self, code: str,
                          file_path: str) -> List[ReviewComment]:
        """安全審查"""
        security_patterns = [
            (r"eval\s*\(", "使用了 eval，可能導致程式碼注入", "error"),
            (r"exec\s*\(", "使用了 exec，可能導致程式碼注入", "error"),
            (r"subprocess\.(call|popen|run)\s*\(.*shell\s*=\s*True",
             "shell=True 存在命令注入風險", "error"),
            (r"pickle\.(loads|load)\s*\(",
             "使用 pickle 反序列化不可信的資料存在安全風險", "warning"),
            (r"os\.system\s*\(", "使用 os.system 可能導致命令注入", "error"),
            (r"sqlite3\.execute\s*\(\s*f[\"']",
             "使用 f-string 拼接 SQL 查詢可能導致 SQL 注入", "error"),
            (r"sqlite3\.execute\s*\(\s*['\"].*\+.*['\"]",
             "字串拼接 SQL 查詢可能導致 SQL 注入", "error"),
            (r"request\.(GET|POST|PUT|DELETE)\s*\(.*verify\s*=\s*False",
             "停用 SSL 憑證驗證", "warning"),
            (r"self\.request\.session\.headers\[.Authorization.\] = [^B]",
             "可能的硬編碼授權 Token", "warning"),
        ]

        comments = []
        lines = code.split("\n")
        for i, l in enumerate(lines, 1):
            for pattern, message, severity in security_patterns:
                if re.search(pattern, l):
                    comments.append(ReviewComment(
                        file_path=file_path,
                        line_number=i,
                        severity=severity,
                        category="security",
                        message=message,
                    ))
        return comments

    def _calculate_score(self, comments: List[ReviewComment]) -> float:
        score = 100.0
        for c in comments:
            if c.severity == "error":
                score -= 15.0
            elif c.severity == "warning":
                score -= 5.0
            else:
                score -= 2.0
        return max(0.0, score)

    def _should_pass(self, score: float,
                      comments: List[ReviewComment]) -> bool:
        errors = [c for c in comments if c.severity == "error"]
        if len(errors) > 2:
            return False
        if score < 60.0:
            return False
        return True

    def _generate_summary(self, result: ReviewResult) -> str:
        total = len(result.comments)
        by_severity = {}
        by_category = {}
        for c in result.comments:
            by_severity[c.severity] = by_severity.get(c.severity, 0) + 1
            by_category[c.category] = by_category.get(c.category, 0) + 1

        parts = [
            f"審查結果: {'通過' if result.passed else '未通過'}",
            f"評分: {result.score:.1f}/100",
            f"發現 {total} 個問題",
        ]
        if by_severity:
            parts.append(
                f"（嚴重程度: {', '.join(f'{k}: {v}' for k, v in by_severity.items())}）"
            )
        if by_category:
            parts.append(
                f"（分類: {', '.join(f'{k}: {v}' for k, v in by_category.items())}）"
            )
        return " | ".join(parts)

    def review_and_fix(self, code: str, file_path: str = "source.py",
                        max_fix_iterations: int = 3) -> Tuple[str, ReviewResult]:
        """審查並自動修復程式碼（完整的生成評估修正迴路）"""
        current_code = code
        for iteration in range(max_fix_iterations):
            result = self.review(current_code, file_path)

            if result.passed:
                print(f"在第 {iteration + 1} 輪後通過審查")
                return current_code, result

            errors = [
                c for c in result.comments
                if c.severity in ("error", "warning")
            ]
            if not errors:
                return current_code, result

            fix_prompt = self._build_fix_prompt(
                current_code, errors, file_path
            )
            response = self.model_api.generate(fix_prompt)
            current_code = self._extract_code(response)

            print(f"第 {iteration + 1} 輪修復: "
                  f"已修正 {len(errors)} 個問題")

        final_result = self.review(current_code, file_path)
        return current_code, final_result

    def _build_fix_prompt(self, code: str, errors: List[ReviewComment],
                           file_path: str) -> str:
        issues_text = "\n".join(
            f"- 第 {c.line_number} 行 [{c.severity}][{c.category}]: "
            f"{c.message}"
            + (f" 建議: {c.suggestion}" if c.suggestion else "")
            for c in errors[:10]
        )
        return f"""請修正以下程式碼中的問題：

檔案: {file_path}

```python
{code}
```

需要修正的問題:
{issues_text}

請輸出修正後的完整程式碼。"""

    def _extract_code(self, response: str) -> str:
        if "```" in response:
            parts = response.split("```")
            for i, part in enumerate(parts):
                if i % 2 == 1:
                    content = part.strip()
                    if content.startswith("python"):
                        content = content[6:].strip()
                    return content
        return response

這個案例展示了如何將 Loop Engineering 的各個元件整合成一個完整的 Code Review 系統。系統首先執行語法、型別、Lint 等自動化閘道檢查，然後進行 AI 邏輯審查和安全審查，最後根據審查結果計算評分並決定是否通過。如果未通過，系統會自動進入修復迴路，反覆修正直到品質達標或達到最大迭代次數。

Loop Engineering 的核心價值在於將 AI 的一次性輸出轉變為可控、可量測、可改善的工程流程，這也是 AI 軟體工程區別於單純使用 AI 寫程式的關鍵所在。
