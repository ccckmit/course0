# 第15章：Docker 與 AI 結合

容器化技術已成為現代軟體部署的標準方式。Docker 提供了輕量級的虛擬化，而 Kubernetes 則實現了大規模容器編排。AI 可以在容器化過程中提供智慧輔助，從 Dockerfile 生成到 Kubernetes 部署配置，大幅降低 DevOps 的工作負擔。本章將探討如何利用 AI 輔助容器化與編排的各個環節。

## 15.1 Dockerfile 生成

Dockerfile 是容器映像的建構藍圖。撰寫高效的 Dockerfile 需要對層快取、多階段建置和安全最佳實務有深入理解。AI 可以根據應用程式類型自動生成最佳化的 Dockerfile。

### 15.1.1 多階段建置

多階段建置（Multi-stage Build）是減少最終映像大小的關鍵技術。AI 可以自動分析應用程式的建置需求，生成合適的多階段 Dockerfile。

```dockerfile
# AI 生成的多階段 Dockerfile - Python 應用範例

# 第一階段：建置階段
FROM python:3.11-slim AS builder

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    libpq-dev \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .
RUN pip install --no-cache-dir --user -r requirements.txt

COPY src/ ./src/

# 第二階段：執行階段
FROM python:3.11-slim AS runtime

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq5 \
    curl \
    && rm -rf /var/lib/apt/lists/*

COPY --from=builder /root/.local /root/.local
COPY --from=builder /app/src ./src
COPY --from=builder /app/requirements.txt .

ENV PATH=/root/.local/bin:$PATH

RUN useradd -m -u 1000 appuser && chown -R appuser:appuser /app
USER appuser

HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
    CMD curl -f http://localhost:8000/health || exit 1

EXPOSE 8000

CMD ["uvicorn", "src.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 15.1.2 基礎映像選擇

選擇合適的基礎映像是 Dockerfile 最佳化的第一步。AI 可以根據應用程式的需求推薦最適合的基礎映像。常見的選擇包括 Alpine（最小體積）、Slim（精簡版）和 Distroless（僅包含執行環境）。AI 會根據語言和框架自動推薦。

```python
#!/usr/bin/env python3
# ai_dockerfile_gen.py - AI 輔助 Dockerfile 生成

import os
import json
from openai import OpenAI

def analyze_project():
    """分析專案結構以確定技術棧"""
    project_info = {
        "language": None,
        "framework": None,
        "has_requirements": os.path.exists("requirements.txt"),
        "has_package_json": os.path.exists("package.json"),
        "has_pom_xml": os.path.exists("pom.xml"),
        "has_go_mod": os.path.exists("go.mod"),
    }

    if project_info["has_requirements"]:
        project_info["language"] = "python"
        with open("requirements.txt") as f:
            content = f.read()
            if "fastapi" in content:
                project_info["framework"] = "fastapi"
            elif "django" in content:
                project_info["framework"] = "django"
            elif "flask" in content:
                project_info["framework"] = "flask"
    elif project_info["has_package_json"]:
        project_info["language"] = "node"
        with open("package.json") as f:
            pkg = json.load(f)
            deps = {**pkg.get("dependencies", {}), **pkg.get("devDependencies", {})}
            if "next" in deps:
                project_info["framework"] = "next"
            elif "react" in deps:
                project_info["framework"] = "react"
            elif "express" in deps:
                project_info["framework"] = "express"
    elif project_info["has_pom_xml"]:
        project_info["language"] = "java"
        project_info["framework"] = "spring" if "spring" in open("pom.xml").read() else "java"
    elif project_info["has_go_mod"]:
        project_info["language"] = "go"

    return project_info

def recommend_base_image(project_info):
    """根據專案資訊推薦基礎映像"""
    recommendations = {
        "python": {
            "fastapi": "python:3.11-slim",
            "django": "python:3.11-slim",
            "flask": "python:3.11-alpine",
            "default": "python:3.11-slim"
        },
        "node": {
            "next": "node:20-alpine",
            "react": "node:20-alpine AS build",
            "express": "node:20-alpine",
            "default": "node:20-alpine"
        },
        "java": {
            "spring": "eclipse-temurin:21-jre-alpine",
            "default": "eclipse-temurin:21-jre-alpine"
        },
        "go": {
            "default": "golang:1.22-alpine"
        }
    }

    lang = project_info.get("language")
    if not lang:
        return None

    framework = project_info.get("framework", "default")
    lang_recs = recommendations.get(lang, {})
    return lang_recs.get(framework, lang_recs.get("default"))

def generate_dockerfile(project_info):
    """使用 AI 生成 Dockerfile"""
    client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
    base_image = recommend_base_image(project_info)

    prompt = f"""根據以下專案資訊生成一個最佳化的 Dockerfile。

專案資訊：
- 語言：{project_info['language']}
- 框架：{project_info['framework']}
- 建議基礎映像：{base_image}
- 是否有 requirements.txt：{project_info['has_requirements']}
- 是否有 package.json：{project_info['has_package_json']}

要求：
1. 多階段建置
2. 適當的基礎映像選擇
3. 層快取最佳化
4. 非 root 使用者執行
5. 健康檢查
6. 安全最佳實務

輸出格式為 JSON：
{{
  "dockerfile": "完整的 Dockerfile 內容",
  "dockerignore": ".dockerignore 內容",
  "build_command": "建置指令"
}}"""

    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},
        temperature=0.3
    )

    return json.loads(response.choices[0].message.content)

def main():
    print("正在分析專案結構...")
    project_info = analyze_project()
    print(f"檢測到語言：{project_info['language']}")
    print(f"檢測到框架：{project_info['framework']}")

    result = generate_dockerfile(project_info)

    with open("Dockerfile", "w") as f:
        f.write(result["dockerfile"])
    print("Dockerfile 已生成")

    if result.get("dockerignore"):
        with open(".dockerignore", "w") as f:
            f.write(result["dockerignore"])
        print(".dockerignore 已生成")

    print(f"\n建置指令：{result.get('build_command', 'docker build -t app .')}")

if __name__ == "__main__":
    main()
```

### 15.1.3 層快取最佳化

Docker 建置過程中，每一條指令都會建立一個新層。AI 可以分析 Dockerfile 中的指令順序，提出快取最佳化建議。核心原則是將較少變更的指令放在前面。

```dockerfile
# 未最佳化的 Dockerfile（建置較慢）
FROM node:20-alpine
WORKDIR /app
COPY . .
RUN npm install
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]

# AI 最佳化後的 Dockerfile（利用層快取）
FROM node:20-alpine AS deps
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --only=production

FROM node:20-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-alpine AS runtime
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY --from=build /app/dist ./dist
COPY --from=build /app/package.json ./

USER node
EXPOSE 3000
HEALTHCHECK --interval=30s --timeout=3s \
    CMD wget --no-verbose --tries=1 --spider http://localhost:3000/health || exit 1

CMD ["node", "dist/server.js"]
```

層快取最佳化的核心檢查工具：

```python
# layer_cache_optimizer.py

def analyze_layer_cache(dockerfile_path):
    """分析 Dockerfile 的層快取效率"""
    with open(dockerfile_path) as f:
        lines = f.readlines()

    issues = []

    copy_instructions = []
    for i, line in enumerate(lines):
        stripped = line.strip()
        if stripped.startswith("COPY"):
            copy_instructions.append((i, stripped))

    for idx, (line_num, cmd) in enumerate(copy_instructions):
        if cmd == "COPY . ." or cmd == "COPY ./ ./":
            for j in range(line_num + 1, min(line_num + 10, len(lines))):
                if "RUN npm install" in lines[j] or "RUN pip install" in lines[j]:
                    issues.append({
                        "line": line_num + 1,
                        "severity": "critical",
                        "message": "在安裝依賴之前複製了所有檔案，每次原始碼變更都會觸發重新安裝",
                        "suggestion": "先複製 package.json/requirements.txt，安裝依賴後再複製原始碼"
                    })
                    break

    has_multi_stage = any("AS " in line for line in lines)
    if not has_multi_stage:
        issues.append({
            "line": 1,
            "severity": "warning",
            "message": "未使用多階段建置",
            "suggestion": "使用多階段建置可以減少最終映像大小"
        })

    run_count = sum(1 for line in lines if line.strip().startswith("RUN "))
    if run_count > 5:
        issues.append({
            "line": 1,
            "severity": "suggestion",
            "message": f"有 {run_count} 個 RUN 指令，過多的層會增加映像大小",
            "suggestion": "使用 && 合併相關的 RUN 指令"
        })

    return issues
```

### 15.1.4 安全最佳實務

AI 可以協助檢查 Dockerfile 中的安全問題，包括非 root 使用者執行、避免硬編碼機密、使用固定版本標籤等。

```dockerfile
# 安全的 Dockerfile 範例

FROM python:3.11-slim

RUN addgroup --system --gid 1001 appgroup \
    && adduser --system --uid 1001 --gid 1001 appuser

WORKDIR /app

RUN apt-get update && apt-get install -y --no-install-recommends \
    curl \
    ca-certificates \
    && rm -rf /var/lib/apt/lists/* \
    && apt-get clean

COPY requirements.txt .
RUN pip install --no-cache-dir --no-deps -r requirements.txt \
    && pip check

COPY --chown=appuser:appgroup src/ ./src/

USER appuser

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1 \
    PIP_NO_CACHE_DIR=1

HEALTHCHECK --interval=30s --timeout=3s --start-period=10s \
    CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"

EXPOSE 8000

CMD ["python", "src/main.py"]
```

```python
# dockerfile_security_scanner.py

import re

def scan_dockerfile_security(dockerfile_path):
    """掃描 Dockerfile 中的安全問題"""
    security_issues = []

    checks = {
        "root_user": {
            "pattern": "USER root",
            "severity": "high",
            "message": "使用 root 使用者執行應用程式",
            "suggestion": "新增非 root 使用者並切換"
        },
        "hardcoded_secret": {
            "pattern": r"(?:PASSWORD|SECRET|API_KEY|TOKEN)\s*=\s*['\"][^'\"]+['\"]",
            "severity": "critical",
            "message": "Dockerfile 中包含硬編碼的機密資訊",
            "suggestion": "使用 Docker Secret 或執行期環境變數"
        },
        "latest_tag": {
            "pattern": r"FROM\s+\S+:latest\b",
            "severity": "medium",
            "message": "使用 latest 標籤會導致不可重複的建置",
            "suggestion": "指定明確的版本標籤，如 python:3.11-slim"
        }
    }

    with open(dockerfile_path) as f:
        content = f.read()
        lines = content.split("\n")

    for check_name, check in checks.items():
        if check.get("pattern"):
            if re.search(check["pattern"], content, re.IGNORECASE):
                security_issues.append({
                    "check": check_name,
                    "severity": check["severity"],
                    "message": check["message"],
                    "suggestion": check["suggestion"]
                })

    has_user = any(line.strip().startswith("USER ") for line in lines)
    if not has_user:
        security_issues.append({
            "check": "no_user_switch",
            "severity": "high",
            "message": "未切換到非 root 使用者",
            "suggestion": "在 CMD 之前加入 USER 指令"
        })

    return security_issues
```

## 15.2 Docker Compose 編排

Docker Compose 用於定義和運行多容器應用程式。AI 可以根據服務架構自動生成 docker-compose.yml。

### 15.2.1 多服務配置

```python
#!/usr/bin/env python3
# compose_generator.py - AI 輔助 Docker Compose 生成

import json
import os
from openai import OpenAI

def detect_services():
    """檢測專案中的服務"""
    services = {}

    if os.path.exists("Dockerfile"):
        services["app"] = {
            "build": ".",
            "port": 8000,
            "type": "application"
        }

    if os.path.exists("requirements.txt"):
        with open("requirements.txt") as f:
            content = f.read()
            if "psycopg" in content or "psycopg2" in content:
                services["database"] = {
                    "image": "postgres:16-alpine",
                    "type": "database",
                    "port": 5432
                }
            if "redis" in content:
                services["redis"] = {
                    "image": "redis:7-alpine",
                    "type": "cache",
                    "port": 6379
                }

    if os.path.exists("package.json"):
        with open("package.json") as f:
            pkg = json.load(f)
            if "redis" in str(pkg.get("dependencies", {})):
                services["redis"] = {
                    "image": "redis:7-alpine",
                    "type": "cache",
                    "port": 6379
                }

    return services

def generate_compose_config(services):
    """使用 AI 生成 Docker Compose 配置"""
    client = OpenAI()

    prompt = f"""根據以下檢測到的服務，生成一個 Docker Compose 配置。

服務列表：
{json.dumps(services, indent=2)}

請輸出完整的 docker-compose.yml 內容（JSON 格式包裝）：
{{
  "compose": "docker-compose.yml 內容",
  "env_template": ".env.example 內容"
}}

要求：
1. 使用 version 3.8
2. 為每個服務添加健康檢查
3. 配置適當的網路和卷
4. 設定資源限制
5. 服務啟動順序（depends_on 搭配 condition）"""

    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"},
        temperature=0.3
    )

    return json.loads(response.choices[0].message.content)

def main():
    print("檢測服務中...")
    services = detect_services()

    if not services:
        print("未檢測到服務，將生成基本模板")
        services = {"app": {"build": ".", "port": 8000, "type": "application"}}

    result = generate_compose_config(services)

    with open("docker-compose.yml", "w") as f:
        f.write(result["compose"])
    print("docker-compose.yml 已生成")

    if result.get("env_template"):
        with open(".env.example", "w") as f:
            f.write(result["env_template"])
        print(".env.example 已生成")

if __name__ == "__main__":
    main()
```

## 15.3 Kubernetes 整合

AI 可以大幅簡化 Kubernetes 資源配置的撰寫過程，從 Deployment 到 Service、Ingress 等。

### 15.3.1 Deployment 配置

```python
#!/usr/bin/env python3
# k8s_gen.py - AI 輔助 Kubernetes 配置生成

import json
import os
from openai import OpenAI

def generate_k8s_manifests(app_name, container_image, replicas=3):
    """使用 AI 生成 Kubernetes 配置"""
    client = OpenAI()

    prompt = f"""為以下應用程式生成 Kubernetes 配置。

應用程式名稱：{app_name}
容器映像：{container_image}
副本數：{replicas}

請生成以下資源的 YAML 配置，以 JSON 格式輸出：
{{
  "deployment": "Deployment YAML",
  "service": "Service YAML",
  "configmap": "ConfigMap YAML",
  "hpa": "HPA YAML"
}}

要求：
1. Deployment 包含資源限制、存活探測、就緒探測
2. Service 使用 ClusterIP 類型
```

## 15.4 容器最佳化

AI 可以協助分析和最佳化容器映像，減少大小、加快啟動時間，並設定合理的資源限制。

### 15.4.1 映像大小最佳化

```python
#!/usr/bin/env python3
# image_optimizer.py

import subprocess
import json

def analyze_image_size(image_name):
    """分析 Docker 映像各層的大小"""
    result = subprocess.run(
        ["docker", "history", image_name, "--no-trunc", "--format", "{{.ID}} {{.CreatedBy}} {{.Size}}"],
        capture_output=True, text=True
    )

    layers = []
    for line in result.stdout.strip().split("\n"):
        parts = line.split(None, 2)
        if len(parts) == 3:
            layer_id, command, size = parts
            layers.append({
                "id": layer_id[:12],
                "command": command[:80],
                "size": size
            })

    return layers

def suggest_optimizations(layers):
    """根據層分析提供最佳化建議"""
    suggestions = []

    for layer in layers:
        size_str = layer["size"]
        command = layer["command"]

        if "GB" in size_str or "MB" in size_str:
            size_value = float(size_str.replace("GB", "").replace("MB", "").strip())
            if "GB" in layer["size"] or (size_value > 100 and "MB" in layer["size"]):
                if "apt-get" in command and "clean" not in command:
                    suggestions.append(f"層 {layer['id']} 較大（{size_str}），apt-get 後缺少清理")
                elif "npm install" in command:
                    suggestions.append(f"層 {layer['id']} 較大（{size_str}），考慮使用 npm ci --only=production")
                elif "pip install" in command:
                    suggestions.append(f"層 {layer['id']} 較大（{size_str}），考慮使用 --no-cache-dir")

    return suggestions
```

```python
#!/usr/bin/env python3
# image_vulnerability_scanner.py

import subprocess
import json

def scan_with_trivy(image_name):
    """使用 Trivy 掃描映像漏洞"""
    result = subprocess.run(
        ["trivy", "image", "--format", "json", "--severity", "CRITICAL,HIGH", image_name],
        capture_output=True, text=True
    )

    if result.returncode != 0:
        print(f"掃描失敗：{result.stderr}")
        return []

    scan_result = json.loads(result.stdout)
    vulnerabilities = []

    for result_entry in scan_result.get("Results", []):
        target = result_entry.get("Target", "unknown")
        for vuln in result_entry.get("Vulnerabilities", []):
            vulnerabilities.append({
                "package": vuln.get("PkgName"),
                "installed_version": vuln.get("InstalledVersion"),
                "fixed_version": vuln.get("FixedVersion"),
                "severity": vuln.get("Severity"),
                "cve_id": vuln.get("VulnerabilityID"),
                "target": target
            })

    return vulnerabilities

def ai_remediation_suggestion(vulnerability):
    """使用 AI 提供漏洞修復建議"""
    client = OpenAI()

    prompt = f"""以下是一個容器映像的安全漏洞：

套件：{vulnerability['package']}
目前版本：{vulnerability['installed_version']}
修復版本：{vulnerability['fixed_version']}
CVE ID：{vulnerability['cve_id']}
嚴重程度：{vulnerability['severity']}

請提供修復建議，包括：
1. 如何升級受影響的套件
2. 是否有替代方案
3. 如果無法立即升級的緩解措施"""

    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}]
    )

    return response.choices[0].message.content

def main():
    import sys
    image = sys.argv[1] if len(sys.argv) > 1 else "myapp:latest"

    print(f"正在掃描映像：{image}")
    vulns = scan_with_trivy(image)

    if not vulns:
        print("未發現嚴重或高風險漏洞")
        return

    print(f"發現 {len(vulns)} 個漏洞")
    for vuln in vulns[:5]:
        print(f"  - {vuln['cve_id']}: {vuln['package']} ({vuln['severity']})")

        if vuln.get("fixed_version") and vuln["fixed_version"] != "":
            print(f"    建議升級至：{vuln['fixed_version']}")

if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
# ai_deploy.py - AI 輔助部署工具

import subprocess
import json
import os
from openai import OpenAI

class AIDeployAssistant:
    def __init__(self):
        self.client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

    def validate_dockerfile(self):
        """驗證並最佳化 Dockerfile"""
        if not os.path.exists("Dockerfile"):
            print("Dockerfile 不存在，正在生成...")
            return False

        with open("Dockerfile") as f:
            content = f.read()

        prompt = f"""審查以下 Dockerfile 並提供改進建議：

{content}

檢查項目：
1. 多階段建置
2. 層快取順序
3. 安全問題
4. 基礎映像選擇
5. 映像大小

以 JSON 格式輸出建議。"""

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"}
        )

        return json.loads(response.choices[0].message.content)

    def validate_k8s_manifests(self):
        """驗證 Kubernetes 配置"""
        manifests = []
        for f in os.listdir("."):
            if f.startswith("k8s-") and f.endswith(".yml"):
                with open(f) as mf:
                    manifests.append({"file": f, "content": mf.read()})

        if not manifests:
            return {"error": "未找到 Kubernetes 配置檔案"}

        prompt = f"""審查以下 Kubernetes 配置：

{json.dumps(manifests, indent=2)}

檢查項目：
1. 資源限制是否設定
2. 安全上下文是否正確
3. 健康檢查是否配置
4. 映像標籤是否固定版本
5. 服務發現配置是否正確

以 JSON 格式輸出審查結果。"""

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"}
        )

        return json.loads(response.choices[0].message.content)

    def rollback_decision(self, deployment_name, namespace):
        """根據監控指標決定是否需要回滾"""
        metrics = subprocess.run(
            ["kubectl", "top", "pod", "-n", namespace, "--no-headers"],
            capture_output=True, text=True
        )

        logs = subprocess.run(
            ["kubectl", "logs", f"deployment/{deployment_name}", "-n", namespace, "--tail=50"],
            capture_output=True, text=True
        )

        prompt = f"""以下是部署 {deployment_name} 的監控資料，請判斷是否需要回滾：

Pod 資源使用：
{metrics.stdout[:1000]}

最近日誌：
{logs.stdout[:2000]}

請以 JSON 格式回答：
{{
  "should_rollback": true/false,
  "reason": "原因說明",
  "confidence": "高/中/低"
}}"""

        response = self.client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"}
        )

        return json.loads(response.choices[0].message.content)

def main():
    import argparse
    parser = argparse.ArgumentParser(description="AI 輔助部署工具")
    parser.add_argument("--validate-dockerfile", action="store_true", help="驗證 Dockerfile")
    parser.add_argument("--validate-k8s", action="store_true", help="驗證 K8s 配置")
    parser.add_argument("--check-rollback", help="檢查是否需要回滾（格式：deployment:namespace）")

    args = parser.parse_args()
    assistant = AIDeployAssistant()

    if args.validate_dockerfile:
        result = assistant.validate_dockerfile()
        print(json.dumps(result, indent=2, ensure_ascii=False))

    if args.validate_k8s:
        result = assistant.validate_k8s_manifests()
        print(json.dumps(result, indent=2, ensure_ascii=False))

    if args.check_rollback:
        parts = args.check_rollback.split(":")
        if len(parts) == 2:
            result = assistant.rollback_decision(parts[0], parts[1])
            if result.get("should_rollback"):
                print(f"建議回滾：{result['reason']}")
            else:
                print(f"部署正常：{result['reason']}")

if __name__ == "__main__":
    main()
```

### 15.6.4 完整部署腳本

```bash
#!/bin/bash
# deploy.sh - 完整部署腳本

set -e

APP_NAME="myapp"
NAMESPACE="production"
REGISTRY="ghcr.io/myorg"
VERSION=$(git rev-parse --short HEAD)

python3 ai_deploy.py --validate-dockerfile

docker push $REGISTRY/$APP_NAME:$VERSION
docker push $REGISTRY/$APP_NAME:latest

python3 ai_deploy.py --generate-k8s --app $APP_NAME \
    --image $REGISTRY/$APP_NAME:$VERSION

kubectl apply -f k8s-deployment.yml -n $NAMESPACE
kubectl apply -f k8s-service.yml -n $NAMESPACE
kubectl apply -f k8s-ingress.yml -n $NAMESPACE

echo "=== 步驟 7：監控部署進度 ==="
kubectl rollout status deployment/$APP_NAME -n $NAMESPACE --timeout=300s

echo "=== 部署完成 ==="
```

### 15.6.5 最佳實踐總結

使用 AI 輔助容器化和 Kubernetes 部署時，應遵循以下原則：

1. **不可變基礎設施**：每次部署都建立新的映像，絕不修改執行中的容器
2. **漸進式發布**：使用滾動更新或藍綠部署，逐步切換流量
3. **安全性優先**：在 CI 流程中整合漏洞掃描，使用最小權限映像
4. **可觀測性**：配置完善的健康檢查、日誌收集和監控告警
5. **基礎設施即程式碼**：將所有配置檔案納入版本控制，AI 生成的配置需經人工審查
6. **映像最小化**：盡可能減少映像大小，降低攻擊面並加速部署
7. **資源管理**：為每個容器設定合理的資源請求和限制
