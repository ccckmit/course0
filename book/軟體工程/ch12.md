# 第十二章：AI 與上線部署

## 12.1 概述

上線部署是軟體開發生命週期中最關鍵也最危險的環節之一。傳統上，部署流程依賴大量的手動操作與資深工程師的經驗判斷，這不僅耗時，也容易因人為失誤而導致服務中斷。隨著 AI 技術的成熟，越來越多團隊開始將 AI 整合到部署流程中，從 CI/CD Pipeline 的配置生成、部署腳本的最佳化，到基礎設施管理與監控告警，AI 正在重塑我們將程式碼送到生產環境的方式。

本章將深入探討 AI 如何輔助上線部署的各個面向，並透過實際的程式碼範例與案例研究，幫助讀者建立 AI 驅動的現代化部署思維。

## 12.2 CI/CD Pipeline 整合

### 12.2.1 Pipeline 配置生成

傳統的 CI/CD Pipeline 配置撰寫是一項繁瑣的工作。開發者需要熟悉各種 CI 平台的語法（如 GitHub Actions、GitLab CI、Jenkins Pipeline），並手動撰寫 YAML 配置檔。AI 可以透過學習既有專案的配置模式，自動生成符合需求的 Pipeline 配置。

以下是一個使用 AI 輔助生成的 GitHub Actions 配置範例：

```yaml
name: CI/CD Pipeline

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]
  release:
    types: [published]

env:
  REGISTRY: ghcr.io
  IMAGE_NAME: ${{ github.repository }}
  NODE_VERSION: 20

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ env.NODE_VERSION }}
          cache: npm
      - run: npm ci
      - run: npm run lint

  test:
    needs: lint
    runs-on: ubuntu-latest
    strategy:
      matrix:
        node-version: [18, 20, 22]
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: testpass
        ports:
          - 5432:5432
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: npm
      - run: npm ci
      - run: npm test
      - run: npm run test:e2e

  build:
    needs: test
    runs-on: ubuntu-latest
    outputs:
      digest: ${{ steps.build.outputs.digest }}
    steps:
      - uses: actions/checkout@v4
      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v3
      - name: Login to Container Registry
        uses: docker/login-action@v3
        with:
          registry: ${{ env.REGISTRY }}
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Build and push
        id: build
        uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ${{ env.REGISTRY }}/${{ env.IMAGE_NAME }}:${{ github.sha }}
          cache-from: type=gha
          cache-to: type=gha,mode=max
```

AI 可以分析專案的 package.json、Dockerfile 與資料庫配置，自動推導出上述的 Pipeline 結構。例如，偵測到專案使用 PostgreSQL 就會自動加入 services 定義；偵測到 monorepo 結構就會自動生成 matrix 策略。

### 12.2.2 建置腳本最佳化

建置腳本的效率直接影響開發者體驗與部署速度。AI 可以透過分析建置日誌與時間分佈，提出最佳化建議。以下是一些 AI 可以識別並改善的常見問題：

快取策略不當導致重複下載依賴、Docker 層級未充分利用導致建置時間過長、測試未平行化導致等待時間浪費。

AI 輔助優化後的 Dockerfile 範例：

```dockerfile
# 使用多階段建置減少最終映像大小
FROM node:20-alpine AS builder

WORKDIR /app

# 先複製依賴定義檔，利用 Docker 層級快取
COPY package.json package-lock.json ./
RUN npm ci --only=production

FROM node:20-alpine AS runner

WORKDIR /app

RUN addgroup --system app && adduser --system app

# 從 builder 階段複製已安裝的依賴
COPY --from=builder --chown=app:app /app/node_modules ./node_modules
COPY --chown=app:app . .

USER app

EXPOSE 3000

HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD wget --no-verbose --tries=1 --spider http://localhost:3000/health || exit 1

CMD ["node", "dist/index.js"]
```

AI 可以根據框架特性自動建議是否使用多階段建置、選擇合適的基底映像（如從 node:20 改為 node:20-alpine）、加入健康檢查指令、以及最佳化層級順序。

### 12.2.3 自動化發布

發布管理涉及版本號遞增、變更日誌生成、Git Tag 建立與 Release Note 撰寫。AI 可以根據 Git 提交訊息與 Pull Request 描述，自動產生結構化的 Release Note：

## 12.3 部署腳本生成

### 12.3.1 部署配置

部署配置因環境而異，AI 可以根據開發、測試、預發布、生產等不同環境的需求，自動生成對應的配置檔。以下是 AI 生成的部署腳本範例：

```python
#!/usr/bin/env python3
"""
AI 生成的部署腳本
根據環境變數與配置模板自動產生部署配置
"""
import os
import json
import subprocess
import sys
from pathlib import Path
from typing import Optional, Dict, Any
from dataclasses import dataclass, asdict
from string import Template


@dataclass
class DeployConfig:
    app_name: str
    environment: str
    region: str
    replicas: int
    cpu_limit: str
    memory_limit: str
    container_registry: str
    image_tag: str
    health_check_path: str
    database_url: str
    redis_url: str
    log_level: str


class ConfigGenerator:
    def __init__(self, template_dir: Path):
        self.template_dir = template_dir
        self.env_templates = {
            "development": {"replicas": 1, "cpu": "0.5", "memory": "512Mi", "log_level": "debug"},
            "staging": {"replicas": 2, "cpu": "1", "memory": "1Gi", "log_level": "info"},
            "production": {"replicas": 5, "cpu": "2", "memory": "2Gi", "log_level": "warn"},
        }

    def generate_config(self, environment: str, image_tag: str) -> DeployConfig:
        env_defaults = self.env_templates.get(environment, self.env_templates["development"])
        return DeployConfig(
            app_name=os.getenv("APP_NAME", "my-service"),
            environment=environment,
            region=os.getenv("REGION", "us-east-1"),
            replicas=env_defaults["replicas"],
            cpu_limit=env_defaults["cpu"],
            memory_limit=env_defaults["memory"],
            container_registry=os.getenv("CONTAINER_REGISTRY", "ghcr.io/myorg"),
            image_tag=image_tag,
            health_check_path="/health",
            database_url=self._resolve_database_url(environment),
            redis_url=self._resolve_redis_url(environment),
            log_level=env_defaults["log_level"],
        )

    def _resolve_database_url(self, environment: str) -> str:
        base = os.getenv("DATABASE_URL_BASE", "postgresql://user:pass@db.internal:5432")
        db_name = os.getenv("DB_NAME", "myapp")
        return f"{base}/{db_name}_{environment}"

    def _resolve_redis_url(self, environment: str) -> str:
        base = os.getenv("REDIS_URL_BASE", "redis://redis.internal:6379")
        return f"{base}/{environment}"


class DeploymentManager:
    def __init__(self, config: DeployConfig):
        self.config = config

    def validate_config(self) -> bool:
        required = ["app_name", "environment", "image_tag", "database_url"]
        for field in required:
            if not getattr(self.config, field, None):
                print(f"錯誤: 缺少必要的配置欄位 {field}")
                return False
        return True

    def create_kubernetes_manifest(self) -> Dict[str, Any]:
        return {
            "apiVersion": "apps/v1",
            "kind": "Deployment",
            "metadata": {
                "name": self.config.app_name,
                "labels": {
                    "app": self.config.app_name,
                    "env": self.config.environment,
                    "managed-by": "ai-deploy-tool",
                },
            },
            "spec": {
                "replicas": self.config.replicas,
                "strategy": {
                    "type": "RollingUpdate",
                    "rollingUpdate": {"maxUnavailable": "25%", "maxSurge": "25%"},
                },
                "selector": {"matchLabels": {"app": self.config.app_name}},
                "template": {
                    "metadata": {"labels": {"app": self.config.app_name}},
                    "spec": {
                        "containers": [
                            {
                                "name": self.config.app_name,
                                "image": f"{self.config.container_registry}/{self.config.app_name}:{self.config.image_tag}",
                                "ports": [{"containerPort": 3000}],
                                "resources": {
                                    "requests": {
                                        "cpu": self.config.cpu_limit,
                                        "memory": self.config.memory_limit,
                                    },
                                    "limits": {
                                        "cpu": self.config.cpu_limit,
                                        "memory": self.config.memory_limit,
                                    },
                                },
                                "env": [
                                    {"name": "NODE_ENV", "value": self.config.environment},
                                    {"name": "DATABASE_URL", "value": self.config.database_url},
                                    {"name": "REDIS_URL", "value": self.config.redis_url},
                                    {"name": "LOG_LEVEL", "value": self.config.log_level},
                                ],
                                "livenessProbe": {
                                    "httpGet": {"path": self.config.health_check_path, "port": 3000},
                                    "initialDelaySeconds": 10,
                                    "periodSeconds": 15,
                                },
                                "readinessProbe": {
                                    "httpGet": {"path": self.config.health_check_path, "port": 3000},
                                    "initialDelaySeconds": 5,
                                    "periodSeconds": 10,
                                },
                            }
                        ],
                        "imagePullSecrets": [{"name": "registry-credentials"}],
                    },
                },
            },
        }

    def deploy(self, dry_run: bool = False) -> bool:
        if not self.validate_config():
            return False
        manifest = self.create_kubernetes_manifest()
        manifest_path = f"deploy/{self.config.environment}/manifest.json"
        Path(manifest_path).parent.mkdir(parents=True, exist_ok=True)
        with open(manifest_path, "w") as f:
            json.dump(manifest, f, indent=2)
        if not dry_run:
            result = subprocess.run(
                ["kubectl", "apply", "-f", manifest_path],
                capture_output=True, text=True, check=False,
            )
            if result.returncode != 0:
                print(f"部署失敗: {result.stderr}")
                return False
            print(f"部署成功: {self.config.app_name} -> {self.config.environment}")
        return True


if __name__ == "__main__":
    env = sys.argv[1] if len(sys.argv) > 1 else "development"
    tag = sys.argv[2] if len(sys.argv) > 2 else "latest"
    generator = ConfigGenerator(Path("templates"))
    config = generator.generate_config(env, tag)
    manager = DeploymentManager(config)
    success = manager.deploy(dry_run=(env == "development"))
    sys.exit(0 if success else 1)
```

### 12.3.2 環境變數管理

環境變數的管理是部署過程中最容易出錯的環節之一。AI 可以幫助團隊維護環境變數的一致性，自動比對不同環境的變數差異，並偵測安全漏洞。

AI 輔助的環境變數驗證工具：

```python
"""
環境變數管理與驗證工具
AI 自動比對各環境的變數配置
"""
import os
import re
from typing import Dict, List, Optional, Set
from dataclasses import dataclass
from enum import Enum


class SecretLevel(Enum):
    PUBLIC = "public"
    INTERNAL = "internal"
    SECRET = "secret"
    CRITICAL = "critical"


@dataclass
class EnvVariable:
    name: str
    description: str
    secret_level: SecretLevel
    required: bool
    default_value: Optional[str] = None
    pattern: Optional[str] = None


class EnvValidator:
    def __init__(self):
        self.known_variables: Dict[str, EnvVariable] = {}

    def scan_source_code(self, source_dir: str) -> List[str]:
        detected = []
        pattern = re.compile(r"(?:process\.env\.|os\.getenv\(|env\()['\"](\w+)['\"]")
        for root, _dirs, files in os.walk(source_dir):
            for file in files:
                if file.endswith((".py", ".js", ".ts", ".yaml", ".yml")):
                    path = os.path.join(root, file)
                    try:
                        with open(path, "r") as f:
                            content = f.read()
                        matches = pattern.findall(content)
                        detected.extend(matches)
                    except (IOError, UnicodeDecodeError):
                        continue
        return list(set(detected))

    def validate_env_file(self, env_path: str, environment: str) -> List[str]:
        errors = []
        defined_vars: Set[str] = set()
        if os.path.exists(env_path):
            with open(env_path, "r") as f:
                for line in f:
                    line = line.strip()
                    if line and not line.startswith("#") and "=" in line:
                        name = line.split("=", 1)[0].strip()
                        defined_vars.add(name)
        for var_name, var_spec in self.known_variables.items():
            if var_spec.required and var_name not in defined_vars:
                errors.append(f"[{environment}] 缺少必要變數: {var_name}")
        for defined_var in defined_vars:
            if defined_var not in self.known_variables:
                errors.append(f"[{environment}] 未定義的變數: {defined_var}")
        return errors

    def check_secrets_in_code(self, source_dir: str) -> List[str]:
        warnings = []
        secret_patterns = [
            (r"password\s*=\s*['\"][^'\"]+['\"]", "密碼硬編碼"),
            (r"api[_-]?key\s*=\s*['\"][^'\"]+['\"]", "API Key 硬編碼"),
            (r"secret\s*=\s*['\"][^'\"]+['\"]", "Secret 硬編碼"),
            (r"token\s*=\s*['\"][^'\"]+['\"]", "Token 硬編碼"),
        ]
        for root, _dirs, files in os.walk(source_dir):
            for file in files:
                if file.endswith((".py", ".js", ".ts")):
                    path = os.path.join(root, file)
                    with open(path, "r") as f:
                        content = f.read()
                    for pattern, desc in secret_patterns:
                        if re.search(pattern, content, re.IGNORECASE):
                            warnings.append(f"[{path}] 可能的{desc}")
        return warnings


validator = EnvValidator()

validator.known_variables = {
    "DATABASE_URL": EnvVariable(
        name="DATABASE_URL",
        description="資料庫連線字串",
        secret_level=SecretLevel.CRITICAL,
        required=True,
    ),
    "REDIS_URL": EnvVariable(
        name="REDIS_URL",
        description="Redis 連線字串",
        secret_level=SecretLevel.SECRET,
        required=True,
    ),
    "LOG_LEVEL": EnvVariable(
        name="LOG_LEVEL",
        description="日誌等級",
        secret_level=SecretLevel.PUBLIC,
        required=False,
        default_value="info",
        pattern="^(debug|info|warn|error)$",
    ),
}

source_vars = validator.scan_source_code("./src")
print(f"原始碼中偵測到 {len(source_vars)} 個環境變數引用")
env_errors = validator.validate_env_file("./.env.production", "production")
for err in env_errors:
    print(f"驗證錯誤: {err}")
secret_warnings = validator.check_secrets_in_code("./src")
for w in secret_warnings:
    print(f"安全警告: {w}")
```

### 12.3.3 資料庫遷移

資料庫遷移是部署過程中最需要謹慎處理的部分。AI 可以分析資料庫 Schema 的變更，自動生成遷移腳本，並評估變更的風險等級。

AI 輔助的資料庫遷移分析工具：

```python
"""
資料庫變更分析與遷移生成
"""
import re
from typing import List, Tuple, Optional
from enum import Enum


class ChangeRisk(Enum):
    SAFE = "safe"
    WARNING = "warning"
    DANGEROUS = "dangerous"
    BLOCKING = "blocking"


class MigrationAnalyzer:
    def __init__(self):
        self.risk_patterns = {
            ChangeRisk.DANGEROUS: [
                r"DROP\s+TABLE",
                r"DROP\s+COLUMN",
                r"ALTER\s+COLUMN.*DROP\s+DEFAULT",
                r"ALTER\s+COLUMN.*TYPE\s+\w+",
            ],
            ChangeRisk.WARNING: [
                r"ALTER\s+TABLE.*ADD\s+COLUMN.*NOT\s+NULL",
                r"CREATE\s+INDEX",
                r"RENAME\s+TABLE",
                r"RENAME\s+COLUMN",
            ],
        }

    def analyze_sql(self, sql: str) -> List[Tuple[str, ChangeRisk, str]]:
        findings = []
        for risk_type, patterns in self.risk_patterns.items():
            for pattern in patterns:
                matches = re.finditer(pattern, sql, re.IGNORECASE)
                for match in matches:
                    findings.append((match.group(), risk_type, self._get_suggestion(risk_type)))
        return findings

    def _get_suggestion(self, risk: ChangeRisk) -> str:
        suggestions = {
            ChangeRisk.SAFE: "可以直接執行",
            ChangeRisk.WARNING: "建議在離峰時間執行，並準備回滾方案",
            ChangeRisk.DANGEROUS: "需要手動審查，建議使用多步驟遷移策略",
            ChangeRisk.BLOCKING: "會導致服務中斷，需要規劃停機窗口",
        }
        return suggestions.get(risk, "未知風險")

    def generate_rollback(self, sql: str) -> Optional[str]:
        rollback_map = {
            r"CREATE\s+TABLE\s+(\w+)": r"DROP TABLE IF EXISTS \1",
            r"DROP\s+TABLE\s+(\w+)": r"-- 無法自動回滾刪除表格 \1，需要從備份還原",
            r"ALTER\s+TABLE\s+(\w+)\s+ADD\s+COLUMN\s+(\w+)": r"ALTER TABLE \1 DROP COLUMN \2",
            r"ALTER\s+TABLE\s+(\w+)\s+DROP\s+COLUMN\s+(\w+)": r"-- 無法自動回滾刪除欄位 \1.\2",
        }
        for pattern, rollback in rollback_map.items():
            match = re.match(pattern, sql.strip(), re.IGNORECASE)
            if match:
                return rollback.format(*match.groups())
        return None

    def suggest_migration_steps(self, sql_statements: List[str]) -> List[str]:
        steps = []
        has_destructive = False
        for stmt in sql_statements:
            findings = self.analyze_sql(stmt)
            for _found, risk, _suggestion in findings:
                if risk in (ChangeRisk.DANGEROUS, ChangeRisk.BLOCKING):
                    has_destructive = True
                    break
        if has_destructive:
            steps.append("步驟 1: 在低流量時段執行遷移")
            steps.append("步驟 2: 先執行備份")
            steps.append("步驟 3: 分階段套用變更（先加欄位，再改資料，最後刪除）")
            steps.append("步驟 4: 啟用功能開關（Feature Flag）控制新程式碼") else:
            steps.append("步驟 1: 在 CI Pipeline 中執行遷移")
        steps.append("步驟 5: 驗證資料完整性")
        steps.append("步驟 6: 監控應用程式錯誤率")
        return steps


analyzer = MigrationAnalyzer()
sample_migration = """
ALTER TABLE users ADD COLUMN last_login_at TIMESTAMP;
ALTER TABLE users ADD COLUMN email_verified BOOLEAN NOT NULL DEFAULT false;
CREATE INDEX idx_users_email ON users(email);
ALTER TABLE orders DROP COLUMN legacy_status;
"""

findings = analyzer.analyze_sql(sample_migration)
print("=== 遷移風險分析 ===")
for found, risk, suggestion in findings:
    print(f"[{risk.value}] {found}")
    print(f"  建議: {suggestion}")

print("\n=== 回滾方案 ===")
for stmt in sample_migration.strip().split("\n"):
    stmt = stmt.strip()
    if stmt:
        rollback = analyzer.generate_rollback(stmt)
        if rollback:
            print(f"原指令: {stmt}")
            print(f"回滾: {rollback}\n")

print("\n=== 遷移步驟建議 ===")
steps = analyzer.suggest_migration_steps(sample_migration.strip().split("\n"))
for step in steps:
    print(step)
```

## 12.4 基礎設施即程式碼 (IaC)

### 12.4.1 Terraform 配置生成

AI 可以根據應用程式的需求描述，自動生成 Terraform 或 Pulumi 的基礎設施配置。以下是一個 AI 生成的 Terraform 配置範例：

```hcl
# 由 AI 根據應用需求生成的 Terraform 配置

terraform {
  required_version = ">= 1.6"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
    random = {
      source  = "hashicorp/random"
      version = "~> 3.5"
    }
  }
  backend "s3" {
    bucket         = "myorg-terraform-state"
    key            = "production/terraform.tfstate"
    region         = "us-east-1"
    encrypt        = true
    dynamodb_table = "terraform-state-lock"
  }
}

provider "aws" {
  region = var.aws_region
  default_tags {
    tags = {
      Environment = var.environment
      ManagedBy   = "terraform"
      Project     = var.project_name
    }
  }
}

# VPC 網路設定
module "vpc" {
  source = "terraform-aws-modules/vpc/aws"
  version = "5.5.0"

  name = "${var.environment}-vpc"
```

```python
"""
雲端資源成本分析與建議工具
"""
from typing import Dict, List, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta


@dataclass
class ResourceMetrics:
    cpu_avg: float
    cpu_p95: float
    memory_avg: float
    memory_p95: float
    request_count: int
    error_rate: float
    latency_p95: float


@dataclass
class CostOptimizationSuggestion:
    resource: str
    current_cost: float
    estimated_saving: float
    suggestion: str
    risk: str


class ResourcePlanner:
    def __init__(self):
        self.instance_pricing = {
            "t3.medium": {"vcpu": 2, "memory_gb": 4, "hourly": 0.0416},
            "t3.large": {"vcpu": 2, "memory_gb": 8, "hourly": 0.0832},
            "t3.xlarge": {"vcpu": 4, "memory_gb": 16, "hourly": 0.1664},
            "c6i.xlarge": {"vcpu": 4, "memory_gb": 8, "hourly": 0.1700},
            "r6i.xlarge": {"vcpu": 4, "memory_gb": 32, "hourly": 0.2016},
        }

    def analyze_resource_usage(self, metrics: ResourceMetrics) -> List[CostOptimizationSuggestion]:
        suggestions = []
        if metrics.cpu_avg < 20 and metrics.memory_avg < 40:
            suggestions.append(
                CostOptimizationSuggestion(
                    resource="運算資源",
                    current_cost=self._estimate_monthly_cost("t3.large"),
                    estimated_saving=self._estimate_monthly_cost("t3.large") * 0.5,
                    suggestion="CPU 與記憶體使用率偏低，建議降級至 t3.medium 規格",
                    risk="低風險，若流量突然增加可設定自動擴展",
                )
            )
        elif metrics.cpu_p95 > 80 and metrics.latency_p95 > 1000:
            suggestions.append(
                CostOptimizationSuggestion(
                    resource="運算資源",
                    current_cost=self._estimate_monthly_cost("t3.large"),
                    estimated_saving=0,
                    suggestion="CPU 使用率達 80% 且延遲偏高，建議升級至 c6i.xlarge",
                    risk="中等風險，升級期間可能需重新啟動服務",
                )
            )
        return suggestions

    def _estimate_monthly_cost(self, instance_type: str) -> float:
        pricing = self.instance_pricing.get(instance_type, {})
        hourly = pricing.get("hourly", 0)
        return hourly * 24 * 30

    def forecast_capacity(
        self,
        current_requests_per_sec: float,
        growth_rate: float,
        months: int
    ) -> List[Dict]:
        forecasts = []
        for month in range(1, months + 1):
            projected_rps = current_requests_per_sec * ((1 + growth_rate) ** month)
            required_instances = max(1, int(projected_rps / 100) + 1)
            forecasts.append({
                "month": month,
                "projected_rps": round(projected_rps, 2),
                "required_instances": required_instances,
                "estimated_monthly_cost": required_instances * self._estimate_monthly_cost("t3.large"),
            })
        return forecasts

    latency_p95=250,
```

```python
"""
AI 日誌分析與異常偵測工具
"""
import re
import json
from collections import Counter, defaultdict
from typing import List, Dict, Optional, Tuple
from datetime import datetime, timedelta


class LogEntry:
    def __init__(self, timestamp: str, level: str, service: str, message: str):
        self.timestamp = timestamp
        self.level = level
        self.service = service
        self.message = message
        self.parsed_time = datetime.fromisoformat(timestamp) if timestamp else datetime.now()

    @classmethod
    def from_json(cls, line: str) -> Optional["LogEntry"]:
        try:
            data = json.loads(line)
            return cls(
                timestamp=data.get("timestamp", ""),
                level=data.get("level", "INFO"),
                service=data.get("service", "unknown"),
                message=data.get("message", ""),
            )
        except (json.JSONDecodeError, KeyError):
            return None


class LogAnalyzer:
    def __init__(self, window_minutes: int = 5):
        self.window_minutes = window_minutes
        self.recent_errors: List[LogEntry] = []
        self.error_patterns: Dict[str, int] = Counter()
        self.known_anomalies: Dict[str, str] = {
            "connection refused": "資料庫或快取服務無法連線",
            "out of memory": "記憶體不足，需要增加容器資源限制",
            "deadlock detected": "資料庫死結，需要檢查交易順序",
            "timeout": "請求逾時，可能是外部服務回應緩慢",
            "rate limit": "API 速率限制已達上限",
            "permission denied": "權限不足，請檢查 IAM 角色設定",
            "disk full": "磁碟空間不足，需要清理或擴充儲存空間",
            "segmentation fault": "嚴重的記憶體存取錯誤，可能需要修復程式碼",
            "null pointer": "空指標異常，請檢查物件是否為 null",
            "circuit breaker": "斷路器已開啟，下游服務不穩定",
        }

    def ingest_log(self, log_entry: LogEntry) -> Optional[Dict]:
        window_start = datetime.now() - timedelta(minutes=self.window_minutes)
        analysis_result = None

        if log_entry.level in ("ERROR", "CRITICAL", "FATAL"):
            self.recent_errors.append(log_entry)
            for pattern, description in self.known_anomalies.items():
                if re.search(pattern, log_entry.message, re.IGNORECASE):
                    self.error_patterns[pattern] += 1
                    count = self.error_patterns[pattern]
                    if count >= 5:
                        analysis_result = {
                            "alert": "known_anomaly",
                            "pattern": pattern,
                            "description": description,
                            "frequency": count,
                            "suggestion": self._generate_suggestion(pattern),
                            "recent_examples": [
                                e.message for e in self.recent_errors[-3:]
                            ],
                        }
                    break
            unusual_pattern = self._detect_unusual_pattern(log_entry)
            if unusual_pattern:
                analysis_result = analysis_result or {}
                analysis_result.update(unusual_pattern)

        self.recent_errors = [e for e in self.recent_errors if e.parsed_time > window_start]
        return analysis_result

    def _detect_unusual_pattern(self, entry: LogEntry) -> Optional[Dict]:
        duration_match = re.search(r"took\s+(\d+)\s*ms", entry.message)
        if duration_match:
            duration = int(duration_match.group(1))
            if duration > 5000:
                return {
                    "alert": "slow_query",
                    "duration_ms": duration,
                    "severity": "warning",
                    "suggestion": "此查詢耗時超過 5 秒，建議檢查資料庫索引",
                }
        retry_match = re.search(r"retry\s+(\d+)", entry.message)
        if retry_match:
            retries = int(retry_match.group(1))
            if retries > 3:
                return {
                    "alert": "excessive_retries",
                    "retry_count": retries,
                    "severity": "warning",
                    "suggestion": "重試次數過多，下游服務可能不穩定",
                }
        return None

    def _generate_suggestion(self, pattern: str) -> str:
        suggestions = {
            "connection refused": "檢查資料庫或 Redis 服務狀態，確認連線字串與安全群組設定",
            "out of memory": "增加容器記憶體限制，檢查是否有記憶體洩漏（memory leak）",
            "deadlock detected": "調整交易隔離等級，縮短交易時間，確保一致的鎖定順序",
            "timeout": "增加逾時設定，檢查外部服務延遲，考慮使用非同步處理",
            "rate limit": "檢討 API 呼叫頻率，實作快取策略，申請提高配額",
        }
        return suggestions.get(pattern, "請查看內部 Runbook 取得詳細處理步驟")

    def generate_summary_report(self) -> Dict:
        total = len(self.recent_errors)
        by_service = Counter(e.service for e in self.recent_errors)
        by_minute = Counter()
        for e in self.recent_errors:
            minute_key = e.parsed_time.strftime("%H:%M")
            by_minute[minute_key] += 1
        return {
            "total_errors": total,
            "errors_by_service": dict(by_service.most_common(5)),
            "errors_by_minute": dict(sorted(by_minute.items())),
            "top_patterns": dict(self.error_patterns.most_common(5)),
            "window_minutes": self.window_minutes,
        }
```

## 12.6 滾動更新與零停機部署

### 12.6.1 策略建議

零停機部署（Zero Downtime Deployment）是現代服務的基本要求。AI 可以根據服務的特性與基礎設施環境，建議最適合的部署策略：

滾動更新（Rolling Update）：逐步替換舊版本的執行個體，適合大多數無狀態服務。藍綠部署（Blue-Green）：同時運行兩套完整的環境，一次性切換流量，適合需要完整驗證的服務。金絲雀發布（Canary Release）：先讓少量使用者使用新版本，逐步增加流量比例，適合高風險的重大變更。

### 12.6.2 健康檢查

健康檢查是確保部署成功與否的關鍵機制。以下是一個綜合性的健康檢查配置範例：

```python
"""
健康檢查工具 - 用於部署驗證與持續監控
"""
import json
import time
import subprocess
from typing import Dict, List, Optional
from dataclasses import dataclass
from urllib.request import urlopen, Request
from urllib.error import URLError


@dataclass
class HealthCheckResult:
    component: str
    status: str
    latency_ms: float
    detail: str
    suggestion: Optional[str] = None


class DeploymentHealthChecker:
    def __init__(self, base_url: str, timeout: int = 10):
        self.base_url = base_url
        self.timeout = timeout
        self.checks: List[HealthCheckResult] = []

    def check_http_endpoint(self, path: str, expected_status: int = 200) -> HealthCheckResult:
        start = time.time()
        url = f"{self.base_url}{path}"
        try:
            req = Request(url)
            response = urlopen(req, timeout=self.timeout)
            elapsed = (time.time() - start) * 1000
            if response.status == expected_status:
                return HealthCheckResult(
                    component=path,
                    status="pass",
                    latency_ms=round(elapsed, 2),
                    detail=f"HTTP {response.status}",
                )
            return HealthCheckResult(
                component=path, status="fail",
                latency_ms=round(elapsed, 2),
                detail=f"HTTP {response.status}, 預期 {expected_status}",
                suggestion="檢查應用程式是否正確啟動，以及路由設定",
            )
        except URLError as e:
            elapsed = (time.time() - start) * 1000
            return HealthCheckResult(
                component=path, status="fail",
                latency_ms=round(elapsed, 2),
                detail=str(e.reason),
                suggestion="確認 URL 是否正確，防火牆規則是否允許連線",
            )

    def check_database_connection(self) -> HealthCheckResult:
        start = time.time()
        try:
            result = subprocess.run(
                ["pg_isready", "-h", "localhost", "-p", "5432", "-t", "5"],
                capture_output=True, text=True, timeout=10, check=False,
            )
            elapsed = (time.time() - start) * 1000
            if result.returncode == 0:
                return HealthCheckResult(
                    component="database", status="pass",
                    latency_ms=round(elapsed, 2),
                    detail=result.stdout.strip(),
                )
            return HealthCheckResult(
                component="database", status="fail",
                latency_ms=round(elapsed, 2),
                detail=result.stderr.strip(),
                suggestion="檢查資料庫服務是否運行，連線字串是否正確",
            )
        except subprocess.TimeoutExpired:
            return HealthCheckResult(
                component="database", status="fail",
                latency_ms=0, detail="資料庫連線逾時",
                suggestion="請確認資料庫伺服器是否正常運行",
            )

    def check_disk_space(self, threshold_percent: float = 90.0) -> HealthCheckResult:
        start = time.time()
        result = subprocess.run(
            ["df", "-h", "/"],
            capture_output=True, text=True, timeout=5, check=False,
        )
        elapsed = (time.time() - start) * 1000
        lines = result.stdout.strip().split("\n")
        if len(lines) >= 2:
            parts = lines[1].split()
            if len(parts) >= 5:
                usage_str = parts[4].replace("%", "")
                usage = float(usage_str)
                detail = f"磁碟使用率: {usage}%"
                if usage < threshold_percent:
                    return HealthCheckResult(
                        component="disk", status="pass",
                        latency_ms=round(elapsed, 2), detail=detail,
                    )
                return HealthCheckResult(
                    component="disk", status="warn",
                    latency_ms=round(elapsed, 2), detail=detail,
                    suggestion=f"磁碟使用率 {usage}% 超過閾值 {threshold_percent}%，建議清理或擴充",
                )
        return HealthCheckResult(
            component="disk", status="error",
            latency_ms=round(elapsed, 2), detail="無法解析磁碟使用資訊",
        )

    def run_all_checks(self) -> List[HealthCheckResult]:
        endpoints = ["/health", "/ready", "/metrics"]
        for ep in endpoints:
            self.checks.append(self.check_http_endpoint(ep))
        self.checks.append(self.check_database_connection())
        self.checks.append(self.check_disk_space(85.0))
        return self.checks

    def generate_report(self) -> Dict:
        passed = sum(1 for c in self.checks if c.status == "pass")
        warnings = sum(1 for c in self.checks if c.status == "warn")
        failed = sum(1 for c in self.checks if c.status == "fail")
        return {
            "status": "healthy" if failed == 0 else "unhealthy",
            "summary": {
                "total": len(self.checks),
                "passed": passed,
                "warnings": warnings,
                "failed": failed,
            },
            "checks": [
                {"component": c.component, "status": c.status, "latency_ms": c.latency_ms}
                for c in self.checks
            ],
        }


checker = DeploymentHealthChecker("http://localhost:3000")
results = checker.run_all_checks()
report = checker.generate_report()
print(json.dumps(report, ensure_ascii=False, indent=2))
for c in results:
    if c.status != "pass":
        print(f"注意 [{c.component}]: {c.suggestion}")
```

### 12.6.3 回滾方案

完善的回滾方案是零停機部署的重要保障。AI 可以根據部署的變更類型與影響範圍，自動產生對應的回滾腳本：

```bash
#!/bin/bash
# AI 生成的回滾腳本
# 根據部署類型自動選擇回滾策略

set -euo pipefail

ENVIRONMENT="${1:-production}"
ROLLBACK_TO="${2:-previous}"
SERVICE_NAME="${3:-my-service}"

echo "=== 啟動回滾流程 ==="
echo "環境: $ENVIRONMENT"
echo "目標版本: $ROLLBACK_TO"

# 步驟 1: 保存當前版本資訊（用於緊急恢復）
echo "[1/6] 記錄當前版本資訊..."
kubectl get deployment "$SERVICE_NAME" -n "$ENVIRONMENT" \
  -o jsonpath='{.spec.template.spec.containers[0].image}' \
  > "/tmp/current-image-${SERVICE_NAME}.txt"
echo "當前映像: $(cat /tmp/current-image-${SERVICE_NAME}.txt)"

# 步驟 2: 執行 Kubernetes 滾動回滾
echo "[2/6] 執行 Kubernetes Rollback..."
if [ "$ROLLBACK_TO" = "previous" ]; then
  kubectl rollout undo deployment/"$SERVICE_NAME" -n "$ENVIRONMENT"
elif [ "$ROLLBACK_TO" = "stable" ]; then
  # 回滾到特定的 revision
  STABLE_REVISION=$(kubectl rollout history deployment/"$SERVICE_NAME" -n "$ENVIRONMENT" \
    | grep -i "stable\|healthy" | tail -1 | awk '{print $1}')
  if [ -n "$STABLE_REVISION" ]; then
    kubectl rollout undo deployment/"$SERVICE_NAME" -n "$ENVIRONMENT" --to-revision="$STABLE_REVISION"
  fi
fi

# 步驟 3: 等待部署穩定
echo "[3/6] 等待部署穩定..."
kubectl rollout status deployment/"$SERVICE_NAME" -n "$ENVIRONMENT" --timeout=5m

# 步驟 4: 驗證健康檢查
echo "[4/6] 執行健康檢查..."
for i in {1..10}; do
  STATUS=$(curl -so /dev/null -w "%{http_code}" "http://${SERVICE_NAME}.${ENVIRONMENT}.internal/health")
  if [ "$STATUS" = "200" ]; then
    echo "健康檢查通過 (嘗試 $i)"
    break
  fi
  if [ "$i" = "10" ]; then
    echo "健康檢查失敗，觸發緊急程序"
    # 還原回新版本
    kubectl set image deployment/"$SERVICE_NAME" \
      -n "$ENVIRONMENT" \
      "$SERVICE_NAME=$(cat /tmp/current-image-${SERVICE_NAME}.txt)"
    exit 1
  fi
  sleep 3
done

# 步驟 5: 驗證資料庫遷移
echo "[5/6] 驗證資料庫狀態..."
python3 -c "
import psycopg2
conn = psycopg2.connect('postgresql://user:pass@db.internal/proddb')
cur = conn.cursor()
cur.execute('SELECT version(), current_timestamp')
row = cur.fetchone()
print(f'資料庫版本: {row[0]}')
print(f'當前時間: {row[1]}')
cur.close()
conn.close()
"

# 步驟 6: 更新監控告警
echo "[6/6] 通知監控系統..."
curl -X POST "http://alertmanager.internal/api/v1/alerts" \
  -H "Content-Type: application/json" \
  -d "[{
    \"labels\": {
      \"alertname\": \"deployment_rollback\",
      \"service\": \"${SERVICE_NAME}\",
      \"environment\": \"${ENVIRONMENT}\",
      \"severity\": \"warning\"
    },
    \"annotations\": {
      \"summary\": \"部署已回滾\",
      \"description\": \"${SERVICE_NAME} 在 ${ENVIRONMENT} 環境已回滾至先前版本\"
    }
  }]"

echo "=== 回滾完成 ==="
```

## 12.8 案例：從 PR Merge 到生產環境的完整流程

本節展示一個完整的 AI 輔助部署流程，從 Pull Request 合併開始，一直到程式碼安全抵達生產環境。

### 12.8.1 流程總覽

AI 驅動的端到端部署流程包含以下自動化階段：

階段一：PR Merge 觸發 CI Pipeline。AI 會分析變更內容，決定需要執行的測試套件與檢查項目。例如，若變更僅涉及前端程式碼，則不需要執行後端整合測試。

階段二：自動化建置與測試。AI 最佳化建置腳本，根據專案類型選擇合適的快取策略，並平行化執行測試。

階段三：基礎設施變更評估。AI 比對 Terraform 狀態文件，偵測基礎設施的變更，執行風險評估。

階段四：資料庫遷移執行。AI 分析 SQL 變更的風險等級，決定是否需要在部署前或部署後執行遷移。

階段五：部署至預發布環境。AI 在預發布環境執行整合驗證，包括回歸測試、效能測試與安全掃描。

階段六：金絲雀發布。AI 根據服務的歷史數據決定初始流量比例（通常為 5-10%），監控錯誤率與延遲指標，逐步增加流量。

階段七：全面發布。在確認新版本穩定後，AI 將流量全數切換至新版本，並更新 DNS 與 CDN 快取。

### 12.8.2 實際流程程式碼

以下是一個 AI 驅動的部署協調器範例：

```python
"""
AI 驅動的部署協調器
實作從 PR Merge 到生產環境的完整自動化流程
"""
import json
import time
import subprocess
from typing import Dict, List, Optional
from dataclasses import dataclass, asdict
from enum import Enum


class DeployStage(Enum):
    CI_TRIGGER = "ci_trigger"
    BUILD_TEST = "build_test"
    INFRA_CHECK = "infra_check"
    DB_MIGRATION = "db_migration"
    STAGING_DEPLOY = "staging_deploy"
    CANARY_RELEASE = "canary_release"
    FULL_ROLLOUT = "full_rollout"
    COMPLETE = "complete"
    ROLLED_BACK = "rolled_back"


@dataclass
class DeployContext:
    pr_number: int
    commit_sha: str
    branch: str
    environment: str
    current_stage: DeployStage
    ai_recommendations: Dict
    metrics: Dict
    errors: List[str]
    started_at: float
    completed_at: Optional[float] = None


class AIDeployOrchestrator:
    def __init__(self):
        self.ctx: Optional[DeployContext] = None

    def start_deploy(self, pr_number: int, commit_sha: str, branch: str, environment: str):
        self.ctx = DeployContext(
            pr_number=pr_number,
            commit_sha=commit_sha,
            branch=branch,
            environment=environment,
            current_stage=DeployStage.CI_TRIGGER,
            ai_recommendations={},
            metrics={},
            errors=[],
            started_at=time.time(),
        )
        print(f"開始部署 PR #{pr_number} ({commit_sha[:8]}) 至 {environment}")

    def stage_ci_trigger(self) -> bool:
        print("[階段 1/7] 觸發 CI Pipeline")
        ai_analysis = self._analyze_changes()
        self.ctx.ai_recommendations["test_strategy"] = ai_analysis
        result = self._run_command([
            "gh", "run", "list", "--workflow=ci.yml",
            "--json=databaseId,status",
        ])
        print(f"AI 分析結果: 需要執行 {len(ai_analysis.get('required_tests', []))} 個測試套件")
        return True

    def _analyze_changes(self) -> Dict:
        result = self._run_command([
            "git", "diff", "--name-only", f"origin/main...{self.ctx.branch}",
        ])
        changed_files = result.split("\n") if result else []
        analysis = {"changed_files": changed_files, "required_tests": []}
        has_backend = any(f.startswith("src/backend/") for f in changed_files if f)
        has_frontend = any(f.startswith("src/frontend/") for f in changed_files if f)
        has_infra = any(f.startswith("infra/") for f in changed_files if f)
        has_migration = any(f.endswith(".sql") or "migration" in f for f in changed_files if f)
        if has_backend:
            analysis["required_tests"].extend(["unit", "integration", "api"])
        if has_frontend:
            analysis["required_tests"].extend(["unit", "e2e"])
        if has_infra:
            analysis["risk_level"] = "high"
            analysis["notes"] = "基礎設施變更需要 DevOps 團隊審查"
        if has_migration:
            analysis["risk_level"] = "critical"
            analysis["notes"] = "資料庫 Migration 需要特別謹慎處理"
        return analysis

    def stage_build_test(self) -> bool:
        print("[階段 2/7] 建置與測試")
        dockerfile = self._read_file("Dockerfile")
        ai_optimization = self._optimize_dockerfile(dockerfile)
        self.ctx.metrics["build_time_estimate"] = ai_optimization.get("estimated_time", 120)
        build_cmd = [
            "docker", "build",
            "--cache-from", "type=gha",
            "--cache-to", "type=gha,mode=max",
            "-t", f"app:{self.ctx.commit_sha}",
            ".",
        ]
        success = self._run_command(build_cmd, check=True) is not None
        if success:
            test_cmds = ["npm run test:unit", "npm run test:integration", "npm run lint"]
            for cmd in test_cmds:
                result = self._run_command(cmd.split(), timeout=300)
                if result is None:
                    self.ctx.errors.append(f"測試失敗: {cmd}")
                    return False
        return True

    def _optimize_dockerfile(self, content: str) -> Dict:
        suggestions = {}
        if "npm install" in content and "npm ci" not in content:
            suggestions["suggestion"] = "建議改用 npm ci 以獲得確定性建置"
        if "AS builder" not in content:
            suggestions["suggestion"] = "建議使用多階段建置以減小映像大小"
        if "RUN npm install" in content:
            suggestions["cache_strategy"] = "將 package.json 複製分開以利用 Docker 層級快取"
        return suggestions

    def stage_infra_check(self) -> bool:
        print("[階段 3/7] 基礎設施檢查")
        if not self._check_terraform():
            self.ctx.errors.append("Terraform 驗證失敗")
            return False
        if not self._check_security():
            self.ctx.errors.append("安全性掃描發現問題")
            return False
        if not self._check_secrets():
            self.ctx.errors.append("環境變數檢查發現問題")
            return False
        self.ctx.ai_recommendations["infra_approved"] = True
        return True

    def _check_terraform(self) -> bool:
        result = self._run_command(["terraform", "fmt", "-check", "-recursive"], timeout=60)
        if result is None:
            self._run_command(["terraform", "fmt", "-recursive"], timeout=60)
            print("Terraform 格式已自動修正")
        plan = self._run_command(["terraform", "plan", "-out=tfplan"], timeout=120)
        return plan is not None

    def _check_security(self) -> bool:
        scanners = [
            (["trivy", "filesystem", "--severity=CRITICAL", "."], "Trivy"),
            (["npm", "audit", "--audit-level=high"], "npm audit"),
        ]
        for cmd, name in scanners:
            result = self._run_command(cmd, timeout=120)
            if result is None:
                print(f"安全性掃描失敗: {name}")
                return False
        return True

    def _check_secrets(self) -> bool:
        result = self._run_command(
            ["gitleaks", "detect", "--no-git", "--verbose"],
            timeout=60,
        )
        return result is not None

    def stage_db_migration(self) -> bool:
        print("[階段 4/7] 資料庫遷移")
        migration_files = self._find_migration_files()
        for mf in migration_files:
            sql = self._read_file(mf)
            risk = self._analyze_migration_risk(sql)
            if risk == "critical":
                print(f"Migration {mf} 風險評估: 高風險，需要手動確認")
                confirm = input(f"確認執行 {mf}? (yes/no): ")
                if confirm != "yes":
                    return False
            print(f"執行 Migration: {mf}")
            result = self._run_command(
                ["psql", "-f", mf], timeout=60,
            )
            if result is None:
                self.ctx.errors.append(f"Migration 失敗: {mf}")
                rollback = self._generate_rollback(sql)
                if rollback:
                    self._run_command(["psql", "-c", rollback], timeout=60)
                return False
        return True

    def _find_migration_files(self) -> List[str]:
        result = self._run_command(
            ["find", "migrations", "-name", "*.sql", "|", "sort"],
            timeout=10,
        )
        return result.strip().split("\n") if result else []

    def _analyze_migration_risk(self, sql: str) -> str:
        dangerous = ["DROP TABLE", "DROP COLUMN", "ALTER COLUMN", "RENAME"]
        for pattern in dangerous:
            if pattern.lower() in sql.lower():
                return "critical"
        return "normal"

    def _generate_rollback(self, sql: str) -> Optional[str]:
        import re
        create_match = re.search(r"CREATE\s+TABLE\s+(\w+)", sql, re.IGNORECASE)
        if create_match:
            return f"DROP TABLE IF EXISTS {create_match.group(1)};"
        alter_match = re.search(r"ALTER\s+TABLE\s+(\w+)\s+ADD\s+COLUMN\s+(\w+)", sql, re.IGNORECASE)
        if alter_match:
            return f"ALTER TABLE {alter_match.group(1)} DROP COLUMN {alter_match.group(2)};"
        return None

    def stage_staging_deploy(self) -> bool:

    def stage_canary_release(self) -> bool:
        print("[階段 6/7] 金絲雀發布")
        initial_weight = 10
        success_steps = self._run_command([
            "kubectl", "get", "deployment", "my-service",
            "-n", "production", "-o", "jsonpath={.status.readyReplicas}",
        ], timeout=10)
        if not success_steps:
            return False
        total_replicas = int(success_steps.strip())
        canary_replicas = max(1, total_replicas * initial_weight // 100)
        print(f"金絲雀發布: {canary_replicas}/{total_replicas} 個執行個體")
        for step, target_weight in enumerate([10, 25, 50, 75, 100], 1):
            print(f"金絲雀步驟 {step}: 增加至 {target_weight}%")
            target_replicas = max(1, total_replicas * target_weight // 100)
            self._update_canary_weight(canary_replicas, target_replicas)
            if not self._monitor_canary_health():
                print(f"金絲雀發布在 {target_weight}% 失敗，開始回滾")
                return False
            time.sleep(30)
        print("金絲雀發布成功")
        return True

    def _monitor_canary_health(self, duration_seconds: int = 60) -> bool:
        check_interval = 10
        checks = duration_seconds // check_interval
        for i in range(checks):
            error_rate = self._check_error_rate()
            latency = self._check_latency()
            if error_rate > 1.0:

                return False
            if latency > 2000:
                print(f"延遲過高: {latency}ms")

            time.sleep(check_interval)
        return True

    def _run_command(self, cmd: List[str], check: bool = False, timeout: int = 60) -> Optional[str]:
        try:
            result = subprocess.run(
                cmd, capture_output=True, text=True,
                timeout=timeout, check=check,
            )
            return result.stdout
        except (subprocess.CalledProcessError, subprocess.TimeoutExpired, FileNotFoundError) as e:
            print(f"命令失敗: {' '.join(cmd)}")
            print(f"錯誤: {e}")
            return None

    def _read_file(self, path: str) -> str:
```
