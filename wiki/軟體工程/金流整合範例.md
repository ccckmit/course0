# 金流整合範例

`code/軟體工程/payment/` 目錄下包含三種金流閘道的 Python 整合範例：Stripe（國際信用卡）、綠界 ECPay（台灣第三方支付）、以及 Pay4（自建金流系統的統一閘道）。

## Stripe 閘道

### 功能

- `create_payment()` — 建立 PaymentIntent
- `confirm_payment()` — 確認付款
- `handle_webhook()` — 驗證 Webhook 簽章 + 事件分派 (`payment_intent.succeeded`, `payment_intent.payment_failed`)
- `refund()` — 全額 / 部分退款

### 實作重點

```python
# 建立付款
intent = stripe.PaymentIntent.create(
    amount=req.amount,
    currency=req.currency.lower(),
    metadata={"order_id": req.order_id},
)

# Webhook 驗證
event = stripe.Webhook.construct_event(payload, sig_header, webhook_secret)
```

- 使用 `stripe` Python SDK
- Webhook 簽章驗證防止偽造事件
- 所有外部呼叫包在 `try/except stripe.error.StripeError` 中

## 綠界 ECPay 閘道

### 功能

- `create_payment_form()` — 產生 AIO 表單資料（含 CheckMacValue 簽章）
- `verify_callback()` — 驗證回調的 CheckMacValue
- `handle_callback()` — 處理付款結果 (RtnCode=1 成功)
- `query_trade()` / `refund()` — 查詢與退款

### CheckMacValue 簽章演算法

```python
# 1. 參數依 key 排序
# 2. URL encode
# 3. 前面加上 HashKey, 後面加上 HashIV
# 4. URL encode (第二次)
# 5. SHA256 → 大寫十六進位
def _generate_check_mac_value(self, params: dict) -> str:
    sorted_params = sorted(params.items())
    raw = urllib.parse.urlencode(sorted_params)
    raw = f"HashKey={self.hash_key}&{raw}&HashIV={self.hash_iv}"
    raw = urllib.parse.quote(raw, safe='=&')
    return hashlib.sha256(raw.lower().encode('utf-8')).hexdigest().upper()
```

- 不依賴任何 SDK，純 Python 實作簽章
- 測試涵蓋簽章一致性、回調驗證、簽章篡改偵測

## Pay4 閘道 (`pay4_gateway.py`)

將 `pay4/` 自建金流系統包裝成與 Stripe/ECPay 一致的介面：

- 自動初始化 Pay4 資料庫 + 建立商家
- 跨行程共用同一 DB 時自動重複使用商家
- 支援 `create_payment()` 和 `refund()`

```python
gw = Pay4Gateway(db_path="/tmp/pay4.db")
resp = gw.create_payment(PaymentRequest(order_id="ORD-001", amount=5000))
# → PaymentResponse(status=success, payment_id="o_abc...")
```

## 統一處理器

`PaymentGateway` 用 Provider 模式封裝多個金流後端：

```python
gw = PaymentGateway({
    "stripe": StripeGateway(...),
    "ecpay": ECPayGateway(...),
    "pay4": Pay4Gateway(...),
})
resp = gw.create_payment(req, provider="stripe")
```

## 測試策略

- **Stripe**: mock `stripe.PaymentIntent.create` / `stripe.Webhook.construct_event`
- **ECPay**: 純函數測試 CheckMacValue 一致性 + callback 場景
- **Pay4**: 使用真實 Pay4 引擎 (SQLite temp file)，端到端測試訂單流

全部 22 項測試不需真實金流帳號即可執行：

```bash
cd code/軟體工程/payment
./test.sh
```
