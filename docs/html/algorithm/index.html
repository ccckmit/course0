1. 複雜度分析

演算法的效率用 Big O 表示，描述執行時間或記憶體用量如何隨輸入規模成長。

常見複雜度等級

▶
# O(1) — 常數時間 def getFirst(arr): return arr[0] # O(log n) — 對數時間 (二分搜尋) def binarySearch(arr, target): ... # O(n) — 線性時間 def linearSearch(arr, target): for i in range(len(arr)): if arr[i] == target: return i return -1 # O(n²) — 平方時間 (泡沫排序) def bubbleSort(a): for i in range(len(a)): for j in range(i): if a[j] > a[i]: a[i], a[j] = a[j], a[i] return a # O(2ⁿ) — 指數時間 (費氏數列遞迴) def fib(n): if n <= 1: return n return fib(n-1) + fib(n-2)

2. 查表法

將計算結果預先存好，用空間換取時間。典型例子：費氏數列、2ⁿ 計算。

費氏數列 vs 2ⁿ — 遞迴 vs 查表

▶
# 費氏數列：遞迴 (O(2ⁿ)) fib(n) = fib(n-1) + fib(n-2) # 費氏數列：查表 (O(n)) F = [0, 1] + [0]*(n-1) for i in range(2, n+1): F[i] = F[i-1] + F[i-2] # 2ⁿ：三種方法對比 # 方法 1: 直接計算 O(1) def power2n(n): return 2**n # 方法 2: 遞迴 O(n) def power2n(n): return 2*power2n(n-1) # 方法 3: 遞迴+查表 O(n) def power2n(n, table={}): if n not in table: table[n] = 2*power2n(n-1, table) return table[n]

3. 列舉法

系統性地列舉所有可能情況。核心是排列與組合的生成。

排列與組合枚舉

▶
# 排列：n! 種可能 def perm(a, start, end): if start == end: print(a) else: for i in range(start, end): a[start], a[i] = a[i], a[start] # 交換 perm(a, start+1, end) a[start], a[i] = a[i], a[start] # 還原 # 組合：C(n,m) 種可能 def comb(a, m, start, chosen): if len(chosen) == m: print(chosen); return if start >= len(a): return chosen.append(a[start]) comb(a, m, start+1, chosen) # 選 a[start] chosen.pop() comb(a, m, start+1, chosen) # 不選 a[start]

4. 雜湊法

透過雜湊函數將資料映射到固定範圍，實現接近 O(1) 的查找。包含雜湊表、布隆過濾器、SHA256 等。

雜湊表與布隆過濾器

▶
# 簡單雜湊表 (鏈結法) class HashTable: def __init__(self, size=100): self.table = [[] for _ in range(size)] def hash(self, key): return hash(key) % len(self.table) def put(self, key, val): self.table[self.hash(key)].append((key, val)) def get(self, key): for k, v in self.table[self.hash(key)]: if k == key: return v return None # 布隆過濾器 (Bloom Filter) # 用多個雜湊函數判斷元素「可能存在」或「一定不存在」

5. 暴力法

窮舉所有可能性，沒有捷徑。當問題規模小時可行，也是比特幣挖礦（SHA256 反算）的基礎。

暴力搜尋範例

▶
# 比特幣挖礦：暴力尋找符合條件的 nonce def mine(block, difficulty): prefix = '0' * difficulty nonce = 0 while True: h = sha256(block + str(nonce)) if h.startswith(prefix): return nonce nonce += 1

6. 迭代法

從初始猜測開始，反覆套用同一個規則逐步逼近解答。包含 Newton 法、Jacobi 迭代、PageRank、Lorenz 系統、Mandelbrot 集合等。

迭代法的經典應用

▶
# Newton 法求根：x = x - f(x)/f'(x) def newton(f, df, x0, eps=1e-7, max_it=100): x = x0 for _ in range(max_it): x_next = x - f(x)/df(x) if abs(x_next - x) < eps: return x_next x = x_next return x # PageRank：反覆傳遞權重 # PR(A) = (1-d) + d * Σ PR(T)/C(T) # d = 阻尼係數，C(T) = T 的對外連結數 # Jacobi 迭代：解線性方程組 # x^(k+1) = (b - Σ a[i][j]*x[j]^k) / a[i][i]

7. 遞迴法

函數呼叫自身解決子問題，是許多高階演算法的基礎。從基本遞迴到 BNF 語法解析、符號微分。

遞迴的經典模式

▶
# 階乘 def fact(n): return 1 if n <= 1 else n * fact(n-1) # BNF 語法遞迴解析 (範例: 運算式) # E → T | T + E # T → F | F * T # F → (E) | num def parseE(tokens): left = parseT(tokens) if peek(tokens) == '+': consume(tokens); return left + parseE(tokens) return left # 符號微分：d/dx 的遞迴規則 def diff(expr, var): if isConst(expr): return 0 if isVar(expr): return 1 if expr == var else 0 if isAdd(expr): return diff(expr.left, var) + diff(expr.right, var) if isMul(expr): return diff(expr.left, var)*expr.right + expr.left*diff(expr.right, var)

9. λ 演算

用純函數定義布林值、數字、串列、遞迴—證明計算是函數的應用。Church 編碼的完整實作。

Church 編碼 — 全部都是函數

▶
# Church Booleans TRUE = lambda x: lambda y: x FALSE = lambda x: lambda y: y AND = lambda p: lambda q: p(q)(p) NOT = lambda c: c(FALSE)(TRUE) # Church Numerals _zero = lambda f: lambda x: x SUCCESSOR = lambda n: lambda f: lambda x: f(n(f)(x)) _one = SUCCESSOR(_zero) ADDITION = lambda m: lambda n: n(SUCCESSOR)(m) MULTIPLICATION = lambda m: lambda n: lambda f: m(n(f)) # Y Combinator: 匿名函數的遞迴 Y = lambda f: (lambda x: f(lambda y: x(x)(y))) \ (lambda x: f(lambda y: x(x)(y))) # 用 Y 定義階乘 FACTORIAL = Y(lambda f: lambda n: IS_ZERO(n)(lambda _: SUCCESSOR(n)) (lambda _: MULTIPLICATION(n)(f(PREDECESSOR(n))))(NIL))

10. 評分與改良法

對解答評分，然後逐步改良。核心思想：評估 → 改進 → 再評估。

隨機改良排序

▶
# 隨機改良排序：亂換 → 評分 → 保留好的 def randomImproveSort(a): best = a[:] while True: # 隨機交換兩個元素 i, j = random.sample(range(len(a)), 2) a[i], a[j] = a[j], a[i] if score(a) > score(best): best = a[:] elif score(a) < score(best): a[i], a[j] = a[j], a[i] # 還原

11. 爬山演算法

從隨機起點出發，每一步往鄰域中最佳方向移動，直到抵達區域頂點。簡單但可能陷入區域最佳解。

爬山演算法實作

▶
# 單變數爬山 def hillClimbing(f, x, dx=0.01): while True: if f(x+dx) > f(x): # 右邊更高 x += dx elif f(x-dx) > f(x): # 左邊更高 x -= dx else: return x # 區域最高點 # 多變數爬山：對每個維度逐一調整 def hillClimbingN(f, p, step=0.01): while True: improved = False for i in range(len(p)): p[i] += step if f(p) > f(p): ... # 測試各方向 p[i] -= step if not improved: return p

12. 模擬退火法

爬山演算法的改良版，以一定機率接受較差的解，避免陷入區域最佳。隨著時間降低接受機率（降溫）。

模擬退火法

▶
# 模擬退火法框架 def simulatedAnnealing(f, initState, schedule): current = initState for t in range(maxIter): T = schedule(t) # 當前溫度 neighbor = randomNeighbor(current) delta = f(neighbor) - f(current) if delta > 0: # 更好 → 接受 current = neighbor elif random() < exp(delta/T): # 較差 → 機率性接受 current = neighbor return current

13. 梯度下降法

沿梯度反方向調整參數，是機器學習的核心優化方法。包含微分、偏微分、梯度計算、隨機梯度下降 (SGD)。

梯度下降實作

▶
# 計算梯度 def grad(f, p, step=0.01): gp = p.copy() for k in range(len(p)): p1 = p.copy(); p1[k] += step gp[k] = (f(p1) - f(p)) / step # 偏微分 return gp # 梯度下降：p = p - η * ∇f(p) def gradientDescendent(f, p0, step=0.01, max_loops=100000): p = p0.copy() for i in range(max_loops): gp = grad(f, p) # 計算梯度 if norm(gp) < 1e-5: break # 收斂 p -= gp * step # 反梯度方向更新 return p # 隨機梯度下降 (SGD)：每次只用一個樣本更新 # 適合大規模資料，有隨機性可逃脫區域最佳
gd.py 反傳遞算法 梯度計算 微分

14. 貪婪法

每一步都選擇當前最優選項，期望達到全域最優。常用於 Huffman 編碼、最小生成樹 (Kruskal/Prim)。

Huffman 編碼與 Kruskal 演算法

▶
# Huffman 編碼：合併最小頻率的兩個節點 # 1. 統計每個字元頻率 # 2. 建立優先佇列 (min-heap) # 3. 重複取出最小兩個節點，合併後放回 # 4. 直到只剩一個節點 (root) # Kruskal 最小生成樹： def kruskal(num_nodes, edges): edges = sorted(edges, key=lambda e: e[2]) # 按權重排序 parent = list(range(num_nodes)) def find(i): if i != parent[i]: parent[i] = find(parent[i]) return parent[i] mst = [] for u, v, w in edges: if find(u) != find(v): # 不會形成環 parent[find(u)] = find(v) mst.append((u, v, w)) return mst

15. 搜尋法

在圖形或狀態空間中尋找目標節點。三種核心策略：深度優先 (DFS)、廣度優先 (BFS)、最佳優先 (A*)。

圖形搜尋的三大策略

▶
# 圖形表示 g = { '1': {'n':['2','5'], 'v':0}, '2': {'n':['3','4'], 'v':0}, ... } # DFS：遞迴深入 (堆疊) def dfs(g, node): if g[node]['v'] != 0: return g[node]['v'] = 1 for n in g[node]['n']: dfs(g, n) # BFS：逐層擴散 (佇列) def bfs(g, queue): if len(queue)==0: return node = queue.pop() if g[node]['v'] == 0: g[node]['v'] = 1 for n in g[node]['n']: if not g[n]['v']: queue.insert(0, n) bfs(g, queue) # A* 搜尋：f(n) = g(n) + h(n) # g(n) = 起點到 n 的實際成本 # h(n) = n 到終點的估計成本 (啟發式函數)

16. 分割擊破法

將大問題分割為獨立子問題，分別解決後合併。核心在於「分割」與「合併」的設計。

合併排序與二元搜尋

▶
# 合併排序 (Merge Sort): O(n log n) def mergeSort(arr): if len(arr) <= 1: return arr mid = len(arr)//2 left = mergeSort(arr[:mid]) # 分割 right = mergeSort(arr[mid:]) # 分割 return merge(left, right) # 合併 def merge(a, b): result = [] while a and b: result.append(a.pop(0) if a[0]<b[0] else b.pop(0)) return result + a + b # 二元搜尋 (Binary Search): O(log n) def binSearch(arr, target, lo, hi): if lo > hi: return -1 mid = (lo+hi)//2 if arr[mid] == target: return mid if arr[mid] < target: return binSearch(arr, target, mid+1, hi) return binSearch(arr, target, lo, mid-1)

17. 動態規劃

將問題分解為重疊的子問題，用表格記錄子問題答案避免重複計算。兩個關鍵：最優子結構與重疊子問題。

編輯距離 (Edit Distance)

▶
# 編輯距離：DP[i][j] = a[0..i] 到 b[0..j] 的最少編輯次數 def editDistance(a, b): m, n = len(a), len(b) DP = [[0]*(n+1) for _ in range(m+1)] for i in range(m+1): DP[i][0] = i for j in range(n+1): DP[0][j] = j for i in range(1, m+1): for j in range(1, n+1): if a[i-1] == b[j-1]: DP[i][j] = DP[i-1][j-1] # 相同 else: DP[i][j] = 1 + min( DP[i-1][j-1], # 取代 DP[i][j-1], # 插入 DP[i-1][j] # 刪除 ) return DP[m][n]
editDistance.py 組合數 DP

18. 隨機法

利用隨機性解決問題。從亂數產生器到拉斯維加斯演算法（保證正確、隨機時間）。

亂數產生器與隨機演算法

▶
# 線性同餘產生器 (LCG) def lcg(seed, a=1664525, c=1013904223, m=2**32): seed = (a * seed + c) % m return seed / m # 隨機快速排序 (隨機選 pivot 避免最壞情況) def randomizedQuickSort(arr): if len(arr) <= 1: return arr pivot = random.choice(arr) # 隨機 pivot lt = [x for x in arr if x < pivot] eq = [x for x in arr if x == pivot] gt = [x for x in arr if x > pivot] return randomizedQuickSort(lt) + eq + randomizedQuickSort(gt)

19. 蒙地卡羅法

用大量隨機樣本模擬來估計數值。包含 π 估計、排隊理論、Markov 鏈、貝氏推論、EM 演算法。

蒙地卡羅模擬

▶
# 蒙地卡羅估計 π def estimatePi(n=100000): inside = 0 for _ in range(n): x, y = random.random(), random.random() if x*x + y*y <= 1: inside += 1 return 4 * inside / n # Markov Chain Monte Carlo (MCMC) # 透過 Markov 鏈抽樣近似複雜的機率分佈 # EM 演算法：含隱變數的最大似然估計 # E 步：估計隱變數的後驗機率 # M 步：最大化似然函數更新參數

20. 遺傳演算法

模仿達爾文演化論：選擇、交叉、突變。經過多代演化，適應度最高的個體即為近似最佳解。

遺傳演算法框架

▶
# 核心流程 def geneticAlgorithm(population, fitness, max_gen=100): for gen in range(max_gen): # 1. 評估適應度 scores = [fitness(ind) for ind in population] # 2. 選擇 (輪盤法 / 錦標賽法) selected = selection(population, scores) # 3. 交叉 (crossover) offspring = crossover(selected) # 4. 突變 (mutation) population = mutate(offspring) return best(population, fitness)

21. 資訊理論

量化資訊的度量：熵 (entropy)、交叉熵、KL 散度。是機器學習中損失函數的基礎。

熵與交叉熵

▶
# 熵：H(X) = -Σ p(x) log p(x) def entropy(probs): return -sum(p * math.log2(p) for p in probs if p > 0) # 交叉熵：H(p,q) = -Σ p(x) log q(x) def crossEntropy(true_probs, pred_probs): return -sum(p * math.log(q) for p, q in zip(true_probs, pred_probs) if p > 0) # KL 散度：D_KL(p||q) = Σ p(x) log(p(x)/q(x)) # = H(p,q) - H(p) (交叉熵 - 熵)

22. 計算理論

探索計算的本質與極限：有限狀態機、形式文法、λ 演算、圖靈機。這些是計算機科學的理論基礎。

有限狀態機

▶

DFA (決定性有限自動機) 是最簡單的計算模型，只能辨識正規語言。

# 接受偶數個 0 的二進位字串 class DFA: def __init__(self): self.state = 'even' # even / odd def transition(self, c): if c == '0': self.state = 'odd' if self.state=='even' else 'even' def accept(self): return self.state == 'even'

形式文法

▶

Chomsky 階層：Type 3 (正規) → Type 2 (上下文無關) → Type 1 (上下文相關) → Type 0 (無限制)。

# 上下文無關文法: S → aSb | ε # 產生 aⁿbⁿ 字串 def anbn(n): return 'a'*n + 'b'*n # 上下文相關文法: aⁿbⁿcⁿ (需要計數到 n) def anbncn(n): return 'a'*n + 'b'*n + 'c'*n
