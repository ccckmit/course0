Graph Algorithms — BFS、DFS、最短路徑、最小生成樹

圖的表示

圖由頂點（Vertex）和邊（Edge）組成，常見的表示方式有三種：

  • 鄰接矩陣（Adjacency Matrix）：2D 陣列，matrix[i][j] 表示頂點 i 到 j 是否有邊。適合稠密圖，空間 O(V²)。
  • 鄰接串列（Adjacency List）：每個頂點維護一個鄰居串列。適合稀疏圖，空間 O(V+E)。
  • 邊串列（Edge List）：儲存所有邊的列表。適合需要枚舉所有邊的演算法。

BFS 與 DFS

廣度優先搜尋（BFS）：使用佇列，逐層探索。可求無權重圖的最短路徑，時間 O(V+E)。

def bfs(graph, start): visited = set() queue = [start] visited.add(start) while queue: v = queue.pop(0) for neighbor in graph[v]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) return visited

深度優先搜尋（DFS）：使用堆疊或遞迴，用於拓撲排序、連通分量、環檢測。

def dfs(graph, start, visited=None): if visited is None: visited = set() visited.add(start) for neighbor in graph[start]: if neighbor not in visited: dfs(graph, neighbor, visited) return visited

最短路徑

演算法時間限制說明
DijkstraO((V+E)log V)非負權重使用優先佇列
Bellman-FordO(VE)可處理負權重可檢測負環
Floyd-WarshallO(V³)任意全點對最短路徑
A*視啟發函數非負權重啟發式搜尋

最小生成樹 (MST)

Kruskal 演算法：將邊按權重排序，從最小邊開始，使用 Union-Find 避免形成環。

Prim 演算法：類似 Dijkstra，從起點開始每次加入最小跨接邊。
