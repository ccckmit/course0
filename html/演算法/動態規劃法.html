動態規劃法

Dynamic Programming — 最優子結構與重疊子問題

← 回目錄 上一篇：分割擊破法 下一篇：貪婪法 →

核心概念

動態規劃（Dynamic Programming, DP）是一種將複雜問題分解為重疊子問題的演算法策略。適用於具備以下兩個性質的問題：

  • 最優子結構（Optimal Substructure）：問題的最優解包含子問題的最優解。
  • 重疊子問題（Overlapping Subproblems）：子問題會被多次重複計算。

實作方法

自頂向下（Top-down）：遞迴 + 記憶化（Memoization）。保留遞迴的直觀性，只計算需要的子問題。

自底向上（Bottom-up）：迭代填表（Tabulation）。計算所有子問題，無遞迴開銷，通常效率更高。

費波那契數列

樸素遞迴為 O(2ⁿ)，動態規劃可優化至 O(n)。

def fibonacci_dp(n): if n <= 1: return n dp = [0] * (n + 1) dp[1] = 1 for i in range(2, n + 1): dp[i] = dp[i - 1] + dp[i - 2] return dp[n] # 空間優化版：O(1) def fibonacci_opt(n): if n <= 1: return n a, b = 0, 1 for _ in range(2, n + 1): a, b = b, a + b return b

0/1 背包問題

在容量 W 的限制下，從 n 個物品中選擇最大化總價值。每個物品只能選或不選。

def knapsack(weights, values, W): n = len(weights) dp = [[0] * (W + 1) for _ in range(n + 1)] for i in range(1, n + 1): for w in range(1, W + 1): if weights[i - 1] <= w: dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - weights[i - 1]] + values[i - 1]) else: dp[i][w] = dp[i - 1][w] return dp[n][W]

最長公共子序列 (LCS)

def lcs(s1, s2): m, n = len(s1), len(s2) dp = [[0] * (n + 1) for _ in range(m + 1)] for i in range(1, m + 1): for j in range(1, n + 1): if s1[i - 1] == s2[j - 1]: dp[i][j] = dp[i - 1][j - 1] + 1 else: dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]) return dp[m][n]

其他經典 DP 問題

  • 編輯距離（Edit Distance / Levenshtein Distance）：計算將一個字串轉為另一個所需的最少操作次數。
  • 矩陣鏈乘積（Matrix Chain Multiplication）：找出最優的矩陣相乘順序，最小化乘法次數。
  • 最長遞增子序列（LIS）：O(n²) DP 或 O(n log n) 貪婪 + 二分搜尋。
  • 旅行推銷員問題（TSP）：狀態壓縮 DP，O(n² · 2ⁿ)。
