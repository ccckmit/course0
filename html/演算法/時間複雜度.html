時間複雜度

Time Complexity — 演算法效率分析的核心工具

← 回目錄 下一篇：空間複雜度 →

什麼是時間複雜度？

時間複雜度（Time Complexity）描述演算法執行時間隨輸入規模增長的趨勢。我們使用 Big-O 記號來表示最壞情況下的漸進上界，忽略常數因子和低階項。

常見複雜度等級

記號名稱範例輸入規模建議
O(1)常數時間陣列隨機存取任意
O(log n)對數時間二分搜尋任意
O(n)線性時間線性搜尋~10⁸
O(n log n)線性對數時間合併排序~10⁷
O(n²)平方時間氣泡排序~10⁴
O(n³)立方時間矩陣乘法~500
O(2ⁿ)指數時間費波那契遞迴~30

分析要點

最壞情況 vs 平均情況：Big-O 通常表示最壞情況。例如快速排序平均 O(n log n)，最壞 O(n²)。

忽略常數：O(2n) 和 O(n) 等價，常數因子在漸進分析中被忽略。

忽略低階項：O(n² + n) = O(n²)，只保留增長最快的項。

程式碼範例

def linear_search(arr, target): for i in range(len(arr)): if arr[i] == target: return i return -1 # 時間：O(n)，空間：O(1)
def binary_search(arr, target): left, right = 0, len(arr) - 1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1 # 時間：O(log n)，空間：O(1)
def bubble_sort(arr): n = len(arr) for i in range(n): for j in range(0, n - i - 1): if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] # 時間：O(n²)，空間：O(1)
