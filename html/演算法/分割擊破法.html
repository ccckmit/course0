分割擊破法

Divide and Conquer — 分而治之的經典策略

← 回目錄 上一篇：遞迴法 下一篇：動態規劃法 →

核心概念

分割擊破法（Divide and Conquer）是將一個大問題分割成數個規模較小的子問題，遞迴解決子問題，再將子問題的解合併為原問題的解。三步驟：

  1. 分割（Divide）：將原問題分割成數個規模較小的相同類型子問題。
  2. 解決（Conquer）：遞迴解決子問題。當子問題夠小時直接求解。
  3. 合併（Merge）：將子問題的解合併為原問題的解。

合併排序 (Merge Sort)

將陣列遞迴平分，分別排序後合併。時間 O(n log n)，空間 O(n)。

def merge_sort(arr): if len(arr) <= 1: return arr mid = len(arr) // 2 left = merge_sort(arr[:mid]) right = merge_sort(arr[mid:]) return merge(left, right) def merge(left, right): i = j = 0 result = [] while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]); i += 1 else: result.append(right[j]); j += 1 result.extend(left[i:]) result.extend(right[j:]) return result

快速排序 (Quick Sort)

選 pivot 將陣列分為小於和大於 pivot 的兩部分，遞迴排序。平均 O(n log n)，最壞 O(n²)。

def quicksort(arr): if len(arr) <= 1: return arr pivot = arr[len(arr) // 2] left = [x for x in arr if x < pivot] middle = [x for x in arr if x == pivot] right = [x for x in arr if x > pivot] return quicksort(left) + middle + quicksort(right)

Strassen 矩陣乘法

將矩陣分為四個子矩陣，透過 7 次乘法取代傳統的 8 次乘法。時間 O(n^2.807)，優於傳統 O(n³)。

最大子陣列問題

尋找陣列中總和最大的連續子陣列。分割擊破解法：分別求左半最大、右半最大、跨中點最大三者取最大值。
