排序演算法分類

排序演算法可分為比較排序與非比較排序兩大類。比較排序的理論下限為 O(n log n)，而非比較排序可達到 O(n)。

O(n²) 比較排序

氣泡排序（Bubble Sort）：重複走訪數列，相鄰元素兩兩比較，大的向後移。可加入提早終止優化（若無交換則已排序）。

def bubble_sort(arr): n = len(arr) for i in range(n): swapped = False for j in range(0, n - i - 1): if arr[j] > arr[j + 1]: arr[j], arr[j + 1] = arr[j + 1], arr[j] swapped = True if not swapped: break return arr

選擇排序（Selection Sort）：每次從未排序部分選最小值，放到已排序部分的末尾。

插入排序（Insertion Sort）：將元素插入已排序部分的適當位置。對幾乎已排序的資料效率極高（O(n)）。

O(n log n) 比較排序

合併排序（Merge Sort）：分治策略，將陣列分成兩半分別排序再合併。穩定排序，需要 O(n) 額外空間。

def merge_sort(arr): if len(arr) <= 1: return arr mid = len(arr) // 2 left = merge_sort(arr[:mid]) right = merge_sort(arr[mid:]) return merge(left, right) def merge(left, right): result = [] i = j = 0 while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]); i += 1 else: result.append(right[j]); j += 1 result.extend(left[i:]) result.extend(right[j:]) return result

快速排序（Quick Sort）：選 pivot 分區，左小右大。平均最快但最壞 O(n²)，可透過隨機選 pivot 規避。

堆積排序（Heap Sort）：利用最大堆積進行排序。時間 O(n log n)，空間 O(1)。

非比較排序

計數排序（Counting Sort）：O(n+k)，適用於範圍有限的整數。統計每個值出現次數。

基數排序（Radix Sort）：按位數逐位排序，從最低位到最高位。

桶排序（Bucket Sort）：將資料均勻分配到桶中，各桶分別排序。
