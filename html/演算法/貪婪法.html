核心概念

每一步都選擇當前看起來最優的選項，期望最終能得到全域最優解。貪婪法的三個組成部分：

  • 選擇函數（Selection Function）：從候選中選出最優者。
  • 可行性檢查（Feasibility Check）：確保選擇可行。
  • 目標函數更新：更新問題狀態和目標值。

活動選擇問題

選擇最多不衝突的活動。策略：按結束時間排序，每次選擇結束最早且不衝突的活動。

def activity_selection(activities): # activities: list of (start, end) activities.sort(key=lambda x: x[1]) selected = [activities[0]] last_end = activities[0][1] for start, end in activities[1:]: if start >= last_end: selected.append((start, end)) last_end = end return selected

Huffman 編碼

一種無失真資料壓縮演算法。根據字元出現頻率建構最優前綴碼：

  • 將每個字元視為葉節點，頻率為權重
  • 重複合併兩個最小頻率的節點
  • 最終得到一棵最優二元樹（Huffman Tree）

最小生成樹

Kruskal：將邊按權重排序，從小到大選擇不形成環的邊（使用 Union-Find 檢測）。

Prim：類似 Dijkstra，從起點開始每次加入最小跨接邊，逐步擴展生成樹。
