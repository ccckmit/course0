線性搜尋 (Linear Search)

從資料結構的第一個元素開始逐一比對，直到找到目標或遍歷完整個結構。時間 O(n)。適用於未排序的小型資料集。

二分搜尋 (Binary Search)

在已排序陣列中，每次將搜尋範圍縮小一半。時間 O(log n)。需要預先排序。

def binary_search(arr, target): left, right = 0, len(arr) - 1 while left <= right: mid = (left + right) // 2 if arr[mid] == target: return mid elif arr[mid] < target: left = mid + 1 else: right = mid - 1 return -1

圖形搜尋

廣度優先搜尋 (BFS)：使用佇列逐層探索，找到的路徑一定是最短的（無權重圖）。時間 O(V+E)。

深度優先搜尋 (DFS)：使用堆疊或遞迴，沿一條路徑走到盡頭再回溯。用於拓撲排序、連通分量檢測。

A* 搜尋演算法

A* 是一種啟發式搜尋演算法，結合了 Dijkstra 的最短路徑保證與貪婪最佳優先搜尋的效率。使用評估函數 f(n) = g(n) + h(n)：

  • g(n)：從起點到節點 n 的實際成本
  • h(n)：從節點 n 到終點的啟發式估計成本

只要 h(n) 是可容許的（不高估實際成本），A* 保證找到最短路徑。
